Two ways to connect, depending on how deep you want to go:

- **Just the MCP server**: one command that gives Claude every Bland tool.
- **The Bland plugin**: the MCP server plus skills for every part of the platform, `/bland:*` commands for a file-based pathway workspace, and Norm, the agent builder. This is the full Bland development experience in Claude Code.

## Prerequisites

- [Claude Code](https://code.claude.com) installed
- Your Bland API key from the [dashboard](https://app.bland.ai/dashboard/settings)

## Option 1: Add the MCP server

```bash
claude mcp add --transport http bland https://api.bland.ai/v1/mcp \
  --header "Authorization: Bearer $BLAND_API_KEY"
```

That's it. Verify the connection:

```bash
claude mcp list
```

  <img src="/images/mcp/claude-mcp-list.png" alt="claude mcp list showing the bland server connected" />
</Frame>

Inside a session, run `/mcp` to see the server's tools, or just ask:

```
> list my pathways and tell me which ones have no published version
> pull the transcript of my last call and explain where the agent went off script
> create a pathway that qualifies inbound leads and books a demo
```

<Tip>
By default `claude mcp add` configures the server for the current project only. Add `--scope user` to make it available in every project.
</Tip>

## Option 2: Install the Bland plugin

The plugin layers a complete pathway-engineering workflow on top of the MCP server: skills that load on demand, a local file workspace for pathways, validation against the real compiler, simulated conversations, and Norm's autonomous build-test-fix loop.

Inside Claude Code:

```
/plugin marketplace add CINTELLILABS/bland-plugins
/plugin install bland@bland
```

The installer prompts for your API key and stores it securely. Then start with:

```
/bland:norm build me an agent that confirms dental appointments
```

Useful commands once you're in:

| Command | What it does |
| --- | --- |
| `/bland:clone` | List pathways, or pull one into a local file workspace |
| `/bland:validate` | Offline structural check of your edits |
| `/bland:test` | Simulate a conversation against your local pathway |
| `/bland:commit` | Run the server compiler and save (optionally publish) a new version |
| `/bland:loop` | Autonomous build-test-fix loop until a goal passes |
| `/bland:status --check` | Self-test your setup end to end |

See the [Bland plugin](/integrations/mcp/norm) page for the full command reference, the skills, the build-to-production flow, and the file-based pathway workspace.
