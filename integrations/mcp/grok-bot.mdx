[Grok Bot](https://x.ai/bot) works from a cloud computer and can use connected tools. Its [official connector instructions](https://docs.x.ai/grok-bot/computer-and-apps#connect-an-app) use **Settings > Plugins**. Connections are shared across your account, and you attach a connector to a task with `@`.

<Note>
The documented Plugins flow does not establish how to add an arbitrary MCP URL with an Authorization header. The Bland connection has not been verified in Grok Bot. Confirm that your version supports both before following the configuration below.
</Note>

Setting up a different assistant? See [Personal AI Agents](/integrations/mcp/personal-agents).

## Prerequisites

- Access to Grok Bot with a custom MCP connection that accepts a URL and headers
- A Bland API key from the [dashboard](https://app.bland.ai/dashboard/settings)
- An active [Agent Phone Plan](/platform/agent-phone-plan) if you want a dedicated number for your agent

## If your client supports custom MCP servers

Configure the connection with these values:

| Field | Value |
| --- | --- |
| Server URL | `https://api.bland.ai/v1/mcp` |
| Header name | `Authorization` |
| Header value | `Bearer YOUR_BLAND_API_KEY` |

Replace `YOUR_BLAND_API_KEY` with your key in the connection's credential field. Attach the connection to your task, then ask Grok Bot to list your Bland pathways to check authentication before placing a call.

If the required custom-server or header controls are unavailable, use a client with documented setup, such as [Poke](/integrations/mcp/poke) or [OpenClaw](/integrations/mcp/openclaw).

## Account setup and phone numbers

You can create a Bland account and subscribe to the Agent Phone Plan at [Billing & Plans](https://app.bland.ai/dashboard/pay?tab=plan), then configure the connection with your API key.

Automatic signup through the [Agent onboarding API](/platform/connect-your-agent) requires your agent to make HTTP requests, poll for approval, and store the returned credential. Automatic MCP registration is an additional client capability. These steps have not been verified in Grok Bot; use manual account and connection setup unless you have confirmed those capabilities.

On the Agent Phone Plan, calls and texts are limited to US and Canadian numbers, one call at a time, up to 60 minutes per outbound call, and up to 100 texts a day. See [Limits](/platform/agent-phone-plan#limits).
