[Grok Bot](https://x.ai/bot) works from a cloud computer, can use connected tools, and can approve a payment through its own agent wallet. That combination lets it sign up for Bland, pay for its own number, and hand you the finished connection without you ever opening a signup page. Relaying a one-time code by text is your only manual step.

Setting up a different assistant? See [Personal AI Agents](/integrations/mcp/personal-agents).

## Prerequisites

- Access to Grok Bot with its agent wallet connected, to let it set itself up
- Or: a Bland API key from the [dashboard](https://app.bland.ai/dashboard/settings) and a custom MCP connection that accepts a URL and headers, to configure the connection yourself
- Either way, an active [Agent Phone Plan](/platform/agent-phone-plan) gets you a dedicated number and texting; headless self-setup pays for the first month as part of signup

## Option 1: Let Grok Bot set itself up

Tell Grok Bot:

```text
Read https://docs.bland.ai/platform/agent-headless-onboarding and set yourself up with a Bland account, paying with my agent wallet. Text me the verification code when it arrives so I can send it back to you, then add the account's API key as a custom MCP connection and confirm it works by listing my pathways.
```

Grok Bot starts the headless flow, asks your agent wallet to approve the first month of the Agent Phone Plan, and a verification code arrives at your phone by text. Relay that code back to Grok Bot, and it finishes setup and receives its API key and phone number in the same conversation. If the payment is declined, Grok Bot falls back to the link-based flow and asks you to approve it in a browser instead.

If your Grok Bot has no Link wallet connected, skip the headless flow and use the [Agent onboarding API](/platform/connect-your-agent) prompt from [Personal AI Agents](/integrations/mcp/personal-agents#option-2-let-the-agent-sign-itself-up) instead: Grok Bot shows you a link, and you add a card for the plan or pick free credits there.

See [Headless agent onboarding](/platform/agent-headless-onboarding) for the full request and response shapes, in case you want to follow along with what Grok Bot is doing.

## Option 2: Configure the connection yourself

<Note>
The documented Plugins flow does not establish how to add an arbitrary MCP URL with an Authorization header. Confirm that your version supports both before following the configuration below.
</Note>

Configure the connection with these values:

| Field | Value |
| --- | --- |
| Server URL | `https://api.bland.ai/v1/mcp` |
| Header name | `Authorization` |
| Header value | `Bearer YOUR_BLAND_API_KEY` |

Replace `YOUR_BLAND_API_KEY` with your key in the connection's credential field. Attach the connection to your task, then ask Grok Bot to list your Bland pathways to check authentication before placing a call.

If the required custom-server or header controls are unavailable, use a client with documented setup, such as [Poke](/integrations/mcp/poke) or [OpenClaw](/integrations/mcp/openclaw).

You can create the account yourself in the [dashboard](https://app.bland.ai) rather than through Option 1, and add the [Agent Phone Plan](/platform/agent-phone-plan) at [Billing & Plans](https://app.bland.ai/dashboard/pay?tab=plan) if you want a dedicated number and texting; without it, your agent calls from a shared Bland number on the org's free credits.

On the Agent Phone Plan, calls and texts are limited to US and Canadian numbers, one call at a time, up to 60 minutes per outbound call, and up to 100 texts a day. See [Limits](/platform/agent-phone-plan#limits).
