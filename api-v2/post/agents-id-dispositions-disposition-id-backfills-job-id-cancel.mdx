---
title: "Cancel Disposition Backfill"
api: "POST https://api.bland.ai/v2/agents/{agent_id}/dispositions/{disposition_id}/backfills/{job_id}/cancel"
description: "Stop a queued or running disposition backfill so it scores no more past calls and stops adding to your organization's usage costs."
---

### Overview

<Note>
Dispositions are enabled per organization. If your organization does not have access, these endpoints return `404`.
</Note>

Asks a `queued` or `running` backfill to stop. The request takes no body and returns `202` with the backfill as it reads right now. Cancellation finishes in the background. The backfill can still read `queued` or `running` until it settles as `cancelled`. Poll [Get Disposition Backfill](/api-v2/get/agents-id-dispositions-disposition-id-backfills-job-id) to confirm.

After the backfill settles as `cancelled`, you can start a new backfill for the same version.

Requires an admin, owner, operator, or prompter role.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="agent_id" type="string" required>
  The agent's unique identifier. Must be a UUID; otherwise returns `400` with the message `agentId must be a valid UUID`. Returns `404 Agent not found` if the agent is not in your organization.
</ParamField>

<ParamField path="disposition_id" type="string" required>
  The disposition's unique identifier. Must be a UUID; otherwise returns `400` with the message `dispositionId must be a valid UUID`.
</ParamField>

<ParamField path="job_id" type="string" required>
  The backfill's `id`. Must be a UUID; otherwise returns `400` with the message `jobId must be a valid UUID`. Returns `404 Backfill not found` if no backfill with this id belongs to the disposition. Returns `409 CONFLICT` if the backfill already reached a final status.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The backfill. See [Get Disposition Backfill](/api-v2/get/agents-id-dispositions-disposition-id-backfills-job-id) for every field.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of error objects if the request failed.
</ResponseField>
