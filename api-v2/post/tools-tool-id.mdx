---
title: "Update Tool"
api: "POST https://api.bland.ai/v2/tools/{tool_id}"
description: "Update an existing tool. All fields are optional. Only the fields you provide will be updated."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="tool_id" type="string" required>
  The tool's UUID exactly as returned by [Create Tool](/api-v2/post/tools) or [List Tools](/api-v2/get/tools). This endpoint does not accept the `TL-` prefix: `TL-...` returns `400 INVALID_PARAMETER` with the message `id: Invalid UUID format`.
</ParamField>

### Body Parameters

All fields are optional. Fields you send are merged over the stored tool definition, then the merged definition is validated as a whole. Fields you omit keep their current value. Only integration tools can be updated here; a custom HTTP tool returns `400 INVALID_TOOL_TYPE` and must be updated with [Update Custom Tool](/api-v1/post/tools-tool-id).

<ParamField body="name" type="string">
  The name the AI will see when deciding to use this tool.
</ParamField>

<ParamField body="description" type="string">
  Description of what the tool does. Maximum 5000 characters.
</ParamField>

<ParamField body="integration" type="string">
  The integration key to update. Must be one of: `bland`, `bland-sms`, `custom-code`, `slack`, `salesforce`, `rest_api`, `hubspot`, `calendly`, `cal-com-v2`, `notion`.
</ParamField>

<ParamField body="action" type="string">
  The action key to invoke within the integration. To discover available action keys, call `GET /v1/integrations/{integration}/actions`. Returns `400 ACTION_NOT_FOUND` with the list of valid actions if the key is invalid.
</ParamField>

<ParamField body="input_schema" type="object">
  JSON Schema that defines the parameters the AI will fill in when invoking this tool.
</ParamField>

<ParamField body="body" type="string | object">
  Request body template sent to the integration. For `custom-code` tools with the `run_snippet` action, `body.timeout` is in seconds and must be an integer from 1 to 60.
</ParamField>

<ParamField body="speech" type="string">
  Text the AI says aloud while executing this tool.
</ParamField>

<ParamField body="timeout" type="number">
  Maximum time in milliseconds to wait for the integration. Minimum `1000`, maximum `60000`.
</ParamField>

<ParamField body="cache" type="boolean">
  Whether to cache the tool's response.
</ParamField>

<ParamField body="response_data" type="array">
  Defines which fields to extract from the integration response.

  <Expandable title="response_data item">
    <ParamField body="name" type="string" required>
      Variable name to assign the extracted value.
    </ParamField>
    <ParamField body="data" type="string" required>
      JSON path to the value in the response.
    </ParamField>
    <ParamField body="context" type="string">
      Optional description of what this data represents.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="max_retries" type="number">
  Number of times to retry the tool on failure. Minimum `0`, maximum `4`.
</ParamField>

<ParamField body="cooldown" type="number">
  Seconds to wait between retries. Minimum `1`, maximum `30`.
</ParamField>

<ParamField body="resource_id" type="string">
  UUID of a connected resource (e.g. a Slack workspace or Salesforce org) to scope this tool to. The resource must be active and belong to your account. Returns `404` if the ID is invalid or inactive. To list available resource IDs for an integration, call `GET /v1/integrations/{integration}/resources`.
</ParamField>

<ParamField body="extractVarSettings" type="object">
  Controls how the AI extracts the tool's input variables. See [Create Tool](/api-v2/post/tools) for the `useAudio`, `ignorePrevious`, and `audioVariables` fields.
</ParamField>

<ParamField body="public" type="boolean">
  Accepted, but this endpoint does not change the tool's visibility. The value is stored inside the tool definition JSON and the `public` column returned by [List Tools](/api-v2/get/tools) is left unchanged. Set `public` when you create the tool instead.
</ParamField>

<ParamField body="label" type="string">
  Human-readable label for this tool.
</ParamField>

<ParamField body="staging_tool" type="object">
  Replaces the tool's draft definition (the version run with `?staging=true`).
</ParamField>

<ParamField body="agent_id" type="string">
  Accepted and ignored. Agent attribution is set at creation time only.
</ParamField>

<Note>
  Unknown top-level keys are not rejected. They are merged into the stored tool definition, so send only the fields listed above.
</Note>

### Response

Returns `200` with the updated tool's ID.

<ResponseField name="data.id" type="string">
  The UUID of the updated tool.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of `{ error, message }` objects if the request failed.
</ResponseField>

### Errors

| Status | `error` | When |
|---|---|---|
| 400 | `INVALID_PARAMETER` | `tool_id` is not a UUID, or a custom-code timeout is invalid. |
| 400 | `INVALID_TOOL_TYPE` | The tool is a custom HTTP tool, not an integration tool. |
| 400 | `TOOL_V2_UPDATE_VALIDATION_ERROR` | The merged definition fails validation. The message lists each failing path, for example `[/timeout: Expected number to be less or equal to 60000]`. |
| 400 | `INTEGRATION_NOT_FOUND` | The merged `integration` is not registered. |
| 400 | `ACTION_NOT_FOUND` | The merged `action` does not exist for the integration. |
| 404 | `TOOL_NOT_FOUND` | No tool with that ID belongs to your account. |
| 404 | `RESOURCE_NOT_FOUND` | The new `resource_id` is unknown, inactive, or not yours. |
| 500 | `UPDATE_INTERNAL_SERVER_ERROR` | Unexpected server error. |
