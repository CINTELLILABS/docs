---
title: "Create Tool"
api: "POST https://api.bland.ai/v2/tools"
description: "Create a new tool. Tools connect to built-in integrations (e.g. Slack, OpenAPI) and are invoked automatically by your agent during calls and SMS conversations."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body Parameters

<ParamField body="name" type="string" required>
  The name the AI will see when deciding to use this tool. Must be at least 1 character.

  The name must not contain any of these reserved words, even as a substring of a longer word (the check is case-insensitive, so `DisplayOrder` is rejected because it contains `play`): `input`, `speak`, `transfer`, `switch`, `wait`, `finish`, `press`, `button`, `say`, `pause`, `record`, `play`, `dial`, `hang`. Returns `400 RESERVED_TOOL_NAME`.
</ParamField>

<ParamField body="description" type="string" required>
  Description of what the tool does. Shown to the AI to help it decide when to use this tool. Maximum 5000 characters.
</ParamField>

<ParamField body="integration" type="string" required>
  The integration key to use. Must be one of: `bland`, `bland-sms`, `custom-code`, `slack`, `salesforce`, `rest_api`, `hubspot`, `calendly`, `cal-com-v2`, `notion`. Call `GET /v1/integrations` for the current list. Returns `400 INTEGRATION_NOT_FOUND` if the key is not registered.

  This endpoint only creates integration tools. Custom HTTP tools (a `url` plus `method` and `headers`) are created with the legacy [Create Custom Tool](/api-v1/post/tools) endpoint. Sending those keys here returns `400 INVALID_PARAMETER`.
</ParamField>

<ParamField body="action" type="string" required>
  The action key to invoke within the integration. To discover available action keys, call `GET /v1/integrations/{integration}/actions`. Returns `400 ACTION_NOT_FOUND` with the list of valid actions if the key is invalid.
</ParamField>

<ParamField body="input_schema" type="object">
  Must be a valid JSON Schema (validated with AJV in strict mode). Defines the parameters the AI will fill in when invoking this tool. Returns `400 INVALID_INPUT_SCHEMA` if the schema does not compile.

  ```json
  {
    "type": "object",
    "properties": {
      "channel": { "type": "string" },
      "message": { "type": "string" }
    },
    "required": ["channel", "message"]
  }
  ```
</ParamField>

<ParamField body="body" type="string | object">
  Request body template sent to the integration. Supports prompt variables from `input_schema` (e.g. `"{{input.channel}}"`).

  For `custom-code` tools with the `run_snippet` action, `body.timeout` is the snippet timeout in seconds and must be an integer from 1 to 60. Returns `400 INVALID_PARAMETER` otherwise.
</ParamField>

<ParamField body="speech" type="string">
  Text the AI says aloud while executing this tool (e.g. `"One moment while I send that message."`).
</ParamField>

<ParamField body="timeout" type="number">
  Maximum time in milliseconds to wait for the integration to respond. Minimum `1000`, maximum `60000`.
</ParamField>

<ParamField body="cache" type="boolean">
  Whether to cache the tool's response. Accepts `true`, `false`, `"true"`, or `"false"`.
</ParamField>

<ParamField body="response_data" type="array">
  Defines which fields to extract from the integration response and make available as prompt variables.

  <Expandable title="response_data item">
    <ParamField body="name" type="string" required>
      Variable name to assign the extracted value.
    </ParamField>
    <ParamField body="data" type="string" required>
      JSON path to the value in the response (e.g. `"$.message_id"`).
    </ParamField>
    <ParamField body="context" type="string">
      Optional description of what this data represents.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="max_retries" type="number">
  Number of times to retry the tool on failure. Minimum `0`, maximum `4`.
</ParamField>

<ParamField body="cooldown" type="number">
  Seconds to wait between retries. Minimum `1`, maximum `30`.
</ParamField>

<ParamField body="resource_id" type="string">
  UUID of a connected resource (e.g. a Slack workspace or Salesforce org) to scope this tool to. The resource must be active and belong to your account. Returns `404` if the ID is invalid or inactive. To list available resource IDs for an integration, call `GET /v1/integrations/{integration}/resources`.
</ParamField>

<ParamField body="extractVarSettings" type="object">
  Controls how the AI extracts the tool's input variables.

  <Expandable title="extractVarSettings">
    <ParamField body="useAudio" type="boolean">
      Extract variables from the call audio instead of the transcript.
    </ParamField>
    <ParamField body="ignorePrevious" type="boolean">
      Ignore values extracted earlier in the conversation.
    </ParamField>
    <ParamField body="audioVariables" type="string[]">
      Names of `input_schema` properties to extract from audio.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="public" type="boolean">
  Whether this tool is publicly visible. Defaults to `false`.
</ParamField>

<ParamField body="label" type="string">
  Optional human-readable label for this tool.
</ParamField>

<ParamField body="staging_tool" type="object">
  A draft version of the tool definition (same fields as the tool itself: `name`, `description`, `integration`, `action`, and the optional fields above). Stored beside the live definition and used when you run the tool with `?staging=true`.
</ParamField>

<ParamField body="agent_id" type="string">
  UUID of the agent this tool belongs to. Omit for an org-wide tool. Returns `400 INVALID_PARAMETER` if the value is not a UUID.
</ParamField>

<Note>
  The body is validated strictly. Any key not listed above returns `400 INVALID_PARAMETER`.
</Note>

### Response

Returns `200` with the new tool's ID.

<ResponseField name="data.id" type="string">
  The ID of the newly created tool (a UUID, without the `TL-` prefix).
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of `{ error, message }` objects if the request failed.
</ResponseField>

### Errors

All errors return `data: null`. Each entry in `errors` has an `error` code and a `message`.

| Status | `error` | When |
|---|---|---|
| 400 | `INVALID_PARAMETER` | Body fails schema validation (unknown key, wrong type, out of range value, malformed `agent_id`, or bad custom-code timeout). |
| 400 | `MISSING_REQUIRED_FIELDS` | `name`, `description`, `integration`, or `action` is missing. |
| 400 | `RESERVED_TOOL_NAME` | `name` contains a reserved word. |
| 400 | `INVALID_INPUT_SCHEMA` | `input_schema` is not a valid JSON Schema. |
| 400 | `INTEGRATION_NOT_FOUND` | `integration` is not registered. |
| 400 | `ACTION_NOT_FOUND` | `action` does not exist for the integration. |
| 400 | `TOOL_V2_CREATE_VALIDATION_ERROR` | The assembled tool definition fails validation. |
| 404 | `RESOURCE_NOT_FOUND` | `resource_id` is unknown, inactive, or not yours. |
| 500 | `CREATE_INTERNAL_SERVER_ERROR` | Unexpected server error. |
