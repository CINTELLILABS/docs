---
title: "List Batches"
api: "GET https://api.bland.ai/v2/batches/list"
description: "Retrieve a list of all batches created by your organization."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="take" type="integer" default="10">
  Number of batches to return. Clamped to the range 1 to 100.
</ParamField>

<ParamField query="skip" type="integer">
  Number of batches to skip (used for pagination).
</ParamField>

<ParamField query="agent_id" type="string">
  Only return batches created with this `global.agent_id`. Must be a UUID, otherwise the request fails with `BATCH_V2_LIST_VALIDATION_ERROR`.
</ParamField>

### Response

Batches are returned newest first. Each entry is the stored batch row.

<ResponseField name="data" type="array">
  A list of batches created by your organization.
</ResponseField>

<ResponseField name="data[].id" type="string">
  The unique identifier of the batch.
</ResponseField>

<ResponseField name="data[].user_id" type="string">
  The ID of the org that created the batch.
</ResponseField>

<ResponseField name="data[].base_prompt" type="string">
  A JSON string of the `global` object the batch was created with.
</ResponseField>

<ResponseField name="data[].created_at" type="string (ISO 8601)">
  The timestamp when the batch was created.
</ResponseField>

<ResponseField name="data[].call_objects" type="array | null">
  The full `call_objects` array the batch was created with. `null` for batches created from a `file_id`.
</ResponseField>

<ResponseField name="data[].description" type="string">
  A human-readable description of the batch.
</ResponseField>

<ResponseField name="data[].batch_status" type="string | object">
  `"initializing"` until the batch starts dispatching, then an object with `calls_requested`, `calls_in_progress`, `calls_completed`, `calls_failed`, and `calls_failed_errors`.
</ResponseField>

<ResponseField name="data[].calls_in_retry" type="array">
  Call IDs currently being retried.
</ResponseField>

<ResponseField name="data[].label" type="string | null">
  A JSON string of the `column_mapping` used for file batches, otherwise `null`.
</ResponseField>

<ResponseField name="data[].agent_id" type="string | null">
  The `global.agent_id` the batch was created with, if any.
</ResponseField>

<ResponseField name="data[].campaign_id" type="string | null">
  Always `null` for batches created through this API.
</ResponseField>

<ResponseField name="data[].call_params" type="string | null">
  Unused by v2 batches. Always `null`.
</ResponseField>

<ResponseField name="data[].call_data" type="string | null">
  Unused by v2 batches. Always `null`.
</ResponseField>

<ResponseField name="data[].endpoint_code" type="string">
  Always `"api"`.
</ResponseField>

<ResponseField name="errors" type="null">
  Always `null` on success.
</ResponseField>

### Errors

| Status | `error` | When |
| --- | --- | --- |
| 400 | `BATCH_V2_LIST_VALIDATION_ERROR` | `agent_id` is not a valid UUID |
| 500 | `BATCH_V2_LIST_ERROR` | Unexpected failure |

<RequestExample>

```bash cURL

  -H "authorization: YOUR_API_KEY"
```
