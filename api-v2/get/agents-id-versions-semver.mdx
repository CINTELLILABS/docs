---
title: "Get Agent Version"
api: "GET https://api.bland.ai/v2/agents/{agent_id}/versions/{semver}"
description: "Retrieve a published version by its semantic version."
---

### Overview

Returns the full snapshot of a version that has been published, resolved by the semantic version minted at publish time (for example `1.2.0`). Versions that were saved but never published have no semver; read those with [Get Latest Agent Version](/api-v2/get/agents-id-versions-latest). Find semvers with [List Agent Versions](/api-v2/get/agents-id-versions) or [List Agent Deployments](/api-v2/get/agents-id-deployments).

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="x-bland-include-snippets" type="string">
  Send `true` to include `snippets`, the code of every custom code snippet the version runs. Required for a full API key. A dashboard session gets `snippets` without it. Restricted API keys, OAuth client tokens, and requests made by the hosted MCP or Norm never receive `snippets`, with or without this header.
</ParamField>

### Path Parameters

<ParamField path="agent_id" type="string" required>
  The agent's unique identifier.
</ParamField>

<ParamField path="semver" type="string" required>
  The version's semantic version in strict `MAJOR.MINOR.PATCH` form with numeric components, for example `1.2.0`. No `v` prefix and no prerelease or build suffix. Any other format returns `400 INVALID_VERSION`. A well-formed semver that was never minted for this agent returns `404 NOT_FOUND`.
</ParamField>

### Query Parameters

<ParamField query="include_snippets" type="string">
  Send `false` to leave out `snippets` even when the caller would receive them.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The published version, with its snapshot.

  <Expandable title="version object">
    <ResponseField name="id" type="string">
      Unique identifier for the version.
    </ResponseField>
    <ResponseField name="org_id" type="string">
      The organization that owns the agent.
    </ResponseField>
    <ResponseField name="agent_id" type="string">
      The agent this version belongs to.
    </ResponseField>
    <ResponseField name="branch_id" type="string | null">
      The branch the version was saved onto, or `null` on the dev timeline.
    </ResponseField>
    <ResponseField name="snapshot" type="object">
      The saved configuration: `behavior` (the node and edge graph), `settings` (agent-wide options), `contact` (`inboundNumbers`), and `knowledge` (`kbIds`) when present.
    </ResponseField>
    <ResponseField name="name" type="string | null">
      The version's display name, or `null` if none was given.
    </ResponseField>
    <ResponseField name="created_via" type="string">
      `manual` or `autosave`.
    </ResponseField>
    <ResponseField name="revision" type="integer">
      Number of times an autosave rewrote this row in place before it was published.
    </ResponseField>
    <ResponseField name="created_by" type="string | null">
      ID of the user who saved the version. With an API key, this is the user the key belongs to. `null` when no user was recorded.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of the save.
    </ResponseField>
<ResponseField name="snippets" type="array">
      The code of every custom code snippet the version runs: snippets that custom code tools, chain steps, Custom Code steps, and the Initialization step point at, and snippets that library tools used by reference point at. One entry per distinct snippet and version. Present only when the caller receives snippets (see `x-bland-include-snippets`).

      <Expandable title="snippet object">
        <ResponseField name="snippet_id" type="string">
          The snippet's unique identifier.
        </ResponseField>
        <ResponseField name="version" type="integer | null">
          The pinned snippet version, or the latest version when the pointer is not pinned. `null` on an unresolved entry whose pointer is not pinned.
        </ResponseField>
        <ResponseField name="resolved" type="boolean">
          `true` when `content` holds the code. `false` when it does not.
        </ResponseField>
        <ResponseField name="display_name" type="string">
          The snippet's name. Present when `resolved` is `true`.
        </ResponseField>
        <ResponseField name="language" type="string">
          The snippet's language, for example `js`. Present when `resolved` is `true`.
        </ResponseField>
        <ResponseField name="content" type="string">
          The snippet's source code. Present when `resolved` is `true`.
        </ResponseField>
        <ResponseField name="reason" type="string">
          Why an entry has no code. `unavailable`: your organization has no such snippet version. `limit`: a read limit was reached before this snippet. Present when `resolved` is `false`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="snippets_complete" type="boolean">
      `false` when a read limit was reached, so `snippets` is a partial export: some entries have `reason: "limit"`, or library tools past the limit were not read. A single read follows up to 3 levels of library tools that reference other library tools, reads up to 50 library tools, and returns code for up to 50 snippets. Present with `snippets`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of error objects if the request failed.
</ResponseField>
