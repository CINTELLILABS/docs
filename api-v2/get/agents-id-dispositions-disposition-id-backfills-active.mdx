api: "GET https://api.bland.ai/v2/agents/{agent_id}/dispositions/{disposition_id}/backfills/active"
description: "Find the queued or running backfill for a disposition version without its job ID, so you can resume progress tracking or cancel it."
---

### Overview

<Note>
Dispositions are enabled per organization. If your organization does not have access, these endpoints return `404`.
</Note>

Returns the `queued` or `running` backfill for a disposition version. Use it when you don't have the backfill's `id`, for example after a page refresh or when you come back later. It checks the published version by default. Only one backfill per version can be active at a time, so this endpoint returns at most one.

`data` is `null` when no backfill is active. It is also `null` when the disposition has never been published and you don't pass `versionId`.

After you republish, the default lookup checks the new published version. A backfill of an older version can still be running. Pass that version's `versionId` to find it.

Use the returned `id` with [Get Disposition Backfill](/api-v2/get/agents-id-dispositions-disposition-id-backfills-job-id) to poll progress or [Cancel Disposition Backfill](/api-v2/post/agents-id-dispositions-disposition-id-backfills-job-id-cancel) to stop it.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="agent_id" type="string" required>
  The agent's unique identifier. Must be a UUID; otherwise returns `400` with the message `agentId must be a valid UUID`. Returns `404 Agent not found` if the agent is not in your organization.
</ParamField>

<ParamField path="disposition_id" type="string" required>
  The disposition's unique identifier. Must be a UUID; otherwise returns `400` with the message `dispositionId must be a valid UUID`. Returns `404 Disposition not found` if it does not belong to this agent.
</ParamField>

### Query Parameters

<ParamField query="versionId" type="string">
  The disposition version to check. Defaults to the published version. Must be a UUID; otherwise returns `400` with the message `versionId must be a valid UUID`. Returns `404 Disposition version not found` if the version doesn't belong to this disposition. Returns `400` with the message `Only a published or archived version can have a backfill` for the draft.
</ParamField>

### Response

<ResponseField name="data" type="object | null">
  The active backfill, or `null` if none is queued or running. See [Get Disposition Backfill](/api-v2/get/agents-id-dispositions-disposition-id-backfills-job-id) for every field.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of error objects if the request failed.
</ResponseField>

<RequestExample>
```bash cURL
curl https://api.bland.ai/v2/agents/{agent_id}/dispositions/{disposition_id}/backfills/active \
  -H "authorization: YOUR_API_KEY"
```
</RequestExample>
