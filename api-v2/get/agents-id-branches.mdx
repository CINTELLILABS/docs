---
title: "List Agent Branches"
api: "GET https://api.bland.ai/v2/agents/{agent_id}/branches"
description: "List an agent's open branches."
---

### Overview

Returns the agent's open branches (not yet merged or deleted), oldest first. A branch is a dev workspace cut from the dev head; `behind` tells you whether dev has moved past the branch's base since it was cut. Create one with [Create Agent Branch](/api-v2/post/agents-id-branches) and land it with [Merge Agent Branch](/api-v2/post/agents-id-branches-branch-id-merge).

Set `include_closed=true` to read merged and deleted branches instead of open branches. Closed history is paged and ordered by merge or deletion time, newest first, with branch ID as the tie-breaker. Closed branches are read-only.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="agent_id" type="string" required>
  The agent's unique identifier.
</ParamField>

### Query Parameters

<ParamField query="include_closed" type="boolean" default="false">
  Set to `true` to return only merged or deleted branches. Without it, you receive the unchanged open-branch list.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Closed-history page size, from `1` to `50`. Invalid values return `400 INVALID_PAGINATION`, even when `include_closed` is not set.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of closed-history rows to skip. Must be a non-negative safe integer. Invalid values return `400 INVALID_PAGINATION`, even when `include_closed` is not set. Pagination does not change the open-branch list.
</ParamField>

### Response

<ResponseField name="data" type="array">
  Open branches ordered by `created_at` ascending, or a closed-history page ordered by closure time descending. Empty when there are no matching branches.

  <Expandable title="branch object">
    <ResponseField name="id" type="string">
      Unique identifier for the branch.
    </ResponseField>
    <ResponseField name="agent_id" type="string">
      The agent the branch belongs to.
    </ResponseField>
    <ResponseField name="name" type="string">
      The branch name.
    </ResponseField>
    <ResponseField name="base_version_id" type="string | null">
      The dev version the branch was cut from, or last rebased onto. `null` when the branch was cut from an agent with no saved versions.
    </ResponseField>
    <ResponseField name="created_by" type="string | null">
      ID of the user who created the branch. With an API key, this is the user the key belongs to. `null` when no user was recorded.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of creation.
    </ResponseField>
    <ResponseField name="merged_at" type="string | null">
      ISO 8601 merge timestamp. `null` on branches that have not merged.
    </ResponseField>
    <ResponseField name="merged_by" type="string | null">
      ID of the user who merged the branch. `null` when no user was recorded or the merge predates attribution.
    </ResponseField>
    <ResponseField name="deleted_at" type="string | null">
      ISO 8601 deletion timestamp. `null` on branches that have not been deleted.
    </ResponseField>
    <ResponseField name="behind" type="boolean">
      `true` when dev's newest version is no longer an open branch's base. A merge returns `409 BRANCH_BEHIND` until the branch is rebased. Always `false` for closed branches.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of error objects if the request failed.
</ResponseField>
