Welcome to Bland! I'm sure you're excited to build your first agent. Great news — you can hear your agent talk in about a minute, before you buy a phone number or set anything up.

The dashboard walks you through it. A checklist headed **Let's get this agent talking** sits on your dashboard and tracks four steps, moving to the agent's own page once you have one.

## What you start with

When you log into your new workspace, you'll notice it already contains an example agent called "Norma." She's there as an example: an agent to look at, not to build on. and the checklist ignores her: until you make an agent of your own, you are on step one.

## Create your agent

**New agent** opens a short choice.

**Blank agent** starts from nothing, which is what you want here. The other options import an existing V1 pathway or persona, covered in [Migrate to agents](/platform/migrate-to-agents).

Give it a name and a job, then **Create agent**.

## Talk to it

This is the step people expect to be harder than it is. Your agent can talk now, with no phone number involved.

Two ways, both on the checklist:

- **Talk in browser** uses your computer's microphone. It asks for permission, then listens.
- **Call me** rings a number you type into **Your phone number**.

Either one puts you in a real conversation with what you just built. Say something it should handle, and something it should not.

<Note>
Nothing you do here needs a phone number, a plan or a purchase. Buying a number is for letting *other people* reach the agent, which is a later step and not part of getting started.
</Note>

## Promote it to production

<Warning>
An agent that has not been promoted to production cannot take a call from anyone else.

This is the single most common reason a new agent does not answer. Building it, saving it and talking to it in the browser all leave it unpublished.
</Warning>

The checklist's third step walks you through it. What it is doing is moving your work into the **production** environment, which is the version real calls run.

[Environments](/agents/environments) covers what that means and how to undo it.

## See what happened

The last step opens the conversation you just had.

You get the transcript, what the agent decided at each turn, and the recording. This is the same view you will use for every call the agent takes afterwards, so it is worth looking around now while you know exactly what happened and why.

## Then give it a number

Once the agent answers you properly, [Dispatch](/agents/dispatch) is where you attach a phone number so other people can reach it.

## Common failures

<AccordionGroup>
  <Accordion title="I called the number and nothing answered">
    The agent is not in production. Talking in the browser does not publish it, and neither does saving. Finish the promote step.
  </Accordion>

  <Accordion title="Talk in browser does nothing">
    Your browser is blocking the microphone. The control waits on that permission and cannot prompt twice, so allow it in the address bar and press the button again.
  </Accordion>

  <Accordion title="The checklist vanished">
    It disappears once all four steps are done. It also lives on the agent's own page rather than the dashboard once you have created an agent, so check there.
  </Accordion>

  <Accordion title="Norma is answering instead of my agent">
    Norma is the example agent that ships with a new workspace. She is a separate agent; pick yours from the agent list.
  </Accordion>
</AccordionGroup>
