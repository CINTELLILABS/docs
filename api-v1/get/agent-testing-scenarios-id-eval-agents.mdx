---
title: "List Scenario Eval Agents"
api: "GET https://api.bland.ai/v1/agent-testing/scenarios/{id}/eval-agents"
description: "List the eval agents attached to a test scenario."
---

Returns the eval agents used to score simulations for a scenario, ordered by `order` and then attachment time.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The scenario ID.
</ParamField>

## Response

<ResponseField name="data" type="array">
  Attached eval agents. Each item contains `id`, `scenario_id`, `eval_agent_id`, `eval_agent_version_id`, `weight`, `target_level_keys`, `order`, and `created_at`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 404 if the scenario does not exist or belongs to another organization.
</ResponseField>
