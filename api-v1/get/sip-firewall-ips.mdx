---
title: "Get Firewall IPs"
api: "GET https://api.bland.ai/v1/sip/firewall-ips"
description: "Get Bland's static SIP signaling and media IP addresses and ports for your region. Use these to configure your firewall and SBC."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="ip_addresses" type="string[]">
  Array of static IP addresses for your region: the two signaling IPs first, then the four media IPs. Allow-list all of them and trust all of them as SIP peers. Calls you send to Bland go to the signaling IPs. Transfers and warm transfer consult calls that Bland sends to your SBC connect from the signaling IPs. See [Connection Endpoints](/enterprise-features/SIP-integration#connection-endpoints).
</ResponseField>

<ResponseField name="ports.sip" type="string">
  SIP signaling port and transport (e.g., `"5061 TLS"`).
</ResponseField>

<ResponseField name="ports.rtp" type="string">
  RTP media port range (e.g., `"16384-32768 UDP"`).
</ResponseField>

```json Example Request
curl -X GET https://api.bland.ai/v1/sip/firewall-ips \
  -H "Authorization: Bearer <token>"
```
