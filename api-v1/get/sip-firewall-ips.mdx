---
title: "Get Firewall IPs"
api: "GET https://api.bland.ai/v1/sip/firewall-ips"
description: "Get Bland's static IP addresses and ports for your region. Use these to configure your firewall."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="ip_addresses" type="string[]">
  Static IP addresses for the region serving your request: two signaling addresses (SIP over TLS) and four media addresses (SRTP/RTP). Allow all of them.
</ResponseField>

<ResponseField name="ports.sip" type="string">
  SIP signaling port and transport: `"5061 TLS"`.
</ResponseField>

<ResponseField name="ports.rtp" type="string">
  Media port range: `"16384-32768 UDP"`.
</ResponseField>

```bash Example Request
curl -X GET https://api.bland.ai/v1/sip/firewall-ips \
  -H "Authorization: Bearer <token>"
```
