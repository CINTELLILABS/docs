---
title: "Custom Tool Details"
api: "GET https://api.bland.ai/v1/tools/{tool_id}"
description: "Retrieve a Custom Tool you've created."
---

<Note>
Custom Tools v1 is a legacy API maintained for existing customers. Built-in integration tools are managed with the [v2 Tools API](/api-v2/get/tools). Custom HTTP tools that call your own URL are still created and read through v1.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters
<ParamField path="tool_id" type="string" required>
    The ID of the tool you want to retrieve, with or without the `TL-` prefix. A value that is not a UUID returns 400 `INVALID_PARAMETER`. A tool that does not exist or belongs to another organization returns 404 `NOT_FOUND`.
</ParamField>

### Response

<ResponseField name="status" type="string">
    Whether the request succeeded or failed.
</ResponseField>

<ResponseField name="tool" type="object">
    The tool record: `tool_id` (prefixed `TL-`), `label`, `tool` (the definition object), `public`, `user_id`, `resource_id`, `is_active`, `is_draft`, `staging_tool`, `agent_id`, and `created_at`.
</ResponseField>

<ResponseField name="data" type="null">
    Always `null` on this endpoint.
</ResponseField>

<ResponseField name="errors" type="null">
    `null` on success.
</ResponseField>
