---
title: "Check Number Portability"
api: "GET https://api.bland.ai/v1/sip/port/check"
description: "Check whether phone numbers are eligible for porting to Bland."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="phone_numbers" type="string[]" required>
  One or more phone numbers to check, as repeated `phone_numbers[]` parameters. Each is normalized to E.164.
</ParamField>

### Response

<ResponseField name="results" type="array">
  One result per number, in request order:
  - `number` (string): the normalized number, or the raw input when it could not be parsed
  - `portable` (boolean): whether the number can be ported
  - `number_type` (string): the carrier's classification of the number, when available
  - `pin_required` (boolean): present and `true` only when the losing carrier requires an account PIN. Supply it via `phone_number_pins` on [Initiate Port Request](/api-v1/post/sip-port-initiate).
  - `not_portable_reason` (string): present when `portable` is `false`. `"Invalid phone number format"` and `"Portability check failed"` are returned by Bland; other values come from the carrier.
</ResponseField>

### Error Responses

<ResponseField name="400 BAD_REQUEST" type="object">
  `phone_numbers[]` is missing.
</ResponseField>

```bash Example Request
curl -X GET 'https://api.bland.ai/v1/sip/port/check?phone_numbers[]=%2B14150000000&phone_numbers[]=%2B14150000001' \
  -H "Authorization: Bearer <token>"
```
