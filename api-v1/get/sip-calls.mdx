---
title: "Get SIP Call Logs"
api: "GET https://api.bland.ai/v1/sip/calls"
description: "Retrieve SIP call logs for a phone number with cursor-based pagination."
---

Call logs are reconstructed from SIP signaling records: one entry per INVITE, paired with its BYE when one was seen.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="phone_number" type="string" required>
  The number or SIP identity to fetch logs for. Phone-like input is normalized to E.164. Non-numeric identities (for example `bland-test-001`) are matched verbatim.
</ParamField>

<ParamField query="limit" type="number">
  Maximum number of calls to return. Default: 100. Maximum: 500.
</ParamField>

<ParamField query="before" type="string">
  ISO 8601 timestamp. Only calls with signaling before this time are returned. Pass the `start_time` of the last call from the previous page to fetch the next page. Unparseable values are ignored.
</ParamField>

### Response

<ResponseField name="calls" type="array">
  Newest first. Each entry includes:
  - `callid` (string): the SIP Call-ID.
  - `direction` (string): `"inbound"` or `"outbound"`, relative to the queried number.
  - `start_time` (string): ISO 8601 timestamp of the INVITE.
  - `end_time` (string): ISO 8601 timestamp of the BYE, or `null` if none was recorded.
  - `duration_s` (number): seconds between `start_time` and `end_time`, or `null`.
  - `from_uri` (string), `to_uri` (string): full SIP URIs from the INVITE.
  - `from_user` (string), `to_user` (string): the user parts of those URIs.
  - `connect_code` (string): the final SIP response code to the INVITE, as a string (for example `"200"`).
  - `connect_reason` (string): the SIP reason phrase (for example `"OK"`).
  - `src_ip` (string): source IP address of the INVITE.
</ResponseField>

### Error Responses

<ResponseField name="400 INVALID_PARAMETER" type="object">
  `phone_number` is missing or empty.
</ResponseField>

<ResponseField name="404 NOT_FOUND" type="object">
  The number has no SIP configuration in your organization.
</ResponseField>

```bash Example Request
curl -X GET 'https://api.bland.ai/v1/sip/calls?phone_number=%2B14150000000&limit=10' \
  -H "Authorization: Bearer <token>"
```
