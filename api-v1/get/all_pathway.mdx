---
title: "Get All Pathways Information"
api: "GET https://api.bland.ai/v1/pathway"
description: "Returns summary information about every conversational pathway in your account: id, name, description, folder, and production version."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

Returns a JSON array of pathway summaries, newest first. Nodes and edges are not included. Use [Get Single Pathway Information](/api-v1/get/pathway) to fetch a pathway's nodes and edges.

<ResponseField name="id" type="string">
  The unique identifier of the pathway.
</ResponseField>

<ResponseField name="name" type="string">
  The name of the conversational pathway.
</ResponseField>

<ResponseField name="description" type="string | null">
  A description of the conversational pathway.
</ResponseField>

<ResponseField name="published_at" type="string | null">
  ISO 8601 timestamp of the most recent production publish, or `null` if the pathway has never been published.
</ResponseField>

<ResponseField name="folder_name" type="string | undefined">
  The name of the folder the pathway lives in. Omitted for pathways at the root level.
</ResponseField>

<ResponseField name="production_version_number" type="integer | null">
  The version number currently published to production, or `null` if none.
</ResponseField>

### Errors

| Status | Body |
|---|---|
| `400` | `{"status": "error", "message": "Error fetching convo pathways"}` |
