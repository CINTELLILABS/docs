---
title: "Get Test Analytics"
api: "GET https://api.bland.ai/v1/agent-testing/analytics/{pathwayId}"
description: "Get basic testing analytics for a pathway over a time window."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="pathwayId" type="string" required>
  The pathway ID (UUID v4).
</ParamField>

### Query Parameters

<ParamField query="days" type="integer" default="30">
  Number of days to look back. Clamped to the range 1 to 365.
</ParamField>

### Response

Only runs with status `PASSED` or `FAILED` in the window are counted. Runs still in progress or in `ERROR` are excluded.

<ResponseField name="data" type="object">
  <Expandable title="data object">
    <ResponseField name="total_runs" type="integer">
      Number of completed test runs in the time window.
    </ResponseField>
    <ResponseField name="passed" type="integer">
      Number of test runs that passed.
    </ResponseField>
    <ResponseField name="failed" type="integer">
      Number of test runs that failed.
    </ResponseField>
    <ResponseField name="pass_rate" type="number">
      Pass rate as a decimal from 0 to 1.
    </ResponseField>
    <ResponseField name="avg_score" type="number">
      Average `overall_score` across all runs, from 0 to 1.
    </ResponseField>
    <ResponseField name="runs" type="array">
      The runs that were counted, oldest first. Each entry contains `id`, `status`, `overall_score`, `created_at`, `nodes_visited`, `bland_tone_score`, `metadata`, `scenario` (`name`, `category`), and `assertion_results` (each with `status` and `assertion` containing `name` and `type`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="array">
  `null` on success.
</ResponseField>
