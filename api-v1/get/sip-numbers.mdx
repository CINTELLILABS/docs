---
title: "List SIP Numbers"
api: "GET https://api.bland.ai/v1/sip/numbers"
description: "List all phone numbers with SIP configurations for your organization."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="data.numbers" type="array">
  One summary per configured number or SIP identity, most recently configured first:
  - `phone_number` (string): the number as stored (E.164, DID, or extension)
  - `directions` (string[]): configured directions, `"inbound"` and/or `"outbound"`
  - `sip_endpoint` (string): the configured endpoint, or `null`. When both directions set one, the inbound endpoint is shown.
  - `configured_at` (string): ISO 8601 timestamp of the first direction configured
</ResponseField>

For health, use [Get Trunk Health](/api-v1/get/sip-status) per number.

```bash Example Request
curl -X GET https://api.bland.ai/v1/sip/numbers \
  -H "Authorization: Bearer <token>"
```
