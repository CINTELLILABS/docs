---

### Overview

Returns whether [traffic split from v1](/api-v1/put/pathway-migration-split) is currently available for your organization. When `enabled` is `false`, [Set Traffic Split from v1](/api-v1/put/pathway-migration-split) rejects new splits with `FEATURE_NOT_ENABLED`. Rollback with [Delete Traffic Split from v1](/api-v1/delete/pathway-migration-split) always works, so any existing split can still be removed.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="enabled" type="boolean">
  `true` when your organization can configure a traffic split, `false` otherwise.
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.bland.ai/v1/convo_pathway/migration_split/enabled' \
  --header 'authorization: Bearer YOUR_API_KEY'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "enabled": true
}
```

</ResponseExample>
