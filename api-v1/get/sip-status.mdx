---
title: "Get Trunk Health"
api: "GET https://api.bland.ai/v1/sip/status"
description: "Get the health status of a SIP trunk by probing the endpoint with SIP OPTIONS."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="phone_number" type="string" required>
  The phone number to check health for. Accepts E.164 phone numbers, DIDs, and
  extensions attached to a trunk.
</ParamField>

### Response

The response is under `data`. This endpoint checks per-number SIP configuration and probes an outbound endpoint with SIP OPTIONS over TLS. Inbound-only numbers are not probed.

<ResponseField name="configured" type="boolean">
  Whether the number has an inbound or outbound SIP configuration. An
  unconfigured number returns `configured: false` and `health: "unconfigured"`.
</ResponseField>

<ResponseField name="health" type="string">
  `healthy`, `unreachable`, `unchecked`, `mutual_tls`, or `unconfigured`.
  `mutual_tls` means the endpoint requested a client certificate instead of
  replying to OPTIONS; it is distinct from unreachable.
</ResponseField>

<ResponseField name="inbound" type="object">
  Configured inbound endpoint and `active` flag, or `null`. Omitted when
  unconfigured.
</ResponseField>

<ResponseField name="outbound" type="object">
  Configured outbound endpoint and `active` flag, or `null`. Omitted when
  unconfigured.
</ResponseField>

<ResponseField name="uptime_percent" type="number">
  Currently `null`; this endpoint does not calculate continuous uptime.
</ResponseField>

<ResponseField name="avg_response_ms" type="number">
  Response time of this probe in milliseconds, or `null` when no timing is
  available.
</ResponseField>

<ResponseField name="last_checked" type="string">
  ISO 8601 timestamp for the check. Omitted when unconfigured.
</ResponseField>

```bash Example request
curl -X GET 'https://api.bland.ai/v1/sip/status?phone_number=%2B14150000000' \
  -H "Authorization: Bearer <token>"
```
