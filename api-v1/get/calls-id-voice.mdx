---
title: "Get Call Voice"
api: "GET https://api.bland.ai/v1/calls/{call_id}/voice"
description: "Retrieve the sanitized voice configuration used by a call."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="call_id" type="string" required>
  The unique identifier for the call.
</ParamField>

### Response

<ResponseField name="status" type="string">
  `success` when the voice is returned.
</ResponseField>

<ResponseField name="message" type="string">
  Confirms the voice was fetched for the call.
</ResponseField>

<ResponseField name="voice" type="object">
  The public voice configuration used by the call. Sensitive voice properties are removed.
</ResponseField>

If the call has no accessible voice, the endpoint returns `404` with `error` and `message` set to `Voice not found`. Unexpected failures return `500`.
