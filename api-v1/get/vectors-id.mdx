---
title: "Get Knowledge Base Details"
api: "GET https://api.bland.ai/v1/knowledgebases/{vector_id}"
description: "View the details for a specific knowledge base."
---

<Warning>
This endpoint belongs to the legacy Vector Knowledge Bases API. It is maintained for existing customers only. Use the current [Knowledge Bases API](/api-v1/get/knowledge-id) for new work.
</Warning>

This route proxies to the legacy knowledge base service. Any upstream failure, including an unknown `vector_id`, returns a 500 with `errors[].error` set to `KB_GET_SINGLE_EMBEDDING_FAILURE`.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="include-text" type="boolean" default="false">
    Include the full text of the documents stored in the knowledge base. This can be useful for debugging, but may return large amounts of data. `include_text` is accepted as an alias.
</ParamField>

### Path Parameters

<ParamField path="vector_id" type="string" required>
    The `vector_id` of the knowledge base to view.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.vector_id" type="string">
      The unique identifier for the knowledge base.
  </ResponseField>

  <ResponseField name="data.name" type="string">
      The name of the knowledge base.
  </ResponseField>

  <ResponseField name="data.description" type="string">
      A description of the knowledge base.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  `null` on success.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": {
    "vector_id": "KB-55e64dae-1585-4632-ae97-c909c288c6bc",
    "name": "Bland AI FAQs",
    "description": "Business facts, policies, and frequently asked questions for Bland AI."
  },
  "errors": null
}
```
</ResponseExample>
