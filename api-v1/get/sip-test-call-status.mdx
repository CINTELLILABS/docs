---
title: "Get Test Call Status"
api: "GET https://api.bland.ai/v1/sip/test-call/status"
description: "Poll the status and trace of a SIP test call."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="call_id" type="string" required>
  The `call_id` returned from [Send SIP Test Call](/api-v1/post/sip-test-call). Test call records are kept for one hour.
</ParamField>

### Response

<ResponseField name="status" type="string">
  Raw carrier call status: `"queued"`, `"initiated"`, `"ringing"`, `"in-progress"`, `"completed"`, `"failed"`, `"busy"`, `"no-answer"`, or `"canceled"`.
</ResponseField>

<ResponseField name="result" type="string">
  Normalized outcome: `"completed"`, `"failed"`, `"busy"`, `"no-answer"`, `"in-progress"`, `"ringing"`, `"queued"`, `"canceled"`, or `"unknown"`. A `"failed"` status with talk time is reported as `"completed"`, since the call connected.
</ResponseField>

<ResponseField name="duration_seconds" type="number">
  Call duration in seconds, or `null` until the call ends.
</ResponseField>

<ResponseField name="timeline" type="array">
  Status events for the call, each with `event` (string) and `at` (timestamp).
</ResponseField>

### Error Responses

<ResponseField name="400 BAD_REQUEST" type="object">
  `call_id` is missing.
</ResponseField>

<ResponseField name="403 SIP_TEST_CALL_STATUS_FAILED" type="object">
  The `call_id` is unknown, expired, or belongs to another organization, or the carrier lookup failed.
</ResponseField>

```bash Example Request
curl -X GET 'https://api.bland.ai/v1/sip/test-call/status?call_id=2f9c1d4e-8a7b-4c3d-9e1f-0a2b3c4d5e6f' \
  -H "Authorization: Bearer <token>"
```
