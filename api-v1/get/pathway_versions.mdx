---
title: "Get Pathway Versions"
api: "GET https://api.bland.ai/v1/pathway/{pathway_id}/versions"
description: "Retrieves all non-archived versions of a specific pathway, including version number, creation date, name, and staging or published status."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="pathway_id" type="string" required>
  The ID of the pathway for which to retrieve versions.
</ParamField>

### Response

Returns a JSON array of version objects, newest first. Archived versions (see [Delete Pathway Version](/api-v1/delete/pathway_version)) are excluded.

<ResponseField name="id" type="string">
  The internal row identifier of the version. Use `version_number`, not `id`, when calling the other version endpoints.
</ResponseField>

<ResponseField name="version_number" type="integer">
  The version number of this pathway version.
</ResponseField>

<ResponseField name="revision_number" type="integer | null">
  Incremented each time the version is saved.
</ResponseField>

<ResponseField name="created_at" type="string">
  The timestamp when this version was created.
</ResponseField>

<ResponseField name="name" type="string">
  The name of this pathway version. Defaults to `"Version N"` when the version was created without a name.
</ResponseField>

<ResponseField name="source_version_number" type="integer | null">
  The version number this version was copied from, or `null` if it was created from scratch.
</ResponseField>

<ResponseField name="is_staging" type="boolean">
  Present (and `true`) only on the version currently promoted to staging.
</ResponseField>

<ResponseField name="is_prev_published" type="boolean">
  Present (and `true`) only on versions that have been published to production at some point. Only these versions can be used with [Rollback Pathway](/api-v1/post/pathway-rollback).
</ResponseField>

### Errors

| Status | Body |
|---|---|
| `400` | `{"status": "error", "message": "Error fetching pathway versions"}` |
| `403` | `{"status": "error", "message": "Invalid pathway_id or you don't own this pathway"}` for an unknown id, or `"Unauthorized"` for a pathway you cannot access |
