## Overview

Returns a single training sample for a cloned voice you own. By default the response is a WAV file. Pass `?format=json` to get the metadata plus base64-encoded audio instead.

Only cloned voices owned by your org return samples. Default voices, shared-library voices, and voices owned by other orgs return `400 VOICE_SAMPLE_ERROR`.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. The key's user must be an owner or admin of the org.
</ParamField>

---

## Path Parameters

<ParamField path="id" type="string" required>
  UUID of the parent voice.
</ParamField>

<ParamField path="sample_id" type="string" required>
  UUID of the sample to fetch.
</ParamField>

---

## Query Parameters

<ParamField query="format" type="string" default="audio">
  `audio` returns a WAV file. `json` returns sample metadata with base64-encoded audio.
</ParamField>

---

## Response

With `format=audio` (default), returns a mono, 32-bit IEEE float WAV file (`audioFormat: 3`) at the sample's native rate, with:

- `Content-Type: audio/wav`
- `Content-Disposition: attachment; filename="sample-<sample_id>.wav"`

With `format=json`, returns sample metadata.

<ResponseField name="sample" type="object">
  Only present in JSON mode.

  <Expandable title="Sample fields">
    <ResponseField name="id" type="string" />
    <ResponseField name="voice_id" type="string" />
    <ResponseField name="transcription" type="string | null" />
    <ResponseField name="created_at" type="string" />
    <ResponseField name="audio" type="string | null">
      Base64-encoded 32-bit float PCM samples (no WAV header). `null` if the audio could not be decoded, with the reason in `error`.
    </ResponseField>
    <ResponseField name="sample_rate" type="number | null">
      Sample rate of `audio` in Hz.
    </ResponseField>
    <ResponseField name="error" type="string">
      Only present when decoding failed.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `VOICE_SAMPLE_ERROR` | 400 | The voice was not found or is not a cloned voice you own, or `sample_id` does not exist on that voice (`"Sample not found"`). |
| `AUDIO_NOT_FOUND` | 404 | `format=audio` only: the sample exists but has no decodable audio. |
| `UNEXPECTED_ERROR` | 500 | Decoding failed. |
