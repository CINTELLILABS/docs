---
title: "Get Simulation Run Results"
api: "GET https://api.bland.ai/v1/agent-testing/simulation-runs/{id}/results"
description: "Get scores, assertion results, and conversation logs for a simulation run."
---

Use the simulation set ID returned by [Simulate Test Scenario](/api-v1/post/agent-testing-scenarios-id-simulate) as `{id}`. While scoring is starting, this endpoint returns a `RUNNING` summary with empty `assertions` and `logs` arrays.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The simulation set ID.
</ParamField>

## Response

<ResponseField name="data.summary" type="object">
  Contains `simulation_set_id`, `eval_run_id`, `status`, `score`, `passed`, `total_calls`, `passed_count`, `failed_count`, and `created_at`.
</ResponseField>

<ResponseField name="data.assertions" type="array">
  One result per attached eval agent. Each item contains `eval_agent_id`, `name`, `mode`, `score`, `passed`, `weight`, and an optional `breakdown` array of level labels and percentages.
</ResponseField>

<ResponseField name="data.logs" type="array">
  One item per simulated conversation. Each item contains `run_id`, `conversation_id`, `case_name`, `duration_seconds`, `score`, and `passed`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 404 if the simulation set does not exist or belongs to another organization.
</ResponseField>
