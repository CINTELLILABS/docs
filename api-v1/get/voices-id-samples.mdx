---

## Overview

Returns the training samples stored on a voice clone. Only cloned voices owned by your org return samples; default voices, shared-library voices, and voices owned by other orgs return `400 VOICE_SAMPLES_ERROR`.

Stored samples exist for legacy V1 (`BTTS`) voices, which are the only engine that accepts [Add Voice Sample](/api-v1/post/voices-samples). **V3 voices always return `[]`.** V2 voices normally return `[]` too, because their single source clip is not stored as a sample.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. The key's user must be an owner or admin of the org.
</ParamField>

---

## Path Parameters

<ParamField path="id" type="string" required>
  UUID of the voice.
</ParamField>

---

## Query Parameters

<ParamField query="include_audio" type="boolean" default="false">
  When `true`, decodes and includes the audio of every sample. Increases response size and latency significantly. Use [Get Voice Sample](/api-v1/get/voices-id-samples-sample-id) for a single sample instead.
</ParamField>

---

## Response

<ResponseField name="samples" type="array">
  Array of training sample records.

  <Expandable title="Sample fields">
    <ResponseField name="id" type="string">
      UUID of the sample.
    </ResponseField>
    <ResponseField name="voice_id" type="string">
      UUID of the parent voice.
    </ResponseField>
    <ResponseField name="transcription" type="string | null">
      Transcribed text for the sample.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp.
    </ResponseField>
    <ResponseField name="audio" type="string | null">
      Base64-encoded 32-bit float PCM samples (no WAV header). Only present when `include_audio=true`. `null` if the audio could not be decoded, with the reason in `error`.
    </ResponseField>
    <ResponseField name="sample_rate" type="number | null">
      Sample rate of `audio` in Hz. Only present when `include_audio=true`.
    </ResponseField>
    <ResponseField name="error" type="string">
      Only present when `include_audio=true` and decoding failed for this sample.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `VOICE_SAMPLES_ERROR` | 400 | The voice was not found, is not a cloned voice, or is not owned by your org. |
| `UNEXPECTED_ERROR` | 500 | Listing or decoding failed. |
