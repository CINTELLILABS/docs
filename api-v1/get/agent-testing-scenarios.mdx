---
title: "List Test Scenarios"
api: "GET https://api.bland.ai/v1/agent-testing/scenarios"
description: "List test scenarios for your organization."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="pathway_id" type="string">
  Filter by pathway ID.
</ParamField>

<ParamField query="persona_id" type="string">
  Filter by persona ID.
</ParamField>

<ParamField query="agent_id" type="string">
  Filter by agent ID.
</ParamField>

<ParamField query="category" type="string">
  Filter by scenario category. One of `CUSTOM`, `VOICEMAIL`, `VOICEMAIL_SCREENER`, `ANGRY_CALLER`, `BELLIGERENT_CALLER`, `CONFUSED_CALLER`, `CALL_SCREENER`, `HAPPY_PATH`, `EDGE_CASE`.
</ParamField>

<ParamField query="enabled" type="string">
  Filter by enabled status. Pass `true` or `false`. Any other value returns both.
</ParamField>

### Response

`data` is an array of up to 100 scenarios, newest first. There is no pagination; use the filters to narrow the result.

<ResponseField name="data" type="array">
  Each item has the fields described in [Get Test Scenario](/api-v1/get/agent-testing-scenarios-id) plus:

  <Expandable title="extra fields">
    <ResponseField name="runs" type="array">
      Zero or one entries: the most recent run for the scenario. Each entry has `id`, `status`, `overall_score`, `created_at`, `version_number`, `duration_ms`, `turn_count`, `bland_tone_score`, `error_message`, and `assertion_results` (each with `id`, `status`, `score`, `reasoning`, and `assertion` containing `name`, `type`, `is_required`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="array">
  `null` on success.
</ResponseField>
