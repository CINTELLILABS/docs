---
title: "Get SIP Config"
api: "GET https://api.bland.ai/v1/sip"
description: "Retrieve the current SIP configuration for a phone number."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="phone_number" type="string" required>
  The number or SIP identity to fetch configuration for. Accepts an E.164 number, a DID, or an extension. The exact form you send is looked up first, then its `+` or plus-less sibling.
</ParamField>

### Response

<ResponseField name="data.inbound" type="object">
  Inbound SIP configuration. The key is omitted when no inbound direction is configured. Includes `id`, `org_id`, `number`, `direction`, `sip_endpoint`, `headers`, `options`, `trunk_id`, `failover_config`, `codec_config`, `alert_config`, `created_at`, and `updated_at`. `options` is reduced to `auth_mode`, `port`, `transport`, and `secure_media`; any credentials are replaced with `********`.
</ResponseField>

<ResponseField name="data.outbound" type="object">
  Outbound SIP configuration, omitted when not configured. Same fields as inbound. `options.sip_username` and `options.sip_password` are replaced with `********` when set.
</ResponseField>

### Error Responses

<ResponseField name="400 INVALID_PARAMETER" type="object">
  `phone_number` is missing or empty.
</ResponseField>

```bash Example Request
curl -X GET 'https://api.bland.ai/v1/sip?phone_number=%2B14150000000' \
  -H "Authorization: Bearer <token>"
```
