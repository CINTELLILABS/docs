---
title: "Get Knowledge Base Version"
api: "GET https://api.bland.ai/v1/knowledge/{knowledge_base_id}/versions/{version_id}"
description: "Returns a temporary download URL for the content of a specific knowledge base version."
---

Returns metadata for one version plus a presigned URL to its content. For PDF and Word sources the URL points to the converted Markdown; for text, CSV, and other plain sources it points to the source file itself.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="knowledge_base_id" type="string" required>
  The knowledge base the version belongs to.
</ParamField>

<ParamField path="version_id" type="string" required>
  The version ID, from [List Knowledge Base Versions](/api-v1/get/knowledge-id-versions).
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.content_url" type="string">
    Presigned URL for the version content, valid for 30 minutes. Empty string while `processing` is present.
  </ResponseField>

  <ResponseField name="data.processing" type="object">
    Present only when this is the current version and a conversion job is still writing it. `content_url` is withheld until the job finishes.

    <ResponseField name="data.processing.state" type="string">
      `"pending"` or `"running"`.
    </ResponseField>

    <ResponseField name="data.processing.pages_done" type="number">
      Pages converted so far.
    </ResponseField>

    <ResponseField name="data.processing.total_pages" type="number | null">
      Total pages, or `null` until the worker reports a count.
    </ResponseField>

    <ResponseField name="data.processing.percent" type="number | null">
      Progress from 0 to 100, or `null` when `total_pages` is unknown.
    </ResponseField>

    <ResponseField name="data.processing.eta_seconds" type="number | null">
      Estimated seconds remaining, or `null` until enough pages have been timed.
    </ResponseField>

    <ResponseField name="data.processing.attempts" type="number">
      Attempts made so far.
    </ResponseField>

    <ResponseField name="data.processing.max_attempts" type="number">
      Attempts allowed before the job is abandoned.
    </ResponseField>

    <ResponseField name="data.processing.last_error" type="string | null">
      Error from the most recent failed attempt, if any.
    </ResponseField>
  </ResponseField>

  <ResponseField name="data.version" type="object">
    <ResponseField name="data.version.id" type="string">
      Version ID.
    </ResponseField>

    <ResponseField name="data.version.created_at" type="string">
      ISO timestamp of creation.
    </ResponseField>

    <ResponseField name="data.version.file_name" type="string">
      Name of the file `content_url` points to.
    </ResponseField>

    <ResponseField name="data.version.file_size" type="number">
      Size in bytes of the file `content_url` points to.
    </ResponseField>
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on success.
</ResponseField>

### Errors

| Status | Code | Message |
|---|---|---|
| 404 | `KB_ERROR` | `Version not found` |
| 404 | `KB_ERROR` | `No file for this version` |
| 500 | `GET_VERSION_ERROR` | `Failed to get version` |

<RequestExample>

```bash cURL

  -H "authorization: YOUR_API_KEY"
```
