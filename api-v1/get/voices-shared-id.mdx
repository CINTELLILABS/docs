title: "Get Shared Voice"

description: "Get one public library voice without an API key."
---

## Overview

Returns a single voice from the public Bland library, in the same shape as a row from [List Shared Voices](/api-v1/get/voices-shared). Use it to open a detail view from a picker without authenticating.

Only public, non-deleted voices are returned. A private voice, a deleted voice, and an unknown id all return the same `404`, so existence is never revealed.

<Note>
  No API key is required. Responses carry `Cache-Control: public, max-age=30`.
</Note>

---

## Path Parameters

<ParamField path="id" type="string" required>
  UUID of the shared voice. Names are not accepted.
</ParamField>

---

## Response

<ResponseField name="voice" type="object">
  The shared voice. See [List Shared Voices](/api-v1/get/voices-shared#response) for the field list.
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `VOICE_NOT_FOUND` | 404 | The id is not a UUID, or no public voice has that id. |
| `SHARED_VOICE_ERROR` | 500 | The voice could not be fetched. |

