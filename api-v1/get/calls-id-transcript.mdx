---
title: "Get Call Transcript"
api: "GET https://api.bland.ai/v1/calls/{call_id}/transcript"
description: "Get a call's transcript, one page at a time, optionally translated to English."
---

## Overview

Returns a call's transcript as a list of turns, in the order they were spoken. Add `translate=en` to also get an English translation of every turn, for example to review a call that was held in Spanish.

The response is paged. Each request returns up to 50 turns. When the transcript has more, `next_offset` tells you where the next page starts.

Translations are generated when you first request them and are reused for later requests, so the first translated request for a long call takes longer than the ones after it.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. A restricted API key needs the `calls:read` scope.
</ParamField>

---

## Path Parameters

<ParamField path="call_id" type="string" required>
  The ID of the call. The call must belong to your organization.
</ParamField>

---

## Query Parameters

<ParamField query="translate" type="string">
  Set to `en` to add an English translation to every turn. `en` is the only supported value. Omit it to get the transcript without translations.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  The position of the first turn to return. Use the `next_offset` value from the previous response to get the next page.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  The maximum number of turns to return, from `1` to `50`.
</ParamField>

---

## Response

<ResponseField name="data.call_id" type="string">
  The ID of the call.
</ResponseField>

<ResponseField name="data.target_language" type="string | null">
  `en` when you requested a translation, otherwise `null`.
</ResponseField>

<ResponseField name="data.total" type="integer">
  The number of turns in the whole transcript.
</ResponseField>

<ResponseField name="data.offset" type="integer">
  The position of the first turn in this page.
</ResponseField>

<ResponseField name="data.next_offset" type="integer | null">
  The `offset` to request for the next page, or `null` when this page is the last one.
</ResponseField>

<ResponseField name="data.transcripts" type="array of objects">
  The turns in this page. Each turn includes:

  - `id`: the turn ID. This is the same `id` as in the `transcripts` of [Call Details](/api-v1/get/calls-id).
  - `user`: who spoke (`user`, `assistant`, `robot`, or `agent-action`).
  - `text`: the turn as it was spoken.
  - `created_at`: when the turn was recorded.
  - `translated`: the English translation of `text`. Present only when you set `translate=en`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Otherwise one of:

  - `400` with `INVALID_PARAMETER`: `call_id`, `translate`, `offset`, or `limit` is not valid.
  - `404` with `CALL_NOT_FOUND`: the call does not exist or belongs to a different organization.
  - `502` with `TRANSLATION_FAILED`: the translation could not be completed. Try the request again.
</ResponseField>
