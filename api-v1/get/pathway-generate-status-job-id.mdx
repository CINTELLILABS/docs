---
title: "Get Pathway Generation Status"
api: "GET https://api.bland.ai/v1/pathway/generate/status/{job_id}"
description: "Poll pathway generation status and retrieve the generated pathway ID when ready."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="job_id" type="string" required>
  The `jobId` returned by `POST /v1/pathway/generate`.
</ParamField>

### How polling works

- The first status request starts processing and returns `ready: false`.
- Processing starts for at most one job per account per minute. Status requests for other jobs during that window return `ready: false` and do not start them; keep polling.
- Continue polling until `data.ready` is `true`.
- On success, the response includes `pathway_id`.
- On failure, the response includes `error`.

The generate and status endpoints share an IP rate limit of 100 requests per 15 minutes. Requests over the limit return `429`.

### Response

<ResponseField name="data" type="object">
  Generation state object.
</ResponseField>

<ResponseField name="data.ready" type="boolean">
  `false` while generation is still in progress, `true` when processing is complete.
</ResponseField>

<ResponseField name="data.pathway_id" type="string">
  Present when generation succeeds and `ready` is `true`.
</ResponseField>

<ResponseField name="data.error" type="string">
  Present when generation fails and `ready` is `true`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success responses, or a list of errors for invalid/unauthorized requests.
</ResponseField>

<ResponseExample>
```json Not Ready
{
  "data": {
    "ready": false
  },
  "errors": null
}
```

```json Ready (Success)
{
  "data": {
    "ready": true,
    "pathway_id": "a6c24531-75b1-4334-95b2-2d0f11e8fe41"
  },
  "errors": null
}
```

```json Ready (Failed)
{
  "data": {
    "ready": true,
    "error": "Prompt flagged for inappropriate content."
  },
  "errors": null
}
```

```json Error (404)
{
  "data": null,
  "errors": [
    {
      "error": "PATHWAY_GENERATION_FAILED",
      "message": "Job not found"
    }
  ]
}
```

```json Error (403)
{
  "data": null,
  "errors": [
    {
      "error": "UNAUTHORIZED",
      "message": "You don't have permission to access this job"
    }
  ]
}
```
</ResponseExample>
