---
title: "List Alert Bindings"
api: "GET https://api.bland.ai/v1/triage/issues/{id}/alert-bindings"
description: "List the alerts linked to a triage issue."
---

Returns the alerts linked to an issue, newest first.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  Internal UUID of the issue.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="50">
  Number of bindings to return. Minimum 1, maximum 100.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque cursor returned as `next_cursor` from a previous page.
</ParamField>

## Response

<ResponseField name="data.items" type="array">
  Alert bindings. Each item contains `id`, `issue_id`, `org_id`, `active_alert_id`, `alert_config_id`, `alert_name`, `current_severity`, `status`, `binding_mode`, `created_at`, and `updated_at`.
</ResponseField>

<ResponseField name="data.next_cursor" type="string | null">
  Cursor for the next page, or `null`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 404 if the issue does not exist or belongs to another organization.
</ResponseField>
