---
title: "Get Outbound Setup"
api: "GET https://api.bland.ai/v1/sip/outbound-setup"
description: "Get Bland's SIP server details and PBX configuration instructions for outbound call routing."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Query Parameters

<ParamField query="phone_number" type="string">
  Optional. Must parse as an E.164 number. When provided and the number has an outbound configuration with a `sip_username`, the response includes `credentials`.
</ParamField>

### Response

<ResponseField name="sip_server" type="string">
  Bland's SIP server hostname for your region: `us2.sip.bland.ai`, `ca2.sip.bland.ai`, `asia2.sip.bland.ai`, or `eu2.sip.bland.ai`.
</ResponseField>

<ResponseField name="port" type="number">
  SIP signaling port, `5061` (TLS).
</ResponseField>

<ResponseField name="instructions" type="string">
  Human-readable setup instructions for configuring your PBX.
</ResponseField>

<ResponseField name="credentials" type="object">
  `{ "sip_username": string, "sip_password": "********" }`. Only present when `phone_number` is given and that number's outbound options include a `sip_username`. The password is always redacted.
</ResponseField>

### Error Responses

<ResponseField name="400 INVALID_PARAMETER" type="object">
  `phone_number` was sent but is empty.
</ResponseField>

<ResponseField name="400 BAD_REQUEST" type="object">
  `phone_number` is not a valid number with a country code.
</ResponseField>

```bash Example Request
curl -X GET 'https://api.bland.ai/v1/sip/outbound-setup?phone_number=%2B14150000000' \
  -H "Authorization: Bearer <token>"
```

<ResponseExample>
```json Response
{
  "data": {
    "sip_server": "us2.sip.bland.ai",
    "port": 5061,
    "instructions": "Configure your PBX to send outbound calls to the SIP server and port above. When prompted for a number, use the SIP username assigned to your number.",
    "credentials": {
      "sip_username": "bland",
      "sip_password": "********"
    }
  },
  "errors": null
}
```
</ResponseExample>
