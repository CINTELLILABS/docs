---
title: "List Web Agents"
api: "GET https://api.bland.ai/v1/agents"
description: "Retrieves each web agent you've created, along with their settings."
---

<Note>
  Web Agents are the legacy inbound-based agent model, maintained for existing customers. They remain the voice backend for the [Web Chat Widget](/tutorials/chat-widget) (`agent_id` on [Create Widget](/api-v1/post/widget)). For phone calls, use [Send Call](/api-v1/post/calls) with a pathway or persona instead.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="agents" type="array">
  Each agent object, containing the following fields:

  - `agent_id` (string): The unique identifier for the agent.
  - `created_at` (string): ISO timestamp.
  - `prompt` (string | null): The prompt for the agent.
  - `pathway_id` (string | null): Pathway the agent follows, if any.
  - `webhook` (string | null): The webhook URL for the agent.
  - `webhook_events` (string[] | null): Event streams sent to the webhook.
  - `voice` (string | null): The voice used by the agent.
  - `voice_settings` (object | null): Voice tuning settings.
  - `model` (string | null): The model used by the agent.
  - `temperature` (number | null): Sampling temperature.
  - `first_sentence` (string | null): The first sentence the agent will say.
  - `dynamic_data` (array | null): Dynamic data configuration.
  - `tools` (array | null): Custom Tools the agent can use.
  - `interruption_threshold` (number | null): Patience threshold for caller speech.
  - `interruptibility` (number | null): Interruption sensitivity level.
  - `noise_cancellation` (boolean | null): Whether noise suppression is enabled.
  - `silence_end_message` (string | null): Message spoken before hanging up on silence.
  - `max_duration` (number): Maximum call duration in minutes.
  - `metadata` (object | null): Metadata you attached to the agent.
  - `analysis_schema` (object | null): Post-call extraction schema.
  - `pronunciation_guide` (array | null): Pronunciation overrides.

  `language` and `redaction` are accepted on create and update but are not returned.
</ResponseField>

### Error Codes

| Status | Body | Description |
|--------|------|-------------|
| 500 | `{"status": "error", "message": "Internal server error"}` | Unexpected failure. |
