---
title: "Get Suggestion"
api: "GET https://api.bland.ai/v1/knowledge/suggestions/{suggestion_id}"
description: "Retrieves a single knowledge base suggestion by ID."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="suggestion_id" type="string" required>
  The suggestion ID, from [List Suggestions](/api-v1/get/knowledge-id-suggestions) or [Create Suggestion](/api-v1/post/knowledge-improve).
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.id" type="string">
    Suggestion ID.
  </ResponseField>

  <ResponseField name="data.knowledge_base_id" type="string">
    The knowledge base the suggestion belongs to.
  </ResponseField>

  <ResponseField name="data.question" type="string">
    The question.
  </ResponseField>

  <ResponseField name="data.answer" type="string">
    The answer.
  </ResponseField>

  <ResponseField name="data.created_at" type="string">
    ISO timestamp of creation.
  </ResponseField>

  <ResponseField name="data.updated_at" type="string">
    ISO timestamp of last update.
  </ResponseField>

  <ResponseField name="data.kb" type="object">
    The parent knowledge base.

    <ResponseField name="data.kb.id" type="string">
      Knowledge base ID.
    </ResponseField>

    <ResponseField name="data.kb.name" type="string">
      Knowledge base name.
    </ResponseField>
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on success.
</ResponseField>

### Errors

| Status | Code | Message |
|---|---|---|
| 404 | `KB_ERROR` | `Suggestion not found` |
| 500 | `SUGGESTION_GET_ERROR` | `Failed to fetch suggestion` |

<RequestExample>

```bash cURL

  -H "authorization: YOUR_API_KEY"
```
