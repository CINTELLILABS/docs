---
title: "Get Alarm History"
api: "GET https://api.bland.ai/v1/alarms/{id}/history"
description: "Get the event history for a single alarm."
---

<Note>
  The Alarms API is available to Enterprise organizations only. Requests from other organizations return `403` with the error code `ENTERPRISE_REQUIRED`.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  Alarm configuration ID.
</ParamField>

### Query Parameters

<ParamField query="limit" type="integer" default="50">
  Must be between `1` and `200`. Values outside this range return `400` with `INVALID_LIMIT`.
</ParamField>

### Response

<ResponseField name="data.events" type="array">
  Alarm event entries for this alarm, oldest first.
</ResponseField>

<ResponseField name="data.events[].id" type="string">
  Alarm event ID.
</ResponseField>

<ResponseField name="data.events[].metric_type" type="string">
  Metric associated with this event.
</ResponseField>

<ResponseField name="data.events[].previous_state" type="string">
  Previous alarm state before transition.
</ResponseField>

<ResponseField name="data.events[].new_state" type="string">
  New alarm state after transition.
</ResponseField>

<ResponseField name="data.events[].deviation" type="number">
  Deviation from baseline at evaluation time.
</ResponseField>

<ResponseField name="data.events[].threshold" type="number">
  Threshold in effect for this event.
</ResponseField>

<ResponseField name="data.events[].alarm_id" type="string">
  The alarm this event belongs to.
</ResponseField>

<ResponseField name="data.events[].event_type" type="string|null">
  Event type when a notification/state event was recorded (for example `deviation_detected` or `deviation_recovered`).
</ResponseField>

<ResponseField name="data.events[].created_at" type="string">
  ISO timestamp when the event was recorded.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success. An unknown alarm returns `404` with `ALARM_NOT_FOUND`.
</ResponseField>
