## Overview

Returns one page of the publicly-shared voices in the Bland library. These are voices that creators have published for everyone to use; they are not in your org's library until you call [Add Library Voice](/api-v1/post/voices-library-add-id).

Use this endpoint to power voice-picker UIs and discovery flows. For one voice's detail, use [Get Shared Voice](/api-v1/get/voices-shared-id).

<Note>
  No API key is required. Requests are throttled per IP address at 120 per minute; a breach returns `429 RATE_LIMITED` with a `Retry-After` header and blocks the IP for 60 seconds.
</Note>

---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  1-indexed page number. Must be a positive integer.
</ParamField>

<ParamField query="page_size" type="integer" default="24">
  Voices per page, 1 to 100. Values above 100 are clamped to 100.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive substring match on voice name and description. Maximum 200 characters.
</ParamField>

<ParamField query="service" type="string">
  Filter to one engine: `BTTS`, `BTTS_V2`, or `BTTS_V3`.
</ParamField>

<ParamField query="tag" type="string">
  Filter to voices carrying any of the given tags. Repeat the parameter for several tags (`?tag=english&tag=calm`). Matching is case-insensitive for the first letter (`male` and `Male` both match).
</ParamField>

<ParamField query="gender" type="string">
  Convenience alias for `tag`: `male` or `female`.
</ParamField>

<ParamField query="sort" type="string" default="recent">
  Sort order. One of:

  - `recent`: newest first.
  - `name`: alphabetical.
  - `ratings`: most ratings first.
  - `top_rated`: highest average rating first, tiebroken by rating count.
  - `trending`: precomputed recent-popularity score, tiebroken by newest.
</ParamField>

## Response

Responses carry `Cache-Control: public, max-age=30` and an `X-Cache` header (`HIT` or `MISS`); the same query is served from a 30-second server-side cache.

<ResponseField name="voices" type="array">
  The page of shared voices.

  <Expandable title="Voice fields">
    <ResponseField name="id" type="string">
      UUID of the shared voice. Pass to [Add Library Voice](/api-v1/post/voices-library-add-id) to add it to your org.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name in the public library.
    </ResponseField>
    <ResponseField name="description" type="string | null" />
    <ResponseField name="service" type="string">
      The voice's engine: `BTTS`, `BTTS_V2`, `BTTS_V3`, or `LEGACY`.
    </ResponseField>
    <ResponseField name="is_creator_voice" type="boolean">
      `true` if the voice is part of the creator program. Creator voices may carry a per-character fee in addition to the synthesis cost.
    </ResponseField>
    <ResponseField name="ratings" type="number">
      Legacy rating counter.
    </ResponseField>
    <ResponseField name="rating_count" type="number">
      Number of distinct users who have rated the voice.
    </ResponseField>
    <ResponseField name="rating_avg" type="number">
      Average rating, 0-5.
    </ResponseField>
    <ResponseField name="trending_score" type="number">
      Precomputed popularity score used by `sort=trending`.
    </ResponseField>
    <ResponseField name="tags" type="string[]" />
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp.
    </ResponseField>
    <ResponseField name="public" type="boolean">
      Always `true` for entries in the shared library.
    </ResponseField>
    <ResponseField name="creator_display_name" type="string | null">
      Name of the creator who published the voice, if applicable.
    </ResponseField>
    <ResponseField name="creator_fee_cents_per_1k" type="number | null">
      Creator fee in cents per 1,000 characters. `null` for non-creator voices.
    </ResponseField>
    <ResponseField name="creator_fee_cents_per_10k" type="number | null">
      Deprecated alias of `creator_fee_cents_per_1k` (same value).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  Total voices matching the filters, across all pages.
</ResponseField>

<ResponseField name="page" type="number">
  The page returned.
</ResponseField>

<ResponseField name="page_size" type="number">
  The page size applied.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` when `page * page_size < total`.
</ResponseField>

### Errors

Errors use the `{ "data": null, "errors": [...] }` envelope.

| Code | HTTP | Meaning |
|---|---|---|
| `INVALID_PAGE` | 400 | `page` is not a positive integer. |
| `INVALID_PAGE_SIZE` | 400 | `page_size` is not a positive integer. |
| `SEARCH_TOO_LONG` | 400 | `search` exceeds 200 characters. |
| `INVALID_SORT` | 400 | `sort` is not one of the accepted values. |
| `INVALID_SERVICE` | 400 | `service` is not `BTTS`, `BTTS_V2`, or `BTTS_V3`. |
| `RATE_LIMITED` | 429 | More than 120 requests per minute from one IP. `Retry-After` is set. |
| `SHARED_VOICES_ERROR` | 500 | The catalog could not be fetched. |
