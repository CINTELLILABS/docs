---
title: "List Suggestions"
api: "GET https://api.bland.ai/v1/knowledge/{knowledge_base_id}/suggestions"
description: "Lists the question and answer pairs added to a knowledge base."
---

Returns the suggestions created through [Create Suggestion](/api-v1/post/knowledge-improve), newest first, with page based pagination.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="knowledge_base_id" type="string" required>
  The knowledge base to list suggestions for.
</ParamField>

### Query Parameters

<ParamField query="type" type="string">
  Filter by suggestion type: `SUGGESTION` or `FEEDBACK`. Returns all types when omitted.
</ParamField>

<ParamField query="page" type="number" default="1">
  Page number, starting at 1.
</ParamField>

<ParamField query="limit" type="number" default="20">
  Items per page. No maximum is enforced.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.suggestions" type="array">
    Suggestions on this page, ordered by `created_at` descending.

    <ResponseField name="data.suggestions[].id" type="string">
      Suggestion ID.
    </ResponseField>

    <ResponseField name="data.suggestions[].knowledge_base_id" type="string">
      The knowledge base the suggestion belongs to.
    </ResponseField>

    <ResponseField name="data.suggestions[].question" type="string">
      The question.
    </ResponseField>

    <ResponseField name="data.suggestions[].answer" type="string">
      The answer.
    </ResponseField>

    <ResponseField name="data.suggestions[].created_at" type="string">
      ISO timestamp of creation.
    </ResponseField>

    <ResponseField name="data.suggestions[].updated_at" type="string">
      ISO timestamp of last update.
    </ResponseField>
  </ResponseField>

  <ResponseField name="data.total" type="number">
    Total suggestions matching the filter.
  </ResponseField>

  <ResponseField name="data.page" type="number">
    The page returned.
  </ResponseField>

  <ResponseField name="data.limit" type="number">
    The page size used.
  </ResponseField>

  <ResponseField name="data.has_more" type="boolean">
    `true` when a later page exists.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on success.
</ResponseField>

### Errors

| Status | Code | Message |
|---|---|---|
| 404 | `KB_ERROR` | `KB not found or access denied` |
| 500 | `SUGGESTION_LIST_ERROR` | `Failed to fetch suggestions` |
