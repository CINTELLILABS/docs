---
title: "Get corrected transcripts"
api: "GET https://api.bland.ai/v1/calls/{call_id}/correct"
description: "Get the corrected transcript from your call's recording."
---

Re-transcribes the call recording with speaker diarization and returns a corrected transcript. The first request for a call does the transcription; the result is cached, and later requests return the stored result.

If a capture stop has been recorded for the call ([Stop Transfer Capture](/api-v1/post/calls-id-capture-stop)), the corrected transcript ends at that point even if the recording runs longer.

<Warning>
  This endpoint is rate limited to 10 requests per 10 minutes per IP address, counting cached re-reads. Requests over the limit receive `429 Too Many Requests`.
</Warning>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="call_id" type="string" required>
  The unique identifier for the call to be corrected. The call must be longer than 1.5 seconds.
</ParamField>

### Response

<ResponseField type="object" name="data">
  <Expandable title="data properties">
    <ResponseField type="string" name="status">
      `completed` when the transcript was corrected by this request, or `success` when a previously corrected transcript was returned from the cache.
    </ResponseField>

    <ResponseField type="string" name="message">
      Confirms the correction completed or was already cached, and notes that `aligned` is deprecated.
    </ResponseField>

    <ResponseField type="array" name="corrected">
      An array of transcript segments with speaker information and confidence scores. Each segment is constructed as the following.
      ```json
      {
      "start": 0.069, // start time of the segment, in seconds
      "end": 2.551, // end time of the segment, in seconds
      "text": " Hi, I'm calling about a pizza order.", // the corrected text
      "speaker": 2, // the identified speaker diarization. Can be 1,2,3 etc
      "speaker_label": "assistant", // human-readable speaker label ("user", "assistant")
      "confidence": 0.762 // transcription confidence score (0-1)
      }
      ```
      For organizations with post-transfer transcripts enabled, segments spoken by the human agent after a transfer carry `speaker_label: "representative"`.
    </ResponseField>

    <ResponseField type="array" name="aligned">
      **DEPRECATED**: The `aligned` field is deprecated and will be removed in a future version. Please use the `corrected` field instead, which includes `speaker_label` and `confidence` information.

      Legacy description: each corrected segment matched to a role from the original transcript by vectorizing the text and taking the cosine similarity. Each object is constructed as the following.
      ```json
      {
      "start": 0.069,
      "end": 2.551,
      "text": " Hi, I'm calling about a pizza order.",
      "speaker": "assistant", // the presumed role
      "similarity": 0.686 // cosine similarity to the best-matching original line
      }
      ```
    </ResponseField>

    <ResponseField type="array" name="original">
      The original transcript lines recorded during the call, as stored. Each object is constructed as the following.
      ```json
      {
      "id": 3056004,
      "created_at": "2024-02-29T18:40:41.26799+00:00",
      "text": "Great, Thanks John. Could you tell me about the pizza order you placed?",
      "user": "assistant", // "user", "assistant", or "agent-action"
      "c_id": "bfaf99a1-b7c0-4f96-9630-90bc41cea488"
      }
      ```
    </ResponseField>

    <ResponseField type="string" name="created_at">
      When the cached transcript was created. Only present on cached responses (`status: "success"`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField type="null | array" name="errors">
  `null` on success. On failure `data` is `null` and `errors` contains one entry with `error` and `message`:

  | Status | `error` | When |
  |---|---|---|
  | `400` | `MISSING_CALL_ID` | No `call_id` in the path. |
  | `400` | `CALL_LENGTH_TOO_SHORT` | The call is 1.5 seconds or shorter. |
  | `401` | `UNAUTHORIZED` | The call belongs to another organization. |
  | `404` | `CALL_NOT_FOUND` | No call with that ID. |
  | `500` | `RECORDING_URL_CONVERSION_FAILED` | The recording could not be resolved to a fetchable URL. |
  | `500` | `INTERNAL_SERVER_ERROR` | Unexpected error while processing the transcript. |
  | `502` | `TRANSCRIPTION_API_FAILED` | The transcription provider returned an error. |
</ResponseField>
