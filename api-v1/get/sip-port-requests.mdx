---
title: "List Port Requests"
api: "GET https://api.bland.ai/v1/sip/port"
description: "List all number porting requests for your organization."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="port_requests" type="array">
  Port requests, newest first. Each includes:
  - `id` (string): port request ID
  - `org_id` (string)
  - `twilio_port_sid` (string): the carrier's reference for the request
  - `status` (string): the carrier's current request status as reported by its webhooks (for example `"in_review"`, `"waiting_for_signature"`, `"completed"`), or `"canceled"` after [Cancel Port Request](/api-v1/delete/sip-port-cancel)
  - `phone_numbers` (array): each with `number`, `status`, and `port_in_phone_number_sid`
  - `authorized_rep_email` (string)
  - `notification_emails` (string[])
  - `created_at` (string): ISO 8601 timestamp
  - `updated_at` (string): ISO 8601 timestamp
</ResponseField>

When a request reaches `"completed"`, the ported numbers are added to your organization as inbound numbers automatically.

```bash Example Request
curl -X GET https://api.bland.ai/v1/sip/port \
  -H "Authorization: Bearer <token>"
```
