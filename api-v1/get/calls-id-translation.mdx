---
title: "Get Call Translation"
api: "GET https://api.bland.ai/v1/calls/{call_id}/translation"
description: "Get an English translation of every turn of a call, one page at a time."
---

## Overview

Returns the turns of a call with an English translation of each one, for example to review a call that was held in Spanish. Turns are listed in the order they were recorded. Turns with no text are left out.

The response is paged. Each request returns up to 50 turns. When the call has more, `next_offset` tells you where the next page starts.

Translations are generated when you first request them and are reused for later requests, so the first request for a long call takes longer than the ones after it.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. A restricted API key needs the `calls:read` scope.
</ParamField>

---

## Path Parameters

<ParamField path="call_id" type="string" required>
  The ID of the call. The call must belong to your organization.
</ParamField>

---

## Query Parameters

<ParamField query="language" type="string" default="en">
  The language to translate into. `en` is the only supported value.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  The position of the first turn to return. Use the `next_offset` value from the previous response to get the next page.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  The maximum number of turns to return, from `1` to `50`.
</ParamField>

---

## Response

<ResponseField name="data.call_id" type="string">
  The ID of the call.
</ResponseField>

<ResponseField name="data.language" type="string">
  The language of the translations. Always `en`.
</ResponseField>

<ResponseField name="data.total" type="integer">
  The number of turns in the whole call.
</ResponseField>

<ResponseField name="data.offset" type="integer">
  The position of the first turn in this page.
</ResponseField>

<ResponseField name="data.next_offset" type="integer | null">
  The `offset` to request for the next page, or `null` when this page is the last one.
</ResponseField>

<ResponseField name="data.turns" type="array of objects">
  The turns in this page. Each turn includes:

  - `id`: the turn ID. This is the same `id` as in the `transcripts` of [Call Details](/api-v1/get/calls-id).
  - `user`: who spoke (`user`, `assistant`, `robot`, or `agent-action`).
  - `text`: the turn as it was spoken.
  - `translated`: the English translation of `text`.
  - `created_at`: when the turn was recorded.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Otherwise one of:

  - `400` with `INVALID_PARAMETER`: `call_id`, `language`, `offset`, or `limit` is not valid.
  - `404` with `CALL_NOT_FOUND`: the call does not exist or belongs to a different organization.
  - `502` with `TRANSLATION_FAILED`: the translation could not be completed. Try the request again.
</ResponseField>
