---
title: "Get Outcome"
api: "GET https://api.bland.ai/v1/dispositions/{id}"
description: "Get an outcome and its current script."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The outcome ID.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The outcome. It has the same fields as [Create Outcome](/api-v1/post/dispositions) returns, plus `script`.

  <Expandable title="Additional field">
    <ResponseField name="script" type="string | null">
      The JavaScript source for the current `snippet_version`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, otherwise an array of error objects.
</ResponseField>
