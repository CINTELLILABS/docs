---
title: "Event Stream"
api: "GET https://api.bland.ai/v1/event_stream/{call_id}" 
description: "Retrieve stream of events that occurred during the call."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="call_id" type="string" required>
  The unique identifier of the call for which you want to retrieve detailed information.
</ParamField>

### Response

<ResponseField name="status" type="string">
  `success` when the events were retrieved.
</ResponseField>

<ResponseField name="message" type="string">
  A human-readable result message.
</ResponseField>

<ResponseField name="event_stream_data" type="array">
  The events recorded for the call.
</ResponseField>

<ResponseField name="event_stream_data[].level" type="string">
    The level of the event - `queue` or `call`
</ResponseField>

<ResponseField name="event_stream_data[].message" type="string">
    The message of the event.
</ResponseField>

<ResponseField name="event_stream_data[].category" type="string">
    The category of the event - `info`, `performance` or `error`.
</ResponseField>

<ResponseField name="event_stream_data[].call_id" type="string">
    The unique identifier for the call.
</ResponseField>

<ResponseField name="event_stream_data[].timestamp" type="string">
When the event occurred.
</ResponseField>

<ResponseExample>
```json Response
{
  "status": "success",
  "message": "Successfully fetched event stream data",
  "event_stream_data": [
    {
      "level": "call",
      "message": "Call connected",
      "category": "info",
      "call_id": "8dd6f762-6c67-4546-aaad-3e59f5e4a09c",
      "timestamp": "2026-09-07T18:30:00.000Z"
    }
  ]
}
```
</ResponseExample>

Errors return a flat `{ "status": "error", "message": "..." }` body with status `403`, `404`, or `500`.
