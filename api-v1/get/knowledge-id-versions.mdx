---
title: "List Knowledge Base Versions"
api: "GET https://api.bland.ai/v1/knowledge/{knowledge_base_id}/versions"
description: "Lists every version of a knowledge base, newest first, and identifies the current one."
---

A new version is created each time you replace a knowledge base's file or URLs, restore an older version, or edit its content. Use this endpoint to find version IDs for [Get Knowledge Base Version](/api-v1/get/knowledge-id-versions-version-id) and [Restore Knowledge Base Version](/api-v1/post/knowledge-id-versions-restore).

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="knowledge_base_id" type="string" required>
  The knowledge base to list versions for.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.versions" type="array">
    Versions ordered by `created_at` descending.

    <ResponseField name="data.versions[].id" type="string">
      Version ID.
    </ResponseField>

    <ResponseField name="data.versions[].created_at" type="string">
      ISO timestamp of creation.
    </ResponseField>

    <ResponseField name="data.versions[].is_current" type="boolean">
      `true` for the version the knowledge base currently serves.
    </ResponseField>

    <ResponseField name="data.versions[].file_name" type="string">
      Source file name. For web scrape versions this is the stored URL list, named `<kb name>.json`.
    </ResponseField>

    <ResponseField name="data.versions[].file_size" type="number">
      Source file size in bytes. Omitted when unknown.
    </ResponseField>
  </ResponseField>

  <ResponseField name="data.current_version_id" type="string | null">
    ID of the current version. `null` for a knowledge base created before versioning that has not been edited or replaced yet.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on success.
</ResponseField>

### Errors

| Status | Code | Message |
|---|---|---|
| 404 | `KB_ERROR` | `Knowledge base not found` |
| 500 | `GET_VERSIONS_ERROR` | `Failed to get versions` |
