---
title: "List Integration Resources"
api: "GET https://api.bland.ai/v1/integrations/{integration}/resources"
description: "List your organization's connected accounts (resources) for one integration."
---

A resource is a connected account for an integration (for example one Slack workspace or one Salesforce org). Pass a resource's `id` as `resource_id` when you [create a tool](/api-v2/post/tools). Resources are connected from the dashboard; this endpoint only lists them.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="integration" type="string" required>
  Integration key from [List Integrations](/api-v1/get/integrations). An unknown key returns an empty list, not a 404.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.status" type="string">
    Always `"success"`.
  </ResponseField>

  <ResponseField name="data.resources" type="array">
    Resources for this integration, most recently updated first. Each entry is the full resource row: `id`, `user_id`, `org_id`, `integration`, `name`, `description`, `auth` (auth type and secret or connection IDs, never secret values), `config`, `tags`, `status`, `status_message`, `is_active`, `last_used_at`, `last_validated_at`, `metadata`, `created_at`, `updated_at`. See [Get Resource](/api-v1/get/resources-id) for field details.
  </ResponseField>

  <ResponseField name="data.count" type="number">
    Number of resources returned.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  `null` on success. A 400 `INVALID_PARAMETER` is returned for an empty key and a 500 returns `GET_INTEGRATION_RESOURCES_ERROR`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET https://api.bland.ai/v1/integrations/slack/resources \
  -H "authorization: YOUR_API_KEY"
```
