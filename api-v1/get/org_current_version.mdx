---
title: "Get Organization's Current Service Version"
api: "GET https://api.bland.ai/v1/orgs/{org_id}/versions/{service}/current"
description: "Retrieve the current version of a specified service for an organization."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<Note>
Any member of the organization can read this. A non-member caller gets a `500` response with error `ORG_VERSION_SERVICE_LOOKUP_ERROR` and the reason in `message`, not a `403`.
</Note>

### Path Parameters

<ParamField path="org_id" type="string" required>
  The unique identifier of the organization. Must be a UUID, otherwise the request fails with `400 INVALID_UUID`.
</ParamField>

<ParamField path="service" type="string" required>
  The name of the service whose version you want to retrieve.
  <br/>Valid values: `"api_server"`, `"ws_server"`
</ParamField>

### Response

<ResponseField name="data" type="object">
  Contains the current version of the requested service.
</ResponseField>

<ResponseField name="data.version" type="string | null">
  The current version identifier of the service, or `null` if the organization has never pinned a version.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. On failure, `data` is `null` and `errors` contains one entry with `error: "ORG_VERSION_SERVICE_LOOKUP_ERROR"` and the reason in `message` (status `500`).
</ResponseField>

<ResponseExample>

```json Response
{
  "data": {
    "version": "adf1064d-5080-4055-8493-0d4fdc3c8106"
  },
  "errors": null
}

```
</ResponseExample>
