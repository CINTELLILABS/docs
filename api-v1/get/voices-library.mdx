---
title: "List Voice Library"
api: "GET https://api.bland.ai/v1/voices/library"
description: "List only the voices owned by your organization."
---

Returns the private clones and saved public voices owned by your organization. Unlike [List Voices](/api-v1/get/voices), this endpoint does not mix in the public catalog.

Use each row's `voice_id` to group saved copies that point to the same provider voice.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="voices" type="array">
  Voices owned by your organization. Each row uses the same sanitized voice fields as [List Voices](/api-v1/get/voices#response), including rating aggregates.
</ResponseField>

<ResponseField name="count" type="number">
  Number of voices returned.
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `UNAUTHORIZED` | 401 | Authentication is missing. |
| `LIBRARY_LIST_FAILED` | 400 | An owned voice could not be listed. |
| `UNEXPECTED_ERROR` | 500 | The library could not be fetched. |
