---
title: "Get All Folders"
api: "GET https://api.bland.ai/v1/pathway/folders"
description: "Retrieves all folders for the authenticated user, including folder ID, name, and parent folder ID."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Response

<ResponseField name="data" type="array">
  An array of folder objects, sorted by name.
</ResponseField>

<ResponseField name="data[].folder_id" type="string">
  The unique identifier of the folder.
</ResponseField>

<ResponseField name="data[].name" type="string">
  The name of the folder.
</ResponseField>

<ResponseField name="data[].parent_folder_id" type="string | null">
  The ID of the parent folder, or `null` for a top-level folder.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. `500` returns `[{"error": "GET_FOLDERS_INTERNAL_SERVER_ERROR", ...}]`.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": [
    {
      "folder_id": "folder_123",
      "name": "My Folder",
      "parent_folder_id": null
    },
    {
      "folder_id": "folder_456",
      "name": "Subfolder",
      "parent_folder_id": "folder_123"
    }
  ],
  "errors": null
}
```
</ResponseExample>
