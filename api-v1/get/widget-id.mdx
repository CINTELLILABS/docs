---
title: "Get Widget by ID"
api: "GET https://api.bland.ai/v1/widget/{id}"
description: "Retrieves a specific widget by ID."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  UUID of the widget to retrieve.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The widget:

  - `id` (string): Widget UUID
  - `name` (string | null): Display name
  - `org_id` (string): Your organization UUID
  - `pathway_id` (string | null): Associated pathway UUID
  - `agent_prompt` (string | null): Prompt used instead of a pathway
  - `agent_id` (string | null): Associated web agent UUID
  - `allowed_domains` (string[]): Allowed embed domains
  - `messages_per_minute` (number): Visitor message rate limit
  - `config` (object): Widget configuration object
  - `webhook_url` (string | null): Post-conversation webhook URL
  - `placement_group` (string): Internal routing group
  - `created_at` (string): ISO timestamp
  - `updated_at` (string): ISO timestamp
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list of `{error, message}` objects.
</ResponseField>

### Error Codes

| Status | Error | Description |
|--------|-------|-------------|
| 404 | `NOT_FOUND` | No widget with that ID in your organization. |
