---
title: "Get Specific Pathway Version"
api: "GET https://api.bland.ai/v1/pathway/{pathway_id}/version/{version_id}"
description: "Retrieves a specific version of a pathway, or the live production or staging graph, including its nodes, edges, and post-call configuration."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="pathway_id" type="string" required>
  The ID of the pathway.
</ParamField>

<ParamField path="version_id" type="string" required>
  Which graph to return:

  - A version number (for example `3`) returns that version. A version number that does not exist falls back to the production graph.
  - `production` or `0` returns the live production graph.
  - `staging` returns the version currently promoted to staging.
</ParamField>

### Response

<ResponseField name="nodes" type="array of objects">
  Data about all the nodes in the pathway version.

  <Accordion title="Node Object Parameters">
    - `id`: Unique identifier of the node
    - `type`: Type of the node (e.g., "Default", "End Call", "Webhook")
    - `data`: Object containing node-specific data
      - `name`: Name of the node
      - `text` or `prompt`: Text or prompt associated with the node
      - Other properties specific to the node type
  </Accordion>
</ResponseField>

<ResponseField name="edges" type="array of objects">
  Data about all the edges in the pathway version.

  <Accordion title="Edge Object Parameters">
    - `id`: Unique identifier of the edge
    - `source`: ID of the source node
    - `target`: ID of the target node
    - `data.label`: Label for this edge
    - `data.description`: Optional description of the transition
  </Accordion>
</ResponseField>

<ResponseField name="post_call_actions" type="object | null">
  Post-call actions configured on this version.
</ResponseField>

<ResponseField name="revision_number" type="integer | null">
  Incremented each time the version is saved.
</ResponseField>

<ResponseField name="memory_enabled" type="boolean">
  Whether memory is enabled for this version.
</ResponseField>

<ResponseField name="entity_schemas" type="object | null">
  Entity schemas used by memory, if configured.
</ResponseField>

<ResponseField name="analysis_options" type="object | null">
  Execution settings such as `execution_mode` and `flex_groups`.
</ResponseField>

<ResponseField name="version_number" type="integer">
  The version number requested. `0` when `version_id` is `production`. Omitted when `version_id` is `staging`.
</ResponseField>

<ResponseField name="name" type="string">
  Only present for the sentinel values: `"Production Pathway"` for `production`, `"Staging Pathway"` for `staging`. Numeric versions do not return a name; use [Get Pathway Versions](/api-v1/get/pathway_versions) for version names.
</ResponseField>

### Errors

| Status | Body |
|---|---|
| `400` | `{"status": "error", "message": "Error fetching pathway versions"}` (also returned for `staging` when no version has been promoted to staging) |
| `403` | `{"status": "error", "message": "Invalid pathway_id or you don't own this pathway"}` for an unknown id, or `"Unauthorized"` for a pathway you cannot access |
