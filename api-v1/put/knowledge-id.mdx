---
title: "Update Knowledge Base"
api: "PUT https://api.bland.ai/v1/knowledge/{knowledge_base_id}"
description: "Updates a knowledge base's name and/or description."
---

Updates the name, description, and retrieval configuration of an existing knowledge base. This endpoint does not modify the content of the knowledge base.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="content-type" type="string" required>
  Must be `application/json`.
</ParamField>

### Path Parameters

<ParamField path="knowledge_base_id" type="string" required>
  The unique identifier of the knowledge base to update.
</ParamField>

### Body Parameters

<ParamField body="name" type="string">
  New name for the knowledge base. If omitted or empty, the current name is retained.
</ParamField>

<ParamField body="description" type="string">
  New description for the knowledge base. Pass `null` to remove the description entirely.
</ParamField>

<ParamField body="ranking_config" type="object | null">
  Per-source retrieval configuration for anchor-based cascade retrieval. Pass `null` to return to default hybrid retrieval; omit to leave unchanged. An invalid config returns `400`.

  <ParamField body="ranking_config.csv" type="object">
    `anchor_columns` and `ignored_columns` (string arrays) for CSV sources.
  </ParamField>

  <ParamField body="ranking_config.json" type="object">
    `anchor_paths`, `ignored_paths` (JSONPath string arrays), and optional `list_path` for JSON sources.
  </ParamField>

  <ParamField body="ranking_config.web" type="object">
    `use_page_title` and `use_meta_description` (booleans) for web sources.
  </ParamField>

  <ParamField body="ranking_config.cascade_threshold" type="number">
    Stage 1 confidence threshold. A top result above it wins; below it, retrieval falls back to hybrid search.
  </ParamField>
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated knowledge base object.

  <ResponseField name="data.id" type="string">
    Unique identifier for the knowledge base.
  </ResponseField>

  <ResponseField name="data.name" type="string">
    Updated name of the knowledge base.
  </ResponseField>

  <ResponseField name="data.description" type="string">
    Updated description of the knowledge base.
  </ResponseField>

  <ResponseField name="data.status" type="string">
    Current status: `"PROCESSING"`, `"COMPLETED"`, `"FAILED"`, or `"DELETED"`.
  </ResponseField>

  <ResponseField name="data.type" type="string">
    Type of knowledge base: `"FILE"`, `"WEB_SCRAPE"`, `"TEXT"`, or `"INTEGRATION"`.
  </ResponseField>

  <ResponseField name="data.source_urls" type="string">
    For web scrape type: the scraped URLs as a JSON-encoded array string.
  </ResponseField>

  <ResponseField name="data.base_url" type="string">
    Base URL for web scrape type.
  </ResponseField>

  <ResponseField name="data.metadata" type="object">
    Source metadata recorded during ingestion. May be `null`.
  </ResponseField>

  <ResponseField name="data.current_version_id" type="string">
    ID of the content version currently served.
  </ResponseField>

  <ResponseField name="data.chunk_count" type="number">
    Number of indexed chunks. `null` until processing completes.
  </ResponseField>

  <ResponseField name="data.sync_enabled" type="boolean">
    Whether scheduled re-sync is enabled (web scrape and integration sources).
  </ResponseField>

  <ResponseField name="data.last_sync_at" type="string">
    ISO timestamp of the last sync, or `null`.
  </ResponseField>

  <ResponseField name="data.persona_id" type="string">
    Set on persona-owned knowledge bases. Always `null` for knowledge bases you created.
  </ResponseField>

  <ResponseField name="data.ranking_config" type="object">
    Per-source retrieval configuration, or `null` for default hybrid retrieval.
  </ResponseField>

  <ResponseField name="data.created_at" type="string">
    ISO timestamp of creation.
  </ResponseField>

  <ResponseField name="data.updated_at" type="string">
    ISO timestamp of last update.
  </ResponseField>

  <ResponseField name="data.error_message" type="string">
    Error message if status is `"FAILED"`.
  </ResponseField>

  <ResponseField name="data.file" type="object">
    File information for file-type knowledge bases.

    <ResponseField name="data.file.file_name" type="string">
      Original filename.
    </ResponseField>

    <ResponseField name="data.file.file_size" type="number">
      File size in bytes.
    </ResponseField>

    <ResponseField name="data.file.file_type" type="string">
      MIME type of the file.
    </ResponseField>
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on successful update.
</ResponseField>

<Note>
An unknown knowledge base ID, or one owned by another organization, currently returns `500` with `"Failed to update KB"` rather than `404`.
</Note>

<RequestExample>

```bash Update Name Only
curl -X PUT https://api.bland.ai/v1/knowledge/3f1c2a9e-7b4d-4c1e-9a2b-1d5e6f7a8b9c \
  -H "authorization: YOUR_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "name": "Updated Company FAQs"
  }'
```

```json Update Both Name and Description
{
  "name": "Updated Company FAQs",
  "description": "Updated frequently asked questions and company policies for 2025"
}
```

```json Remove Description
{
  "name": "Company FAQs",
  "description": null
}
```

</RequestExample>
