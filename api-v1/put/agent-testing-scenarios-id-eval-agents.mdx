---
title: "Replace Scenario Eval Agents"
api: "PUT https://api.bland.ai/v1/agent-testing/scenarios/{id}/eval-agents"
description: "Replace every eval agent attached to a test scenario."
---

Replaces the scenario's full eval agent roster in one operation. Send an empty array to remove all attachments.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The scenario ID.
</ParamField>

## Body Parameters

Send either an array of attachment objects or an object with an `eval_agents` array.

<ParamField body="eval_agents" type="array" required>
  The complete replacement roster. Duplicate `eval_agent_id` values are rejected.

  <Expandable title="Eval agent fields">
    <ParamField body="eval_agent_id" type="string" required>
      Eval agent UUID.
    </ParamField>
    <ParamField body="eval_agent_version_id" type="string">
      Eval agent version UUID. Defaults to the agent's current version.
    </ParamField>
    <ParamField body="weight" type="number">
      Non-negative scoring weight. Defaults to the selected version's weight.
    </ParamField>
    <ParamField body="target_level_keys" type="string[]">
      Target level keys. Defaults to the selected version's targets.
    </ParamField>
    <ParamField body="order" type="integer">
      Display and scoring order. Defaults to the item's array position.
    </ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="data" type="array">
  The saved attachments. Each item contains `id`, `scenario_id`, `eval_agent_id`, `eval_agent_version_id`, `weight`, `target_level_keys`, `order`, and `created_at`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 400 for invalid or duplicate attachments and 404 for missing resources.
</ResponseField>
