---
title: "Create Widget"
api: "POST https://api.bland.ai/v1/widget"
description: "Creates a new widget."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

<Warning>
  Set exactly one of `pathway_id` or `agent_prompt`. The database enforces this rule, so sending both, or neither, fails with a `500 INTERNAL_SERVER_ERROR` rather than a validation error.
</Warning>

<ParamField body="pathway_id" type="string | null">
  UUID of the pathway the widget runs. Required if `agent_prompt` is not set.
</ParamField>

<ParamField body="agent_prompt" type="string | null">
  Prompt for a prompt-based widget agent. Required if `pathway_id` is not set.
</ParamField>

<ParamField body="allowed_domains" type="string[]" required>
  Domains the widget can be embedded on.
</ParamField>

<ParamField body="messages_per_minute" type="number" required>
  Rate limit for visitor messages (minimum: 0).
</ParamField>

<ParamField body="config" type="object" required>
  Widget configuration object. Any JSON object is accepted and stored, but only the keys below are read.

  <Expandable title="config keys">
    <ParamField body="timeoutSeconds" type="number" default={86400}>
      Seconds of inactivity before the conversation is ended.
    </ParamField>
    <ParamField body="timeoutMessage" type="string">
      Message shown to the visitor when the conversation times out.
    </ParamField>
    <ParamField body="timeoutWarningSeconds" type="number">
      Seconds of inactivity before `timeoutWarningMessage` is shown. Both must be set for the warning to fire.
    </ParamField>
    <ParamField body="timeoutWarningMessage" type="string">
      Warning message shown before the timeout.
    </ParamField>
    <ParamField body="voiceEnabled" type="boolean">
      Set to `false` to force chat-only mode even when `agent_id` is set.
    </ParamField>
    <ParamField body="styles" type="object">
      CSS overrides keyed by `widget`, `logo`, `panel`, and `headerLogo` (for example `{"panel": {"width": 380, "height": 600}}`).
    </ParamField>
    <ParamField body="primaryColor" type="string" default="#010414">
      Primary color as a CSS color value.
    </ParamField>
    <ParamField body="secondaryColor" type="string" default="#010414">
      Secondary color as a CSS color value.
    </ParamField>
    <ParamField body="hideFooter" type="boolean" default={false}>
      Hides the widget footer.
    </ParamField>
    <ParamField body="headerContent" type="string" default="Chat Support">
      Header text, or a URL to an image rendered in the header.
    </ParamField>
    <ParamField body="widgetIcon" type="string">
      URL of the icon shown on the launcher button.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="name" type="string | null">
  Display name for the widget.
</ParamField>

<ParamField body="agent_id" type="string">
  UUID of the [web agent](/api-v1/post/agents) that handles voice sessions for this widget.
</ParamField>

<ParamField body="webhook_url" type="string | null">
  HTTPS URL that receives post-conversation webhook payloads when conversations end. See [Post-Conversation Webhooks](/tutorials/chat-widget#post-conversation-webhooks) for payload details.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The created widget:

  - `id` (string): Widget UUID
  - `name` (string | null): Display name
  - `org_id` (string): Your organization UUID
  - `pathway_id` (string | null): Associated pathway UUID
  - `agent_prompt` (string | null): Prompt used instead of a pathway
  - `agent_id` (string | null): Associated web agent UUID
  - `allowed_domains` (string[]): Allowed embed domains
  - `messages_per_minute` (number): Visitor message rate limit
  - `config` (object): Widget configuration object
  - `webhook_url` (string | null): Post-conversation webhook URL
  - `placement_group` (string): Internal routing group
  - `created_at` (string): ISO timestamp
  - `updated_at` (string): ISO timestamp
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list of `{error, message}` objects.
</ResponseField>

### Error Codes

| Status | Error | Description |
|--------|-------|-------------|
| 400 | `INVALID_PARAMETERS` | Request body is missing. |
| 400 | `INVALID_PARAMETER` | Body failed schema validation (unknown keys are rejected). |
| 400 | `INVALID_WEBHOOK_URL` | `webhook_url` is not a well-formed HTTPS URL of 500 characters or fewer. |
| 500 | `INTERNAL_SERVER_ERROR` | Includes the case where both or neither of `pathway_id` and `agent_prompt` are set. |
