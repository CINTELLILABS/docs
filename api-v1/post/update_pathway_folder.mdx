---
title: "Update Folder"
api: "PATCH https://api.bland.ai/v1/pathway/folders/{folder_id}"
description: "Updates the name of a specific folder for the authenticated user."
---


### Headers
<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<Note>
Org members need the `admin`, `owner`, `operator`, or `prompter` role. Members with the `viewer` role receive a `403` with error code `UNAUTHORIZED`.
</Note>

### Path Parameters

<ParamField path="folder_id" type="string" required>
  The ID of the folder to update.
</ParamField>

### Body Parameters
<ParamField body="name" type="string" required>
  The new name for the folder.
</ParamField>

### Response
<ResponseField name="data.folder_id" type="string">
  The unique identifier of the updated folder.
</ResponseField>
<ResponseField name="data.name" type="string">
  The updated name of the folder.
</ResponseField>
<ResponseField name="data.parent_folder_id" type="string | null">
  The ID of the parent folder, or `null` for a top-level folder.
</ResponseField>
<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

### Errors

| Status | `error` | When |
|---|---|---|
| `400` | `UPDATE_FOLDER_BAD_REQUEST` | `name` is missing. |
| `403` | `UNAUTHORIZED` | The caller's org role cannot edit pathways. |
| `404` | `UPDATE_FOLDER_NOT_FOUND` | The folder does not exist or belongs to another account. |
| `500` | `UPDATE_FOLDER_INTERNAL_SERVER_ERROR` | Unexpected failure. |

<ResponseExample>
```json Response
{
  "data": {
    "folder_id": "updated_folder_123",
    "name": "Updated Folder Name",
    "parent_folder_id": null
  },
  "errors": null
}
```
</ResponseExample>
