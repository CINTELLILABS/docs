---
title: "Attach Scenario Eval Agent"
api: "POST https://api.bland.ai/v1/agent-testing/scenarios/{id}/eval-agents"
description: "Attach or update one eval agent on a test scenario."
---

Attaches one eval agent to a scenario. If the eval agent is already attached, this endpoint updates the existing attachment.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The scenario ID.
</ParamField>

## Body Parameters

<ParamField body="eval_agent_id" type="string" required>
  Eval agent UUID.
</ParamField>

<ParamField body="eval_agent_version_id" type="string">
  Eval agent version UUID. Defaults to the agent's current version.
</ParamField>

<ParamField body="weight" type="number">
  Non-negative scoring weight. Defaults to the selected version's weight.
</ParamField>

<ParamField body="target_level_keys" type="string[]">
  Target level keys. Defaults to the selected version's targets.
</ParamField>

<ParamField body="order" type="integer">
  Display and scoring order. Defaults to `0` for a new attachment.
</ParamField>

## Response

Returns `201 Created` with the saved attachment.

<ResponseField name="data" type="object">
  Contains `id`, `scenario_id`, `eval_agent_id`, `eval_agent_version_id`, `weight`, `target_level_keys`, `order`, and `created_at`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 400 for invalid values and 404 for a missing scenario, eval agent, or version.
</ResponseField>
