---
title: "Create Folder"
api: "POST https://api.bland.ai/v1/pathway/folders"
description: "Creates a new folder for the authenticated user."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<Note>
Org members need the `admin`, `owner`, `operator`, or `prompter` role. Members with the `viewer` role receive a `403` with error code `UNAUTHORIZED`.
</Note>

### Body Parameters

<ParamField body="name" type="string" required>
  The name of the new folder.
</ParamField>

<ParamField body="parent_folder_id" type="string">
  The ID of the parent folder, if creating a subfolder. Must belong to your account.
</ParamField>

### Response

<ResponseField name="data.folder_id" type="string">
  The unique identifier of the newly created folder.
</ResponseField>

<ResponseField name="data.name" type="string">
  The name of the newly created folder.
</ResponseField>

<ResponseField name="data.parent_folder_id" type="string | null">
  The ID of the parent folder, or `null` for a top-level folder.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

### Errors

| Status | `error` | When |
|---|---|---|
| `400` | `CREATE_FOLDER_BAD_REQUEST` | `name` is missing, or `parent_folder_id` is not one of your folders. |
| `403` | `UNAUTHORIZED` | The caller's org role cannot edit pathways. |
| `500` | `CREATE_FOLDER_INTERNAL_SERVER_ERROR` | Unexpected failure. |

<ResponseExample>
```json Response
{
  "data": {
    "folder_id": "new_folder_123",
    "name": "New Folder",
    "parent_folder_id": null
  },
  "errors": null
}
```
</ResponseExample>
