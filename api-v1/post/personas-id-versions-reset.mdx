---
title: "Reset Draft Persona Version"
api: "POST https://api.bland.ai/v1/personas/{persona_id}/versions/reset"
description: "Reset a persona's current draft from another version."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="persona_id" type="string" required>
  The unique identifier of the persona.
</ParamField>

### Body

<ParamField body="source_version_id" type="string" required>
  The ID of a version that belongs to this persona. Its prompts, pathway conditions, knowledge bases, call configuration, default tools, and skills replace those fields on the current draft.
</ParamField>

<Warning>
  Resetting a draft does not copy the source version's `memory_enabled`, `entity_schemas`, or `auth_config` values.
</Warning>

### Response

<ResponseField name="data" type="object">
  The updated draft version.
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list containing `INVALID_BODY`, `PERSONA_NOT_FOUND`, `SOURCE_VERSION_NOT_FOUND`, `NO_DRAFT_VERSION`, or `INTERNAL_SERVER_ERROR`.
</ResponseField>
