---
title: "Start Tornado Session"
api: "POST https://api.bland.ai/v1/agent-testing/tornado/start"
description: "Start an asynchronous pathway test, analysis, and repair loop."
---

Tornado mode runs scenarios, analyzes failures, applies pathway fixes, and retests until all scenarios pass or the session reaches a limit. Persona-only repair is not supported.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body Parameters

<ParamField body="pathway_id" type="string" required>
  Pathway to test and repair. A request containing only `persona_id` returns `400`.
</ParamField>

<ParamField body="persona_id" type="string">
  Optional persona scope for selecting scenarios.
</ParamField>

<ParamField body="scenario_ids" type="string[]">
  Specific scenarios to test. Maximum 50. If omitted or empty, all enabled scenarios in scope are used.
</ParamField>

<ParamField body="version_number" type="integer">
  Pathway version to start from.
</ParamField>

<ParamField body="max_iterations" type="integer" default="5">
  Maximum repair iterations. Values above 10 are clamped to 10.
</ParamField>

<ParamField body="timeout_ms" type="integer" default="900000">
  Session timeout in milliseconds. Values above 1,800,000 are clamped to 1,800,000.
</ParamField>

<Note>
  Only one tornado session can run for the same pathway and persona scope. A conflicting request returns `409`.
</Note>

### Response

Returns `202 Accepted`.

<ResponseField name="data.session_id" type="string">
  New tornado session UUID.
</ResponseField>

<ResponseField name="data.status" type="string">
  `RUNNING`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

<ResponseExample>
```json 202
{
  "data": {
    "session_id": "e1f2a3b4-5678-4cde-9012-3456789abcde",
    "status": "RUNNING"
  },

```
</ResponseExample>
