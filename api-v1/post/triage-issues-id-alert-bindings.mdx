---
title: "Link Alert to Issue"
api: "POST https://api.bland.ai/v1/triage/issues/{id}/alert-bindings"
description: "Link an active alert to a triage issue."
---

Links an active alert to an issue and records the alert's current name, severity, and status.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  Internal UUID of the issue.
</ParamField>

## Body Parameters

<ParamField body="active_alert_id" type="string" required>
  ID of the active alert to link.
</ParamField>

<ParamField body="alert_config_id" type="string" required>
  ID of the alert configuration that produced the active alert.
</ParamField>

## Response

Returns `201 Created` with the new manual binding.

<ResponseField name="data" type="object">
  Contains `id`, `issue_id`, `org_id`, `active_alert_id`, `alert_config_id`, `alert_name`, `current_severity`, `status`, `binding_mode`, `created_at`, and `updated_at`.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 404 if the issue or alert cannot be found, and 409 if alert bindings are not configured.
</ResponseField>
