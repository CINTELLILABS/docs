## Overview

Creates a Bland TTS voice clone from one or more audio samples. Sent as `multipart/form-data`. The new voice is private to your org and immediately usable with [Speak](/api-v2/post/tts).

Two cloning engines are available, selectable per request:

- **BTTS V3** (default), single sample of about 10 seconds, 30 languages, highest fidelity. Returned `service: "BTTS_V3"`.
- **BTTS V2**, exactly 1 WAV file, 17 languages. Returned `service: "BTTS_V2"`.

The full language list for each engine is in [List TTS Models](/api-v2/get/tts-models). Cantonese is served as a Chinese dialect mode through `zh` text and is not a separate entry.

## Form Fields

<ParamField body="name" type="string" required>
  Display name for the voice clone. 1-30 characters. Must be unique in your library.
</ParamField>

<ParamField body="audio_samples" type="file[]" required>
  Audio file or files. Constraints depend on the engine flag (see below). WAV format recommended.
</ParamField>

<ParamField body="gender" type="string">
  `male` or `female`. Optional but recommended; helps the underlying model.
</ParamField>

<ParamField body="description" type="string">
  Free-text description. Surfaced as additional context to the model for tone and style.
</ParamField>

<ParamField body="isBTTS_V3" type="boolean">
  Use the V3 engine. Default if no engine flag is set. Pass `"true"` as a multipart string.
</ParamField>

<ParamField body="isBTTS_V2" type="boolean">
  Use the V2 engine instead of V3. Pass `"true"` as a multipart string.
</ParamField>

<ParamField body="boost_language_consistency" type="boolean" default="true">
  V3 only. Controls how the clone is anchored at synthesis time.

  - `"true"` (default): **continuation** cloning. Bland transcribes your sample automatically and conditions every generation on the sample audio plus that transcript. Tightest voice match when the sample and the speech are in the same language. If the automatic transcript is empty, the clone request fails.
  - `"false"`: **reference** cloning. Timbre only, no transcript. This generalizes better across languages and is the right choice when the voice will speak a language other than the sample's, code-switch, or speak a language where automatic transcription is weak (Cantonese, for example).

  Pass `"false"` as a multipart string for any multilingual voice. You can inspect the automatic transcript afterward with `GET /v1/voices/:voice/clone` and correct it with `PATCH /v1/voices/:voice/clone/transcript` (body: `{ "transcript": "..." }`).
</ParamField>

## Engine constraints

Each engine validates `audio_samples` differently. Mismatched files will return a `Validation Error` before the clone is created.

<Accordion title="V3 (default)">
  - Exactly 1 audio file.
  - Accepted length: 1 to 60 seconds. About 10 seconds is ideal; the 1-second floor is a validation limit, not a quality floor.
  - Max 10 MB.
  - 30 languages. The sample should be in the language the voice will mostly speak.
</Accordion>

<Accordion title="V2 (isBTTS_V2=true)">
  - Exactly 1 audio file.
  - Accepted length: 3 to 60 seconds. About 10 seconds is ideal.
  - Max 10 MB.
  - 17 languages.
</Accordion>

<Note>
  For a voice that must speak several languages, or any language other than English, send `boost_language_consistency: "false"`. With the default on, a wrong automatic transcript of a non-English sample becomes part of the voice, which is the most common cause of a clone that sounds fine in the console and wrong in another language.
</Note>

## Response

Returns `200 OK` with the new voice on success.

<ResponseField name="data.voice_id" type="string">
  UUID of the new voice clone. Use it as `voice_id` in [Speak](/api-v2/post/tts).
</ResponseField>

<ResponseField name="data.name" type="string">
  The display name you provided.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

<ResponseExample>
```json Response
{
  "status": 200,
  "data": {
    "voice_id": "4cc89edf-c4b7-4df8-98c5-f8548fcd7c62",
    "name": "DocTestClone"
  },
  "errors": null
}
```

```json Validation Error
{
  "status": 400,
  "data": null,
  "errors": [
    { "error": "Validation Error", "message": "No files provided for voice cloning." }
  ]
}
```

```json Voice Limit Exceeded
{
  "status": 400,
  "data": null,
  "errors": [
    { "error": "Limit Exceeded", "message": "You have reached the maximum number of voices for your plan." }
  ]
}
```
</ResponseExample>
