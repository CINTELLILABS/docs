---
title: "Update Recording Preferences"
api: "POST https://api.bland.ai/v1/recordings/preferences"
description: "Update recording storage and live listen preferences for your organization."
---

<Note>
  You must be an organization owner or admin to update these preferences.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

All fields are optional. The endpoint merges the fields you provide into the organization's existing preferences.

<ParamField body="use_bland_url" type="boolean">
  Whether recording access uses a Bland-hosted URL.
</ParamField>

<ParamField body="recording_lifespan_days" type="number">
  Number of days to retain recordings. Pass `-1` for no expiration.
</ParamField>

<ParamField body="live_listen_enabled" type="boolean">
  Enable or disable [live listening](/api-v1/post/calls-id-listen) for the organization.
</ParamField>

<ParamField body="record_bland_call_only" type="boolean">
  Record only the Bland-managed portion of calls.
</ParamField>

### Response

<ResponseField name="data.preferences" type="object">
  The organization's complete preferences object after the update.
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success. Errors include `INVALID_USER` (400), `invalid_parameter` (400), `UNAUTHORIZED` (403), and `INTERNAL_SERVER_ERROR` (500).
</ResponseField>
