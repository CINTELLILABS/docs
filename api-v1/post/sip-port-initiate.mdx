---
title: "Initiate Port Request"
api: "POST https://api.bland.ai/v1/sip/port/initiate"
description: "Submit a number porting request to transfer phone numbers from another carrier to Bland."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

<ParamField body="phone_numbers" type="string[]" required>
  Phone numbers to port. Each must parse as a valid number and is normalized to E.164. Verify portability first with [Check Number Portability](/api-v1/get/sip-port-check).
</ParamField>

<ParamField body="losing_carrier_information" type="object" required>
  Account details at the current carrier, as they appear on the bill:
  - `customer_type` (string): `"Individual"` or `"Business"`
  - `customer_name` (string): the account holder or business name
  - `account_number` (string, optional): account number with the losing carrier
  - `account_telephone_number` (string): the main number on the carrier account
  - `authorized_representative` (string): full name of the person authorized to port the numbers
  - `authorized_representative_email` (string): email used for signing the Letter of Authorization
  - `address` (object): service address with `street`, `street_2` (optional), `city`, `state`, `zip`, `country`
</ParamField>

<ParamField body="target_port_in_date" type="string" required>
  Requested port date, `YYYY-MM-DD`. Must be at least 4 days from today.
</ParamField>

<ParamField body="documents" type="string[]" required>
  One or more `document_sid` values returned from [Upload Port Document](/api-v1/post/sip-port-document).
</ParamField>

<ParamField body="phone_number_pins" type="object">
  Map of E.164 phone number to the account PIN at the losing carrier, for numbers where [Check Number Portability](/api-v1/get/sip-port-check) reported `pin_required: true`.
</ParamField>

<ParamField body="notification_emails" type="string[]">
  Addresses that receive port status updates. Defaults to `[authorized_representative_email]`.
</ParamField>

<ParamField body="target_port_in_time_range_start" type="string">
  Optional start of the preferred porting time window on the target date.
</ParamField>

<ParamField body="target_port_in_time_range_end" type="string">
  Optional end of the preferred porting time window on the target date.
</ParamField>

### Response

<ResponseField name="port_request_id" type="string">
  Unique identifier for the port request. Use it with [List Port Requests](/api-v1/get/sip-port-requests) and [Cancel Port Request](/api-v1/delete/sip-port-cancel).
</ResponseField>

<ResponseField name="status" type="string">
  The carrier's initial request status, for example `"in_review"` or `"waiting_for_signature"`.
</ResponseField>

<ResponseField name="signature_url" type="string">
  URL for electronically signing the Letter of Authorization, or `null` if the carrier did not return one.
</ResponseField>

<ResponseField name="phone_numbers" type="array">
  One entry per number: `number` (E.164), `status` (string), and `port_in_phone_number_sid` (string or `null`).
</ResponseField>

Number porting typically takes 7 to 14 business days. Track progress with [List Port Requests](/api-v1/get/sip-port-requests).

### Error Responses

<ResponseField name="400 BAD_REQUEST" type="object">
  A required field is missing, or `losing_carrier_information.address` lacks `street`, `city`, `state`, `zip`, or `country`.
</ResponseField>

<ResponseField name="400 INVALID_PHONE_NUMBER" type="object">
  One of `phone_numbers` does not parse as a valid number.
</ResponseField>

<ResponseField name="502 TWILIO_PORT_ERROR" type="object">
  The carrier rejected the request. The message carries the carrier's reason, including a `target_port_in_date` earlier than 4 days from today.
</ResponseField>

```bash Example Request
curl -X POST https://api.bland.ai/v1/sip/port/initiate \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_numbers": ["+14150000000", "+14150000001"],
    "losing_carrier_information": {
      "customer_type": "Business",
      "customer_name": "Acme Corp",
      "account_number": "ACC-12345",
      "account_telephone_number": "+14150000000",
      "authorized_representative": "Jane Doe",
      "authorized_representative_email": "jane@acme.com",
      "address": {
        "street": "123 Main St",
        "street_2": "Suite 100",
        "city": "San Francisco",
        "state": "CA",
        "zip": "94105",
        "country": "US"
      }
    },
    "notification_emails": ["it@acme.com"],
    "target_port_in_date": "2026-03-20",
    "phone_number_pins": { "+14150000001": "1234" },
    "documents": ["RDxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"]
  }'
```
