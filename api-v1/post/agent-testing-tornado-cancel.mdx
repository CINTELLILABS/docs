---
title: "Cancel Tornado Session"
api: "POST https://api.bland.ai/v1/agent-testing/tornado/{id}/cancel"
description: "Cancel a running tornado session."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The tornado session ID.
</ParamField>

### Response

<ResponseField name="data.cancelled" type="boolean">
  Whether the session was successfully cancelled.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": { "cancelled": true },
  "errors": null
}
```
</ResponseExample>
