---
title: "Update Memory"
api: "POST https://api.bland.ai/v1/memory/{memory_id}/update"
description: "Update the name of an existing memory."
---

<Note>
  This endpoint belongs to the legacy Memory Store API, which is maintained for existing customers. For new integrations, use the [contact-based Memory API](/api-v1/post/memory-contact). The Memory router allows 100 requests per 15 minutes. Further requests return HTTP `429`. Your organization role must be admin, owner, or operator.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

Your organization role must be admin, owner, or operator.

### Path Parameters

<ParamField path="memory_id" type="string" required>
  The unique identifier of the memory to update.
</ParamField>

### Body Parameters

<ParamField body="name" type="string" required>
  The new name for the memory. Cannot be null or undefined.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated memory object.
</ResponseField>

<ResponseField name="data.id" type="string">
  Unique identifier for the memory.
</ResponseField>

<ResponseField name="data.name" type="string">
  Updated name of the memory.
</ResponseField>

<ResponseField name="data.created_at" type="string">
  ISO timestamp when the memory was originally created.
</ResponseField>

<ResponseField name="data.user_id" type="string">
  Unique identifier for the organization that owns the memory.
</ResponseField>

<ResponseField name="data.memory_duration" type="number">
  Currently under development.
</ResponseField>

<ResponseField name="errors" type="null">
  Error array (null on success).
</ResponseField>
