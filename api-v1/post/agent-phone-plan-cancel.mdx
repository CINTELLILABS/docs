---
title: "Cancel Agent Phone Plan"
api: "POST https://api.bland.ai/billing/cancel_agent_phone"
description: "Cancel your organization's Agent Phone Plan at the end of the billing period, with an optional offboarding survey."
---

### Overview

Cancels your organization's [Agent Phone Plan](/platform/agent-phone-plan) at the end of the current billing period. You keep the plan until then, and the \$29.99/month charge doesn't renew. There's no refund for the current period.

When the plan ends, your included phone number stays on your account. Calls on it still work, but it stops sending texts. Subscribing again turns texting back on.

You can answer a short, optional offboarding survey in the same request with `feedback`. If you leave it out, the response includes `cancellation_survey`, which lists the questions and their allowed answers. You can send your answers afterwards with [Submit Cancellation Feedback](/api-v1/post/agent-phone-plan-cancel-feedback). The survey never affects the cancel.

<Note>
Requires an organization API key that belongs to an admin or owner of the organization. A personal account key gets `403 FORBIDDEN`.
</Note>

<Tip>
If you're an agent canceling for a person, ask them the survey questions and pass their answers through. Don't answer on their behalf.
</Tip>

### Headers

<ParamField header="authorization" type="string" required>
  Your organization API key.
</ParamField>

### Body Parameters

<ParamField body="feedback" type="object">
  Optional answers to the offboarding survey. Every field is optional, and blank answers count as no answer. An invalid survey gets `400 BAD_REQUEST` and nothing is canceled.

  <Expandable title="properties">
    <ParamField body="use_cases" type="string[]">
      What the plan was mainly used for. Any of `answering_calls`, `booking_appointments`, `outbound_calls`, `texting`, `testing`, `other`.
    </ParamField>
    <ParamField body="use_case_other" type="string">
      What else it was used for, when `use_cases` includes `other`. Up to 500 characters.
    </ParamField>
    <ParamField body="reason" type="string">
      The main reason for canceling. One of `too_expensive`, `not_used_enough`, `did_not_work`, `switching_service`, `short_term`, `other`.
    </ParamField>
    <ParamField body="reason_detail" type="string">
      The service you're switching to (with `switching_service`), or the reason (with `other`). Up to 500 characters.
    </ParamField>
    <ParamField body="stay_suggestion" type="string">
      What would have made you stay. Up to 500 characters.
    </ParamField>
  </Expandable>
</ParamField>

### Response

<ResponseField name="data" type="object">
  Your plan after the cancel. `status` stays `active` until the billing period ends, then changes to `canceled`. `phone_number` is the number you keep.
</ResponseField>

<ResponseField name="data.cancellation_survey" type="object">
  Present only when you canceled without `feedback`. It lists the survey questions (`questions[]`, each with a `field`, `type`, `question`, and `options` for the select questions) and where to send the answers (`submit`). Text answers can be up to 500 characters.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

<RequestExample>
```bash With feedback
curl -X POST https://api.bland.ai/billing/cancel_agent_phone \
  -H "authorization: <org-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "feedback": {
      "use_cases": ["answering_calls"],
      "reason": "switching_service",
      "reason_detail": "Another voice provider",
      "stay_suggestion": "A cheaper tier"
    }
  }'
```

```bash Without feedback
curl -X POST https://api.bland.ai/billing/cancel_agent_phone \
  -H "authorization: <org-api-key>"
```
</RequestExample>
