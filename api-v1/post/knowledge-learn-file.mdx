---
title: "Upload File"
api: "POST https://api.bland.ai/v1/knowledge/learn"
description: "Creates a new knowledge base by uploading a file."
---

Upload a file to create a knowledge base that can be used to provide contextual information to your AI agents. Supported file formats include PDF, Word documents, text files, and more.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="content-type" type="string" required>
  Must be `multipart/form-data` for file uploads.
</ParamField>

### Body Parameters (multipart/form-data)

<ParamField body="type" type="string" required default="file">
  Must be `"file"` for file uploads.
</ParamField>

<ParamField body="name" type="string">
  KB name (defaults to filename if not provided).
</ParamField>

<ParamField body="description" type="string">
  Optional description of the knowledge base content.
</ParamField>

<ParamField body="file" type="file" required>
  The file to upload and process into a knowledge base. Maximum size is 20 MB.
</ParamField>

<ParamField body="csv_columns" type="string">
  For CSV uploads only. A JSON-encoded array of column names to ingest, for example `["question","answer"]`. Omit to ingest every column.
</ParamField>

### Limits

- Your plan caps the number of knowledge bases per organization (Start: 10, Build: 50, higher self-serve tiers: 100, Enterprise: effectively unlimited). Exceeding it returns `400` with `KB_UPLOAD_LIMIT_EXCEEDED`.
- Uploads are serialized per organization with a 10 second cooldown. A request during the cooldown returns `423` with `KB_UPLOAD_RATE_LIMITED`.

### Response

Processing is asynchronous. The response confirms that ingestion started; poll [Get Knowledge Base](/api-v1/get/knowledge-id) until `status` is `"COMPLETED"` or `"FAILED"`.

<ResponseField name="data" type="object">
  <ResponseField name="data.success" type="boolean">
    `true` when ingestion started.
  </ResponseField>

  <ResponseField name="data.message" type="string">
    `"FILE KB creation started successfully"`.
  </ResponseField>

  <ResponseField name="data.knowledge_base_id" type="string">
    Unique identifier for the new knowledge base.
  </ResponseField>

  <ResponseField name="data.version_id" type="string">
    Identifier of the initial content version.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on successful creation.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.bland.ai/v1/knowledge/learn \
  -H "authorization: YOUR_API_KEY" \
  -F "type=file" \
  -F "name=Company FAQs" \
  -F "description=Frequently asked questions and policies" \
  -F "file=@company_faqs.pdf"
```

```bash With Default Name
curl -X POST https://api.bland.ai/v1/knowledge/learn \
  -H "authorization: YOUR_API_KEY" \
  -F "type=file" \
  -F "description=Product documentation" \
  -F "file=@product_docs.pdf"
```

</RequestExample>
