---
title: 'Upload Text'
api: 'POST  https://api.bland.ai/v1/knowledgebases/upload'
description: 'Upload a text file as a new knowledge base item'
contentType: 'multipart/form-data'
---

Upload text files along with optional metadata like name and description.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

<ParamField body="file" type="file" required>
  The file to be uploaded. Must be a `.pdf`, `.docx`, `.xlsx`, `.txt`, `.md`, `.csv`, or `.json` file, up to 20 MB. Text files must be saved as UTF-8.

  Bland checks that the file's contents match its extension. A mismatched or unsupported file returns `400` with `INVALID_FILE_TYPE`. A file over 20 MB returns `413` with `FILE_TOO_LARGE`.
</ParamField>

<ParamField body="name" type="string">
  Name for the uploaded text file
</ParamField>

<ParamField body="description" type="string">
  Description for the uploaded text file
</ParamField>
