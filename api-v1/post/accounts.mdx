---
title: "Create Encrypted Key" 
api: "POST https://api.bland.ai/v1/accounts"
description: "Integrate your own Twilio account with Bland. See [Custom Twilio Integration](/tutorials/custom-twilio) for more information."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

Your organization role must be owner or admin.

### Body

<ParamField body="account_sid" type="string" required>
    Your Twilio account SID.
</ParamField>

<ParamField body="auth_token" type="string" required>
    Your Twilio auth token.
</ParamField>

<ParamField body="restricted_account_sid" type="string">
    A restricted Twilio API key SID in `SK` format. When provided, Bland validates its format but skips the live Twilio account check.
</ParamField>

<ParamField body="s3_role_arn" type="string">
    AWS IAM role ARN Bland can assume to store call recordings in your S3 bucket.
</ParamField>

### Response

<ResponseField body="encrypted_key" type="string">
    Your `encrypted_key` to store and use in future requests.
</ResponseField>

<ResponseField body="s3_external_id" type="string|null">
    External ID to use in the role trust policy when `s3_role_arn` is provided. Otherwise `null`.
</ResponseField>

### Errors

- `400` `BYOT_INSERT_FAILED`: invalid credentials, invalid field formats, or an organization role below owner or admin.
- `500` `UNEXPECTED_ERROR`: unexpected server error.

<ResponseExample>
```json
{
    "status": "success",
    "encrypted_key": "YOUR_ENCRYPTED_KEY",
    "s3_external_id": null
}
```
</ResponseExample>
