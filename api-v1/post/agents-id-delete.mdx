---
title: "Delete Web Agent"
api: "POST https://api.bland.ai/v1/agents/{agent_id}/delete"
description: "Delete a web agent."
---

<Note>
  Web Agents are the legacy inbound-based agent model, maintained for existing customers. They remain the voice backend for the [Web Chat Widget](/tutorials/chat-widget) (`agent_id` on [Create Widget](/api-v1/post/widget)). For phone calls, use [Send Call](/api-v1/post/calls) with a pathway or persona instead.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path

<ParamField path="agent_id" type="string" required>
  The web agent to delete.
</ParamField>

### Response

<ResponseField name="agent_id" type="string">
  The ID of the deleted agent.
</ResponseField>

### Error Codes

| Status | Body | Description |
|--------|------|-------------|
| 500 | `{"status": "error", "message": "Internal server error"}` | Unknown `agent_id` (there is no 404), or unexpected failure. |

```json Response
}
```
</ResponseExample>
