---
title: "Scrape Websites"
api: "POST https://api.bland.ai/v1/knowledge/learn"
description: "Creates a new knowledge base by scraping content from web URLs."
---

Create a knowledge base by scraping content from one or more web URLs. This is perfect for creating knowledge bases from documentation sites, blog posts, or other web-based content.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="content-type" type="string" required>
  Must be `application/json` for web scraping knowledge bases.
</ParamField>

### Body Parameters

<ParamField body="type" type="string" required default="web">
  Must be `"web"` for web scraping knowledge bases.
</ParamField>

<ParamField body="name" type="string" required>
  Name for the knowledge base.
</ParamField>

<ParamField body="description" type="string">
  Optional description of the knowledge base content.
</ParamField>

<ParamField body="urls" type="string[]" required>
  Array of URLs to scrape. Maximum 100 URLs (2000 for Enterprise organizations). All URLs must share the same registrable domain; subdomains are allowed. A malformed URL, a mixed-domain list, or too many URLs returns `400`.
</ParamField>

### Limits

- Your plan caps the number of knowledge bases per organization (Start: 10, Build: 50, higher self-serve tiers: 100, Enterprise: effectively unlimited). Exceeding it returns `400` with `KB_UPLOAD_LIMIT_EXCEEDED`.
- Uploads are serialized per organization with a 10 second cooldown. A request during the cooldown returns `423` with `KB_UPLOAD_RATE_LIMITED`.

### Response

Processing is asynchronous. The response confirms that ingestion started; poll [Get Knowledge Base](/api-v1/get/knowledge-id) until `status` is `"COMPLETED"` or `"FAILED"`.

<ResponseField name="data" type="object">
  <ResponseField name="data.success" type="boolean">
    `true` when ingestion started.
  </ResponseField>

  <ResponseField name="data.message" type="string">
    `"WEB_SCRAPE KB creation started successfully"`.
  </ResponseField>

  <ResponseField name="data.knowledge_base_id" type="string">
    Unique identifier for the new knowledge base.
  </ResponseField>

  <ResponseField name="data.version_id" type="string">
    Identifier of the initial content version.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on successful creation.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.bland.ai/v1/knowledge/learn \
  -H "authorization: YOUR_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "type": "web",
    "name": "Documentation",
    "description": "Complete product documentation",
    "urls": [
      "https://docs.example.com/overview",
      "https://docs.example.com/api-reference",
      "https://docs.example.com/tutorials"
    ]
  }'
```

```json Single URL
{
  "type": "web",
  "name": "Blog Posts",
  "description": "Latest company blog posts",
  "urls": [
    "https://example.com/blog/latest-features"
  ]
}
```

```json Multiple URLs
{
  "type": "web",
  "name": "Support Documentation",
  "description": "Customer support and FAQ pages",
  "urls": [
    "https://support.example.com/faq",
    "https://support.example.com/troubleshooting",
    "https://support.example.com/getting-started",
    "https://support.example.com/advanced-features"
  ]
}
```

</RequestExample>

<ResponseExample>

```json Success Response
{
  "data": {
    "success": true,
    "message": "WEB_SCRAPE KB creation started successfully",
    "knowledge_base_id": "3f1c2a9e-7b4d-4c1e-9a2b-1d5e6f7a8b9c",
    "version_id": "8c7d6e5f-4a3b-4c2d-9e1f-0a1b2c3d4e5f"
  },
  "errors": null
}
```

```json Too Many URLs (400)
{
  "data": null,
  "errors": [
    {
      "error": "KB_ERROR",
      "message": "Maximum 100 URLs allowed per KB"
    }
  ]
}
```

```json Mixed Domains (400)
{
  "data": null,
  "errors": [
    {
      "error": "KB_ERROR",
      "message": "All URLs must be from the same domain"
    }
  ]
}
```

```json Limit Exceeded (400)
{
  "data": null,
  "errors": [
    {
      "error": "KB_UPLOAD_LIMIT_EXCEEDED",
      "message": "You have reached the maximum number of knowledge bases. Please upgrade your plan to add more Knowledge Bases."
    }
  ]
}
```

```json Rate Limited (423)
{
  "data": null,
  "errors": [
    {
      "error": "KB_UPLOAD_RATE_LIMITED",
      "message": "Please wait 10 seconds between knowledge base uploads, or wait for your current upload to complete."
    }
  ]
}
```

</ResponseExample>
