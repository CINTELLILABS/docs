## Overview

Appends one or more audio samples to an existing legacy **BTTS V1** voice clone. Each sample is transcribed and stored alongside the voice's existing samples.

A V1 voice holds at most 5 samples in total. **BTTS V2** and **BTTS V3** voices are single-sample by design and reject this call; use [Clone Voice](/api-v1/post/clone) to create a new voice instead.

Sent as `multipart/form-data`.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. A bare key or `Bearer <key>` are both accepted.
</ParamField>

---

## Form Fields

<ParamField body="voice_id" type="string" required>
  UUID of the voice to add samples to. Must be a V1 voice your org owns. `voice` is accepted as an alias.
</ParamField>

<ParamField body="audio_samples" type="file[]" required>
  Audio files to append, up to 5 per request and 25 MB combined. Each file 1 to 60 seconds and at most 10 MB. The voice's sample count after this call cannot exceed 5.
</ParamField>

---

## Response

<ResponseField name="data" type="object">
  <Expandable title="data fields">
    <ResponseField name="status" type="string">
      `success`.
    </ResponseField>
    <ResponseField name="message" type="string">
      For example `"Added 2 samples to voice"`.
    </ResponseField>
    <ResponseField name="samples" type="array">
      The samples added by this call.

      <Expandable title="Sample fields">
        <ResponseField name="sample_id" type="string">
          UUID of the new sample.
        </ResponseField>
        <ResponseField name="transcription" type="string">
          Automatic transcription of the sample. Correct it with [Update Voice Sample Transcriptions](/api-v1/patch/voices-id-samples).
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `BAD_REQUEST` | 400 | `voice_id` is missing, or no `audio_samples` file was sent. |
| `INTERNAL_SERVER_ERROR` | 500 | The voice was not found or is not yours, the voice is not a V1 (`BTTS`) voice, the call would exceed 5 samples, a file failed a size or duration check, or processing failed. The message says which. |
