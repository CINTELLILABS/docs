---
title: "Edit Block Rule"
api: "POST https://api.bland.ai/v1/blocked_numbers/{block_id}/edit"
description: "Update attributes of an existing block rule."
---

<Info>
  You can only update `reason` and `is_active`. Phone numbers and scope (global/inbound) are immutable after creation.
</Info>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="block_id" type="string" required>
  The ID of the block rule to update, as returned by [Create Block Rules](/api-v1/post/blocked-numbers).
</ParamField>

### Body Parameters

Both keys must be present in the body; omitting either returns `400 VALIDATION_ERROR`. Send `null` for a field you do not want to change.

<ParamField body="reason" type="string|null" required>
  The new reason for the block. `null` leaves the existing reason unchanged.
</ParamField>

<ParamField body="is_active" type="boolean|null" required>
  Controls whether the block rule is currently enforced. Set to `false` to disable or `true` to re-enable. `null` leaves it unchanged.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated block rule object.
</ResponseField>

<ResponseField name="data.id" type="string">
  ID of the block rule.
</ResponseField>

<ResponseField name="data.blocked_number" type="string">
  The phone number being blocked.
</ResponseField>

<ResponseField name="data.is_global" type="boolean">
  Indicates if the block applies globally.
</ResponseField>

<ResponseField name="data.inbound_number" type="string|null">
  The specific inbound number the block applies to (if not global).
</ResponseField>

<ResponseField name="data.org_id" type="string">
  UUID of the owning organization.
</ResponseField>

<ResponseField name="data.reason" type="string|null">
  Reason for the block, if present.
</ResponseField>

<ResponseField name="data.is_active" type="boolean">
  Whether the block rule is currently active.
</ResponseField>

<ResponseField name="data.created_at" type="string">
  ISO timestamp when the rule was created.
</ResponseField>

<ResponseField name="data.updated_at" type="string">
  ISO timestamp of the last update.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success. Otherwise `data` is `null` and `errors` holds `400 VALIDATION_ERROR`, `404 BLOCK_NOT_FOUND` or `500 SERVICE_ERROR`.
</ResponseField>
