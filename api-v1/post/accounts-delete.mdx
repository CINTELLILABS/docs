---
title: "Delete Encrypted Key" 
api: "POST https://api.bland.ai/v1/accounts/delete"
description: "Disable an encrypted key for a Twilio account integration. See [Custom Twilio Integration](/tutorials/custom-twilio) for more information."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

Your organization role must be owner or admin.

<ParamField header="encrypted_key" type="string" required>
  The `encrypted_key` to delete. You can alternatively pass it in the `encrypted-key` header or request body.
  
  Learn more about BYOT [here](/tutorials/custom-twilio).
</ParamField>

### Response

<ResponseField body="status" type="string">
    The status of the request.

    - `success` - The encrypted key was successfully deleted.
    - `error` - There was an error deleting the encrypted key.
</ResponseField>

### Errors

- `400` `BYOT_DELETION_FAILED` with `Invalid encrypted_key`: the key is missing or invalid.
- `500` `UNEXPECTED_ERROR`: unexpected server error.

<ResponseExample>
```json
{
    "status": "success"
}
```

```json Invalid Key
{
  "data": null,
  "errors": [
    {
      "error": "BYOT_DELETION_FAILED",
      "message": "Invalid encrypted_key"
    }
  ]
}
```
</ResponseExample>
