---
title: "Delete Memory"
api: "POST https://api.bland.ai/v1/memory/{memory_id}/delete"
description: "Permanently delete an entire memory and all associated data including users, calls, and metadata."
---

<Note>
  This endpoint belongs to the legacy Memory Store API, which is maintained for existing customers. For new integrations, use the [contact-based Memory API](/api-v1/post/memory-contact). The Memory router allows 100 requests per 15 minutes. Further requests return HTTP `429`. Your organization role must be admin, owner, or operator.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

Your organization role must be admin, owner, or operator.

### Path Parameters

<ParamField path="memory_id" type="string" required>
  The unique identifier of the memory to delete.
</ParamField>

### Response

<ResponseField name="data" type="object">
  Response data confirming memory deletion.
</ResponseField>

<ResponseField name="data.message" type="string">
  Success message confirming memory was deleted.
</ResponseField>

<ResponseField name="errors" type="null">
  Error array (null on success).
</ResponseField>

<ResponseExample>
```json Response
{
  "data": {
    "message": "Memory deleted successfully"
  },
  "errors": null
}
```

```json Server Error
{
  "data": null,
  "errors": [
    {
      "error": "INTERNAL_ERROR",
      "message": "An unexpected error occurred"
    }
  ]
}
```
</ResponseExample>

### ⚠️ Warning

This action is **irreversible**. Deleting a memory will permanently remove:
- The memory itself and all its metadata
- All user entries and their associated data
- All call associations and summaries
- Any custom metadata and summaries

Make sure you have backed up any important data before proceeding with deletion.
