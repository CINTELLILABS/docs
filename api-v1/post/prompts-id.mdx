---
title: "Update Prompt"
api: "POST https://api.bland.ai/v1/prompts/{prompt_id}"
description: "Replace the text of a saved prompt."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="prompt_id" type="string" required>
  The unique identifier of the prompt you want to update.
</ParamField>

### Body

<ParamField body="prompt" type="string" required>
    The new prompt text. Replaces the stored text. The prompt's `name` cannot be changed with this endpoint.
</ParamField>

### Response

<ResponseField name="status" type="string">
    `success`.
</ResponseField>

<ResponseField name="prompt" type="object">
  The updated prompt.
</ResponseField>

<ResponseField name="prompt.id" type="string">
  The unique identifier of the prompt.
</ResponseField>

<ResponseField name="prompt.name" type="string">
  The name of the prompt.
</ResponseField>

<ResponseField name="prompt.prompt" type="string">
  The new prompt text.
</ResponseField>

<ResponseField name="prompt.last_updated" type="string">
  The time of last update.
</ResponseField>

### Errors

| Status | Body |
|---|---|
| `400` | `{"error": "Prompt is required"}` |
| `404` | `{"error": "Prompt not found"}` |
| `500` | `{"error": "Internal Server Error"}` |

<RequestExample>
```json Request
{
  "prompt": "You are a friendly receptionist for the Bland Bistro."
}
```
</RequestExample>

<ResponseExample>
```json Response
{
  "status": "success",
  "prompt": {
    "id": "PT-aa8fb0ac-0014-43c0-9268-543522ce7e27",
    "name": "My First Prompt",
    "prompt": "You are a friendly receptionist for the Bland Bistro.",
    "last_updated": "2024-05-12T22:52:49.004987+00:00"
  }
}
```
</ResponseExample>
