---
title: "Allow Masked Caller"
api: "POST https://api.bland.ai/v1/doorman/masked/{key}"
description: "Allow a single masked caller variant (for example, Anonymous or No Caller ID)."
---

<Info>
  Requires an org owner or admin. All seven masked caller variants are allowed by default. Use this endpoint after you've explicitly blocked a variant and want to re-enable it.
</Info>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="key" type="string" required>
  The masked caller variant to allow. One of: `anonymous`, `restricted`, `blocked`, `unknown`, `unavailable`, `private`, `no_caller_id`.
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bland.ai/v1/doorman/masked/anonymous \
  --header 'authorization: YOUR_BLAND_API_KEY'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
  The updated effective policy, including `masked_callers`, `prefixes`, and `available_masked_callers`.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success, or a list of error objects.
</ResponseField>
