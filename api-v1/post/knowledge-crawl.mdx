---
title: "Discover Sitemap URLs"
api: "POST https://api.bland.ai/v1/knowledge/crawl"
description: "Discovers URLs from a website's sitemap for web scraping."
---

Analyzes a website to discover available URLs from its sitemap. This is useful for finding all the pages available on a website before creating a web scraping knowledge base.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="content-type" type="string" required>
  Must be `application/json`.
</ParamField>

### Body Parameters

<ParamField body="url" type="string" required>
  The base URL of the website to discover sitemap URLs from. Must include a scheme and hostname.
</ParamField>

<ParamField body="limit" type="number" default="100">
  Maximum number of URLs to return, from 1 to 2000. Values outside that range return `400`.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <ResponseField name="data.urls" type="string[]">
    Discovered URLs, capped at `limit`.
  </ResponseField>

  <ResponseField name="data.total_count" type="number">
    Number of URLs in `urls`.
  </ResponseField>

  <ResponseField name="data.truncated" type="boolean">
    `true` when more URLs were discovered than `limit` allowed.
  </ResponseField>
</ResponseField>

<ResponseField name="errors" type="null">
  Will be `null` on successful discovery.
</ResponseField>

### Errors

| Status | `error` | When |
|---|---|---|
| 400 | `KB_ERROR` | Missing `url`, invalid URL format, or `limit` outside 1 to 2000 |
| 500 | `KB_ERROR` | Discovery failed upstream (`"Failed to discover sitemap URLs"`) |
| 500 | `SITEMAP_DISCOVERY_ERROR` | Unexpected server error |

<RequestExample>

```bash cURL
curl -X POST https://api.bland.ai/v1/knowledge/crawl \
  -H "authorization: YOUR_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "url": "https://example.com"
  }'
```

```json Request Body
{
  "url": "https://docs.example.com"
}
```

</RequestExample>

<ResponseExample>

```json Success Response
{
  "data": {
    "urls": [
      "https://example.com/",
      "https://example.com/about",
      "https://example.com/products",
      "https://example.com/docs/getting-started",
      "https://example.com/docs/api-reference"
    ],
    "total_count": 5,
    "truncated": false
  },
  "errors": null
}
```

```json Error Response
{
  "data": null,
  "errors": [
    {
      "error": "KB_ERROR",
      "message": "Invalid URL format"
    }
  ]
}
```

</ResponseExample>
