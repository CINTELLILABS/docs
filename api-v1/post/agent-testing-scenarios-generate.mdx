---
title: "Generate Scenario from Call"
api: "POST https://api.bland.ai/v1/agent-testing/scenarios/generate-from-call"
description: "Generate a test scenario from a historical call transcript using AI analysis."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

<ParamField body="call_id" type="string" required>
  UUID v4 of the historical call to generate a scenario from.
</ParamField>

<ParamField body="pathway_id" type="string">
  The pathway to bind the generated scenario to. At least one of `pathway_id`, `persona_id`, or `agent_id` is required.
</ParamField>

<ParamField body="persona_id" type="string">
  The persona to bind the generated scenario to.
</ParamField>

<ParamField body="agent_id" type="string">
  The voice agent to bind the generated scenario to.
</ParamField>

<ParamField body="include_request_data" type="boolean" default="false">
  Include safe request data extracted from the source call.
</ParamField>

<ParamField body="include_variable_assertions" type="boolean" default="false">
  Add assertions for variables observed on the source call.
</ParamField>

<ParamField body="include_llm_persona" type="boolean" default="false">
  Use an LLM to generate the tester persona. This option consumes one execution from the per-minute agent testing allowance.
</ParamField>

### Response

The response contains the generated scenario data. This data is **not yet saved**. Review it, then send it to [Create Test Scenario](/api-v1/post/agent-testing-scenarios).

<Note>
  Sensitive data such as phone numbers, webhook URLs, and API keys is automatically stripped from the generated `request_data`.
</Note>

<ResponseField name="data" type="object">
  <Expandable title="Generated scenario fields">

<ResponseField name="name" type="string">
  An AI-generated name summarizing the scenario.
</ResponseField>

<ResponseField name="description" type="string">
  An AI-generated description of what the scenario tests based on the call transcript.
</ResponseField>

<ResponseField name="category" type="string">
  The inferred category for the scenario (e.g., `HAPPY_PATH`, `EDGE_CASE`, `ANGRY_CALLER`).
</ResponseField>

<ResponseField name="tester_persona_prompt" type="string">
  An AI-generated prompt that instructs the simulated caller to replicate the behavior observed in the original call.
</ResponseField>

<ResponseField name="tester_persona_name" type="string">
  A name for the simulated caller persona derived from the call.
</ResponseField>

<ResponseField name="pathway_id" type="string">
  The pathway the scenario is bound to (if provided).
</ResponseField>

<ResponseField name="persona_id" type="string">
  The persona the scenario is bound to (if provided).
</ResponseField>

<ResponseField name="agent_id" type="string">
  The voice agent the scenario is bound to (if provided).
</ResponseField>

<ResponseField name="request_data" type="object">
  Request data extracted from the call with sensitive fields automatically removed.
</ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>
