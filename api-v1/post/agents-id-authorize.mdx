---
title: "Authorize a Web Agent Call"
api: "POST https://api.bland.ai/v1/agents/{agent_id}/authorize"
description: "Create a single-use session token for a client to talk with your web agent."
---

<Note>
  Web Agents are the legacy inbound-based agent model, maintained for existing customers. They remain the voice backend for the [Web Chat Widget](/tutorials/chat-widget) (`agent_id` on [Create Widget](/api-v1/post/widget)). For phone calls, use [Send Call](/api-v1/post/calls) with a pathway or persona instead.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.

  Example web call usage (client side):
```javascript
import { BlandWebClient } from 'bland-client-js-sdk';

const agentId = 'YOUR-AGENT-ID';
const sessionToken = 'YOUR-SESSION-TOKEN';


document.addEventListener('DOMContentLoaded', async () => {
    document.getElementById('btn').addEventListener('click', async () => {
        const blandClient = new BlandWebClient(
            agentId,
            sessionToken
        );
        await blandClient.initConversation({
            sampleRate: 44100,
        });
    });
});
```

</ParamField>

### Path

<ParamField path="agent_id" type="string" required>
  The web agent to authorize a call for.
</ParamField>

### Body

<ParamField body="request_data" type="object">
  Variables to be passed to this session.

  Example:
  ```json
  {
    "name": "John Doe"
  }
  ```
</ParamField>


### Response

<ResponseField name="token" type="string">
  The single-use session token that can be sent to the client.
</ResponseField>

### Error Codes

| Status | Body | Description |
|--------|------|-------------|
| 400 | `{"error": "Agent ID is required"}` | Missing `agent_id`. |
| 404 | `{"error": "Agent Not Found"}` | No agent with that ID in your account, or `request_data` failed validation. |
| 500 | `{"status": "error", "message": "Internal server error"}` | Unexpected failure. |

<ResponseExample>
```json Response
{
  "token": "22480c52-0ff1-4214-bcb7-50649b508432"
}
```
</ResponseExample>
