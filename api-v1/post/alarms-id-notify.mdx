---
title: "Test Alarm Notifications"
api: "POST https://api.bland.ai/v1/alarms/{id}/notify"
description: "Send a test alarm or recovery notification."
---

<Note>
  The Alarms API is available to Enterprise organizations only. Requests from other organizations return `403` with the error code `ENTERPRISE_REQUIRED`.
</Note>

### Rate limit

This endpoint is limited to 5 requests per 5 minutes per organization. Requests over the limit return `429` with the error code `TOO_MANY_REQUESTS`.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  Alarm configuration ID.
</ParamField>

### Body Parameters

<ParamField body="type" type="string" required>
  Notification type to test. Allowed values: `alarm`, `recovery`.
</ParamField>

### Response

<ResponseField name="data.success" type="boolean">
  Whether at least one configured delivery method succeeded.
</ResponseField>

<ResponseField name="data.message" type="string">
  Summary of the test result.
</ResponseField>

<ResponseField name="data.results" type="object">
  Delivery results by channel (`webhook`, `email`, `sms`).
</ResponseField>

<ResponseField name="data.results.webhook.success" type="boolean">
  Whether webhook delivery succeeded.
</ResponseField>

<ResponseField name="data.results.webhook.statusCode" type="number">
  HTTP status returned by the webhook endpoint, when available.
</ResponseField>

<ResponseField name="data.results.email.success" type="boolean">
  Whether email delivery succeeded.
</ResponseField>

<ResponseField name="data.results.email.sentTo" type="string[]">
  Recipient list used for the test email.
</ResponseField>

<ResponseField name="data.results.sms.success" type="boolean">
  Whether SMS delivery succeeded.
</ResponseField>

<ResponseField name="data.results.sms.sentTo" type="string[]">
  Recipient list used for the test SMS.
</ResponseField>

Each channel result also carries an `error` string when that channel failed. Only channels configured on the alarm appear in `results`.

<ResponseField name="errors" type="null|array">
  `null` on success. When no channel succeeds (or the alarm has no notification methods configured), the response is `400` with `data` still populated and `errors` containing `NOTIFICATION_TEST_FAILED`.
</ResponseField>

<ResponseExample>
```json Success
{
  "data": {
    "success": true,
    "message": "Alarm notification test completed: 2/2 methods successful",
    "results": {
      "webhook": {
        "success": true,
        "statusCode": 200
      },
      "email": {
        "success": true,
        "sentTo": ["alerts@example.com"]
      }
    }
  },
  "errors": null
}
```

```json Test Failed
{
  "data": {
    "success": false,
    "results": {},
    "message": "No notification methods configured for this alarm"
  },
  "errors": [
    {
      "error": "NOTIFICATION_TEST_FAILED",
      "message": "No notification methods configured for this alarm"
    }
  ]
}
```

```json Error
{
  "data": null,
  "errors": [
    {
      "error": "INVALID_NOTIFICATION_TYPE",
      "message": "type must be either 'alarm' or 'recovery'"
    }
  ]
}
```

```json Rate Limited
{
  "data": null,
  "errors": [
    {
      "error": "TOO_MANY_REQUESTS",
      "message": "Too many alarm notification tests. Please wait a few minutes and try again."
    }
  ]
}
```
</ResponseExample>
