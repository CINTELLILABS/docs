---
title: "Create Simulation Set"
api: "POST https://api.bland.ai/v1/agent-testing/simulation-sets"
description: "Run each test scenario several times to detect inconsistent behavior."
---

Creates an asynchronous simulation set. Each scenario runs the requested number of times.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body Parameters

<ParamField body="scenario_ids" type="string[]" required>
  Non-empty scenario IDs owned by your organization.
</ParamField>

<ParamField body="simulations_per_scenario" type="integer" required>
  Number of runs for each scenario. Must be at least 1.
</ParamField>

<ParamField body="pathway_id" type="string">
  Optional pathway scope stored on the simulation set.
</ParamField>

<ParamField body="persona_id" type="string">
  Optional persona scope stored on the simulation set.
</ParamField>

<ParamField body="version_number" type="integer">
  Pathway version to test.
</ParamField>

### Response

Returns `202 Accepted`.

<ResponseField name="data.simulation_set_id" type="string">
  New simulation set UUID.
</ResponseField>

<ResponseField name="data.batch_ids" type="string[]">
  Batch IDs created for the simulations.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns `403` if any scenario is missing or belongs to another organization.
</ResponseField>
