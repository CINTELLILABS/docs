---
title: "Remove Alert Binding"
api: "DELETE https://api.bland.ai/v1/triage/issues/{id}/alert-bindings/{bindingId}"
description: "Unlink an alert from a triage issue."
---

Removes an alert binding without deleting the issue or alert.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  Internal UUID of the issue.
</ParamField>

<ParamField path="bindingId" type="string" required>
  Internal UUID of the alert binding.
</ParamField>

## Response

Returns `204 No Content` on success. Returns 404 if the issue or binding does not exist in your organization.

<ResponseExample>
```http No Content
HTTP/1.1 204 No Content
```
</ResponseExample>
