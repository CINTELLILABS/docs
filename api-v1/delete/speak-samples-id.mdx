---
title: "Delete TTS Generation"
api: "DELETE https://api.bland.ai/v1/speak/samples/{id}"
description: "Delete one stored text-to-speech generation."
---

Deletes one stored generation owned by your organization. A missing generation and a generation owned by another organization both return the same `404`.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  Generation ID.
</ParamField>

### Response

<ResponseField name="data.status" type="string">
  `success`.
</ResponseField>

<ResponseField name="data.id" type="string">
  ID of the deleted generation.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `NOT_FOUND` | 404 | The generation does not exist or belongs to another organization. |
| `INTERNAL_SERVER_ERROR` | 500 | The generation could not be deleted. |

<ResponseExample>
```json Response
{
  "data": {
    "status": "success",
    "id": "a3f8c2d1-4b5e-6789-0abc-def012345678"
  },
  "errors": null
}
```
</ResponseExample>
