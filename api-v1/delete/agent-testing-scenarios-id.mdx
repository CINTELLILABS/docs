---
title: "Delete Test Scenario"
api: "DELETE https://api.bland.ai/v1/agent-testing/scenarios/{id}"
description: "Delete a test scenario and all related data."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The scenario ID (UUID v4). Deleting a scenario also deletes its assertions, runs, and assertion results.
</ParamField>

### Response

Returns `200 OK`. Returns `404 Not Found` if the scenario does not exist or belongs to another organization.

<ResponseField name="data" type="object">
  <Expandable title="data object">
    <ResponseField name="deleted" type="boolean">
      Always `true` on success.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="array">
  `null` on success. On failure, an array of `{ "error": "CODE", "message": "..." }` objects.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": {
    "deleted": true
  },
  "errors": null
}
```

```json Not Found
{
  "data": null,
  "errors": [
    {
      "error": "NOT_FOUND",
      "message": "Scenario not found"
    }
  ]
}
```
</ResponseExample>
