---
title: "Block Masked Caller"
api: "DELETE https://api.bland.ai/v1/doorman/masked/{key}"
description: "Block a single masked caller variant so calls from that placeholder are rejected."
---

<Info>
  Requires an org owner or admin. Once a variant is blocked, inbound calls that resolve to that placeholder identity are rejected before they reach an agent.
</Info>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="key" type="string" required>
  The masked caller variant to block. One of: `anonymous`, `restricted`, `blocked`, `unknown`, `unavailable`, `private`, `no_caller_id`.
</ParamField>

<RequestExample>
```bash cURL
curl --request DELETE \
  --url https://api.bland.ai/v1/doorman/masked/anonymous \
  --header 'authorization: YOUR_BLAND_API_KEY'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
  The updated effective policy, including `masked_callers`, `prefixes`, and `available_masked_callers`.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success, or a list of error objects.
</ResponseField>
