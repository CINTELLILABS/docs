---
title: "Delete Outcome"
api: "DELETE https://api.bland.ai/v1/dispositions/{id}"
description: "Delete an outcome."
---

A deleted outcome stops running and no longer appears in [List Outcomes](/api-v1/get/dispositions).

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The outcome ID.
</ParamField>

### Response

<ResponseField name="data.deleted" type="boolean">
  `true` when the outcome was deleted.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, otherwise an array of error objects.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": {
    "deleted": true
  },
  "errors": null
}
```

```json Not Found
{
  "data": null,
  "errors": [
    {
      "error": "NOT_FOUND",
      "message": "Disposition not found"
    }
  ]
}
```
</ResponseExample>
