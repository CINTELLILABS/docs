---
title: "Delete Pathway Version"
api: "DELETE https://api.bland.ai/v1/pathway/{pathway_id}/version/{version_id}"
description: "Marks a specific version of a pathway as archived, effectively deleting it from active use."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<Note>
Org members need the `admin`, `owner`, `operator`, or `prompter` role. Members with the `viewer` role receive a `403` with error code `UNAUTHORIZED`.
</Note>

### Path Parameters

<ParamField path="pathway_id" type="string" required>
  The ID of the pathway containing the version to be deleted.
</ParamField>

<ParamField path="version_id" type="integer" required>
  The version number of the version to archive (the `version_number` from [Get Pathway Versions](/api-v1/get/pathway_versions), not the `id`).
</ParamField>

### Response

Archived versions disappear from [Get Pathway Versions](/api-v1/get/pathway_versions) but are not hard-deleted. If the archived version was in staging, the staging slot is cleared.

<ResponseField name="status" type="string">
  `success` on success, `error` on failure.
</ResponseField>

<ResponseField name="message" type="string">
  `"Version deleted successfully"`.
</ResponseField>

### Errors

| Status | Body |
|---|---|
| `400` | `{"status": "error", "message": "Error deleting pathway versions"}` |
| `403` | `{"status": "error", "message": "Invalid pathway_id or you don't own this pathway"}` for an unknown id, or `"Unauthorized"` for a pathway you cannot access |
| `404` | `{"status": "error", "message": "Pathway version not found"}` |

<ResponseExample>
```json Response
{
  "status": "success",
  "message": "Version deleted successfully"
}
```
</ResponseExample>
