---
title: "Delete Persona"
api: "DELETE https://api.bland.ai/v1/personas/{persona_id}"
description: "Soft-delete a persona and detach its inbound phone numbers."
---

<Warning>
  This endpoint soft-deletes the persona and immediately detaches every inbound number assigned to it. Persona versions remain stored. The endpoint does not accept a `force` parameter and does not reject personas that are in use.
</Warning>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="persona_id" type="string" required>
  The unique identifier of the persona to delete.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The deletion result object.
  
  <Expandable title="deletion result">
    <ResponseField name="success" type="boolean">
      Whether the deletion was successful.
    </ResponseField>
    <ResponseField name="message" type="string">
      Confirmation message about the deletion.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list of error objects.
</ResponseField>

### Errors

| Status | `error` | When |
| --- | --- | --- |
| 400 | `MISSING_PERSONA_ID` | The path ID is missing |
| 404 | `PERSONA_NOT_FOUND` | No active persona with that ID belongs to your organization |
| 500 | `INTERNAL_SERVER_ERROR` | Unexpected failure |

<ResponseExample>
```json Success Response
{
  "data": {
    "success": true,
    "message": "Persona deleted successfully"
  },
  "errors": null
}
```

```json Error Response (Not Found)
{
  "data": null,
  "errors": [
    {
      "error": "PERSONA_NOT_FOUND",
      "message": "Persona not found"
    }
  ]
}
```
</ResponseExample>
