---
title: "Delete Conversation"
api: "DELETE https://api.bland.ai/v1/sms/conversations/{id}"
description: "Delete a specific conversation and all of its associated messages. This action is permanent."
---

<Note>
  Messaging is an Enterprise feature. Configuring a number for messaging (`POST /v1/sms/number/update`) and sending (`/send`, `/batch`) require an Enterprise plan. This endpoint itself is not plan-gated.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The ID of the conversation to delete.
</ParamField>

### Response

<ResponseField name="data" type="object">
  Confirmation message indicating the conversation and messages were deleted.
</ResponseField>

<ResponseField name="data.message" type="string">
  A human-readable success message.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success, or a list of error objects on failure.
</ResponseField>

The conversation's messages, webhook delivery log, and outcome runs are deleted with it.

### Errors

- `404` `CONVERSATION_NOT_FOUND`: the conversation does not exist or belongs to another organization.
- `500` `ERROR_DELETING_CONVERSATION`: unexpected server error.

<ResponseExample>
```json Response
{
  "data": {
    "message": "Conversation and all associated messages deleted successfully"
  },
  "errors": null
}
```
</ResponseExample>
