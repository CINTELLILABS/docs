---
title: "Delete Messages from Conversation"
api: "DELETE https://api.bland.ai/v1/sms/conversations/{id}/messages"
description: "Delete specific messages from an SMS conversation by their IDs."
---

<Note>
  Messaging is an Enterprise feature. Configuring a number for messaging (`POST /v1/sms/number/update`) and sending (`/send`, `/batch`) require an Enterprise plan. This endpoint itself is not plan-gated.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The ID of the conversation that contains the messages.
</ParamField>

### Body Parameters

<ParamField body="message_ids" type="string[]" required>
  A non-empty list of message IDs to mark as deleted. Use the `messages[].id` values returned by [Get Conversation](/api-v1/get/sms-conversations-id); these are strings, not integers. IDs that do not belong to the conversation are ignored.
</ParamField>

### Response

<ResponseField name="data" type="object">
  Object containing confirmation and the count of messages deleted.
</ResponseField>

<ResponseField name="data.message" type="string">
  A success message indicating how many messages were marked as deleted.
</ResponseField>

<ResponseField name="data.deleted_count" type="number">
  The number of messages successfully marked as deleted.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success, or a list of error objects on failure.
</ResponseField>

Deleted messages are hidden from [Get Conversation](/api-v1/get/sms-conversations-id) and no longer count toward `message_count`; they are not physically removed.

### Errors

- `400` `CONVERSATION_ID_REQUIRED`: no conversation ID in the path.
- `400` `MESSAGE_IDS_REQUIRED`: `message_ids` is missing, not an array, or empty.
- `404` `CONVERSATION_NOT_FOUND`: the conversation does not exist or belongs to another organization.
- `500` `ERROR_DELETING_MESSAGES`: unexpected server error (for example when `message_ids` contains non-string values).

<ResponseExample>
```json Response
{
  "data": {
    "message": "2 messages marked as deleted",
    "deleted_count": 2
  },
  "errors": null
}
```
</ResponseExample>
