---
title: "Delete Folder"
api: "DELETE https://us.api.bland.ai/v1/pathway/folders/{folder_id}"
description: "Deletes a folder. The folder can't have child folders or legacy pathways in it."
---

Scenarios from agents that are filed in the folder don't block the delete. They're taken out of the folder. See [List Scenario Folders](/api-v2/get/agents-library-scenario-folders).


### Headers
<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>
### Path Parameters
<ParamField path="folder_id" type="string" required>
  The ID of the folder to delete.
</ParamField>
### Response
<ResponseField name="folder_id" type="string">
  The ID of the deleted folder.
</ResponseField>
<ResponseExample>
```json Response
{
  "folder_id": "deleted_folder_123"
}
```
</ResponseExample>
