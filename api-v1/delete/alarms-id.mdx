---
title: "Delete Alarm"
api: "DELETE https://api.bland.ai/v1/alarms/{id}"
description: "Delete an alarm configuration."
---

<Note>
  The Alarms API is available to Enterprise organizations only. Requests from other organizations return `403` with the error code `ENTERPRISE_REQUIRED`.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  Alarm configuration ID.
</ParamField>

### Response

Returns a `204 No Content` response on success.

<ResponseExample>
```json Error
{
  "data": null,
  "errors": [
    {
      "error": "ALARM_NOT_FOUND",
      "message": "Alarm configuration not found"
    }
  ]
}
```
</ResponseExample>
