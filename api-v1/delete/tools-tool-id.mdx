---
title: "Delete Custom Tool"
api: "DELETE https://api.bland.ai/v1/tools/{tool_id}"
description: "Delete your Custom Tool."
---

<Note>
Custom Tools v1 is a legacy API maintained for existing customers. Built-in integration tools are managed with the [v2 Tools API](/api-v2/post/tools). Custom HTTP tools that call your own URL are still created and deleted through v1.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>


### Path Parameters
<ParamField path="tool_id" type="string" required>
    The ID of the Custom Tool you want to delete, with or without the `TL-` prefix. A tool that does not exist or belongs to another organization returns 404 `TOOL_NOT_FOUND`.
</ParamField>


### Response
<ResponseField name="status" type="string">
    `"success"` when the tool was deleted.
</ResponseField>

<ResponseField name="message" type="string">
    Confirmation message.
</ResponseField>

<ResponseField name="data" type="null">
    Always `null` on this endpoint.
</ResponseField>

<ResponseField name="errors" type="null">
    `null` on success.
</ResponseField>

<ResponseExample>
```json Success
{
    "status": "success",
    "message": "Tool has been deleted.",
    "data": null,
    "errors": null
}
```

```json Not found (404)
{
    "data": null,
    "errors": [
        {
            "error": "TOOL_NOT_FOUND",
            "message": "Tool not found"
        }
    ],
    "error": "Tool not found"
}
```
</ResponseExample>
