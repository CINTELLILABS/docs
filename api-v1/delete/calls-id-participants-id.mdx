---
title: "Remove Call Participant"
api: "DELETE https://api.bland.ai/v1/calls/{call_id}/participants/{participant_id}"
description: "Remove a participant from a live call."
---

<Note>
  Live participant management currently supports calls on the carrier-direct media path. Other telephony providers return `UNSUPPORTED_PROVIDER`.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="call_id" type="string" required>
  The ID of an active call owned by your organization.
</ParamField>

<ParamField path="participant_id" type="string" required>
  The participant's call SID.
</ParamField>

### Response

<ResponseField name="data.removed" type="boolean">
  `true` when the participant was removed.
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success. Errors include `UNSUPPORTED_PROVIDER` (400), `NOT_FOUND` (404), `CALL_ENDED` (409), and `PARTICIPANT_REMOVE_FAILED` (502).
</ResponseField>
