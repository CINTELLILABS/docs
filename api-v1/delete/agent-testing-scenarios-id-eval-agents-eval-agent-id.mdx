---
title: "Detach Scenario Eval Agent"
api: "DELETE https://api.bland.ai/v1/agent-testing/scenarios/{id}/eval-agents/{evalAgentId}"
description: "Detach an eval agent from a test scenario."
---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The scenario ID.
</ParamField>

<ParamField path="evalAgentId" type="string" required>
  The eval agent UUID.
</ParamField>

## Response

<ResponseField name="data.deleted" type="boolean">
  `true` when an attachment was removed. `false` when the eval agent was not attached.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns 404 if the scenario does not exist or belongs to another organization.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": {
    "deleted": true
  },
  "errors": null
}
```
</ResponseExample>
