---
title: "Update Migration Split Request Policy"
api: "PATCH https://api.bland.ai/v1/convo_pathway/{pathway_id}/migration_split"
description: "Change whether the request's call settings or the agent's win on traffic a migration split sends to an agent."
---

Changes only the `request_policy` of an existing migration split. The share of traffic and the agent stay as they are, so this request is accepted while a rollout is moving the pathway's share. The new policy applies from the next call. [Set Migration Split](/api-v1/put/convo-pathway-id-migration-split) describes what each policy does.

Requires an admin, owner, or operator role.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField header="content-type" type="string" required>
  Must be `application/json`.
</ParamField>

### Path Parameters

<ParamField path="pathway_id" type="string" required>
  The V1 pathway. Must be a UUID of a pathway in your organization. Returns `400 BAD_REQUEST` for an invalid UUID, `404 NOT_FOUND` for a pathway outside your organization, and `400 BAD_REQUEST` for a pathway that Bland compiled from a V2 agent.
</ParamField>

### Body Parameters

<ParamField body="request_policy" type="string" required>
  `honor` (the request's call settings win) or `agent_owned` (the agent's settings win). Any other value, or a missing value, returns `400 BAD_REQUEST`.
</ParamField>

### Response

<ResponseField name="data.migration_split" type="object">
  The split after the change.

  <Expandable title="migration split object">
    <ResponseField name="agent_id" type="string">
      The agent that receives the split traffic.
    </ResponseField>
    <ResponseField name="v2_percentage" type="integer">
      Percentage of the pathway's traffic sent to the agent.
    </ResponseField>
    <ResponseField name="request_policy" type="string">
      The new policy.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the last change.
    </ResponseField>
    <ResponseField name="rollout_id" type="string | null">
      ID of the rollout that is moving this pathway's share, or `null` when no rollout is in progress.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, or a list of error objects if the request failed. Returns `404 NOT_FOUND` when the pathway has no split. Create one with [Set Migration Split](/api-v1/put/convo-pathway-id-migration-split).
</ResponseField>
