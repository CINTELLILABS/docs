---
title: "Rename API Key"
api: "PATCH https://api.bland.ai/keys/rename"
description: "Change the name of an API key."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. Restricted keys cannot rename keys.
</ParamField>

### Body

<ParamField body="key" type="string" required>
  The first 14 characters of the key, as returned by [List API Keys](/api-v1/post/keys-list). Works for full-access and restricted keys.
</ParamField>

<ParamField body="name" type="string" required>
  The new name, up to 64 characters after trimming whitespace. It cannot be blank.
</ParamField>

### Response

<ResponseField name="data" type="null">
  `null` on success.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success. Returns `404` when the key is not found and `403` when you are not allowed to rename it.
</ResponseField>

<ResponseExample>
```json Response
{
  "data": null,
  "errors": null
}
```
</ResponseExample>
