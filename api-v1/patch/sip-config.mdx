---
title: "Update Advanced Config"
api: "PATCH https://api.bland.ai/v1/sip/config"
description: "Update advanced SIP configuration including failover, codecs, and alerts."
---

Only the keys you send are updated. Omitted keys keep their current value.

<Note>
  `failover_config` and `codec_config` are stored on the configuration but are not yet enforced at call time.
</Note>

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Body

<ParamField body="phone_number" type="string" required>
  The phone number to update configuration for. Must parse as an E.164 number.
</ParamField>

<ParamField body="direction" type="string" required>
  The direction to update: `"inbound"` or `"outbound"`.
</ParamField>

<ParamField body="failover_config" type="object">
  Failover configuration:
  - `enabled` (boolean)
  - `endpoints` (array): each with `host` (string), `port` (number), `transport` (`"udp"`, `"tcp"`, or `"tls"`), and `priority` (number)
  - `triggers` (string[]): conditions that trigger failover
  - `failback` (string): `"auto"` or `"manual"`
</ParamField>

<ParamField body="codec_config" type="object">
  Codec configuration:
  - `codecs` (string[]): ordered list of codec names
  - `transcode` (boolean)
</ParamField>

<ParamField body="alert_config" type="object">
  Alert configuration:
  - `enabled` (boolean)
  - `thresholds` (object): `unreachable_minutes`, `failure_rate_percent`, `failure_rate_window_minutes`, `response_time_ms` (all numbers)
  - `channels` (object): `email` (string, address), `sms` (string, phone number), `webhook` (string, URL)
</ParamField>

At least one of `failover_config`, `codec_config`, or `alert_config` is required.

### Response

The updated SIP configuration record for that number and direction: `id`, `org_id`, `number`, `direction`, `sip_endpoint`, `headers`, `options`, `trunk_id`, `failover_config`, `codec_config`, `alert_config`, `created_at`, `updated_at`, plus the internal `inbound_id`.

### Error Responses

<ResponseField name="400 BAD_REQUEST" type="object">
  `phone_number` or `direction` is missing, `phone_number` is not a valid number, or none of the three config objects was sent (`"No valid fields to update"`).
</ResponseField>

<ResponseField name="404 NOT_FOUND" type="object">
  No SIP configuration exists for that number and direction.
</ResponseField>

```bash Example Request
curl -X PATCH https://api.bland.ai/v1/sip/config \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "+14150000000",
    "direction": "outbound",
    "failover_config": {
      "enabled": true,
      "endpoints": [
        { "host": "backup1.sip.provider.com", "port": 5061, "transport": "tls", "priority": 1 },
        { "host": "backup2.sip.provider.com", "port": 5061, "transport": "tls", "priority": 2 }
      ],
      "triggers": ["unreachable", "timeout"],
      "failback": "auto"
    },
    "codec_config": {
      "codecs": ["PCMU", "PCMA", "Opus"],
      "transcode": true
    },
    "alert_config": {
      "enabled": true,
      "thresholds": {
        "unreachable_minutes": 5,
        "failure_rate_percent": 20,
        "failure_rate_window_minutes": 30,
        "response_time_ms": 500
      },
      "channels": {
        "email": "ops@example.com",
        "sms": "+14155550100",
        "webhook": "https://hooks.example.com/sip-alerts"
      }
    }
  }'
```
