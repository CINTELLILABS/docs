---
title: "Update Widget"
api: "PATCH https://api.bland.ai/v1/widget/{id}"
description: "Updates an existing widget. All fields in the request body are optional."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  UUID of the widget to update.
</ParamField>

### Body

<Warning>
  A widget must have exactly one of `pathway_id` or `agent_prompt` set after the update. To switch a pathway widget to a prompt, send `agent_prompt` together with `pathway_id: null` (and the reverse). Leaving both set fails with a `500 INTERNAL_SERVER_ERROR`.
</Warning>

<ParamField body="pathway_id" type="string | null">
  New pathway UUID for the widget. Pass `null` to clear it when switching to `agent_prompt`.
</ParamField>

<ParamField body="agent_prompt" type="string | null">
  New prompt for a prompt-based widget agent. Pass `null` to clear it when switching to `pathway_id`.
</ParamField>

<ParamField body="name" type="string | null">
  New display name for the widget.
</ParamField>

<ParamField body="allowed_domains" type="string[]">
  New list of domains the widget can be embedded on.
</ParamField>

<ParamField body="messages_per_minute" type="number">
  New visitor message rate limit (minimum: 0).
</ParamField>

<ParamField body="config" type="object">
  New widget configuration object. It replaces the stored object; it is not merged. See [Create Widget](/api-v1/post/widget#body) for the keys that are read (`timeoutSeconds`, `timeoutMessage`, `timeoutWarningSeconds`, `timeoutWarningMessage`, `voiceEnabled`, `styles`, `primaryColor`, `secondaryColor`, `hideFooter`, `headerContent`, `widgetIcon`).
</ParamField>

<ParamField body="agent_id" type="string">
  New web agent UUID for voice sessions.
</ParamField>

<ParamField body="webhook_url" type="string | null">
  New HTTPS URL for post-conversation webhook payloads. See [Post-Conversation Webhooks](/tutorials/chat-widget#post-conversation-webhooks) for payload details.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated widget. Same fields as [Create Widget](/api-v1/post/widget#response).
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list of `{error, message}` objects.
</ResponseField>

### Error Codes

| Status | Error | Description |
|--------|-------|-------------|
| 400 | `INVALID_PARAMETERS` | Request body is missing. |
| 400 | `INVALID_PARAMETER` | Body failed schema validation (unknown keys are rejected). |
| 400 | `INVALID_WEBHOOK_URL` | `webhook_url` is not a well-formed HTTPS URL of 500 characters or fewer. |
| 404 | `NOT_FOUND` | No widget with that ID in your organization. |
| 500 | `INTERNAL_SERVER_ERROR` | Includes the case where both or neither of `pathway_id` and `agent_prompt` end up set. |
