---
title: "Update SMS Conversation"
api: "PATCH https://api.bland.ai/v1/sms/conversations/{conversation_id}"
description: "Updates properties of an existing SMS conversation."
---

<Note>
  Messaging is an Enterprise feature. Configuring a number for messaging (`POST /v1/sms/number/update`) and sending (`/send`, `/batch`) require an Enterprise plan. This endpoint itself is not plan-gated.
</Note>

### Headers
<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters
<ParamField path="conversation_id" type="string" required>
  The unique identifier of the SMS conversation to update.
</ParamField>

### Body Parameters
<ParamField body="is_active" type="boolean" required>
  Sets the active status of the conversation. When set to `false`, the conversation is marked as inactive. Must be a boolean; any other value is rejected with `INVALID_IS_ACTIVE_VALUE`.
</ParamField>

### Response
<ResponseField name="data" type="object">
  Confirmation and the updated conversation values.
</ResponseField>

<ResponseField name="data.message" type="string">
  Confirmation message indicating the conversation was updated successfully.
</ResponseField>

<ResponseField name="data.conversation" type="object">
  The updated conversation object containing the new values.
</ResponseField>

<ResponseField name="data.conversation.id" type="string">
  The unique identifier of the conversation.
</ResponseField>

<ResponseField name="data.conversation.is_active" type="boolean">
  The current active status of the conversation.
</ResponseField>

<ResponseField name="data.conversation.updated_at" type="string">
  ISO 8601 timestamp of when the conversation was last updated.
</ResponseField>

<ResponseField name="errors" type="null|array">
  `null` on success, or a list of error objects on failure.
</ResponseField>

### Errors

- `400` `CONVERSATION_ID_REQUIRED`: no conversation ID in the path.
- `400` `INVALID_IS_ACTIVE_VALUE`: `is_active` is missing or not a boolean.
- `404` `CONVERSATION_NOT_FOUND`: the conversation does not exist or belongs to another organization.
- `500` `ERROR_UPDATING_CONVERSATION`: unexpected server error.

<ResponseExample>
```json Success Response
{
  "data": {
    "message": "Conversation updated successfully",
    "conversation": {
      "id": "conv_1234567890",
      "is_active": false,
      "updated_at": "2024-01-15T10:30:00.000Z"
    }
  },
  "errors": null
}
```

```json 400 Error Response
{
  "data": null,
  "errors": [
    {
      "message": "is_active must be a boolean value",
      "error": "INVALID_IS_ACTIVE_VALUE"
    }
  ]
}
```

```json 404 Error Response
{
  "data": null,
  "errors": [
    {
      "message": "Conversation not found",
      "error": "CONVERSATION_NOT_FOUND"
    }
  ]
}
```
</ResponseExample>
