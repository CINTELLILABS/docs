---
title: "Update Outcome"
api: "PATCH https://api.bland.ai/v1/dispositions/{id}"
description: "Rename an outcome, replace its script or change its metadata."
---

Send only the fields you want to change. Updating `script` saves a new version and increases `snippet_version` by 1. Runs after that use the new version.

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The outcome ID.
</ParamField>

### Body Parameters

<ParamField body="name" type="string">
  A new name. 1 to 100 characters, letters and underscores only.
</ParamField>

<ParamField body="script" type="string">
  The new JavaScript source, up to 400,000 characters. It follows the same rules as [Create Outcome](/api-v1/post/dispositions).
</ParamField>

<ParamField body="metadata" type="object">
  Replaces the stored metadata.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated outcome, with the same fields as [Create Outcome](/api-v1/post/dispositions) returns.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success, otherwise an array of error objects.
</ResponseField>
