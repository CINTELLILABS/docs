## Overview

Updates the default synthesis settings stored on a voice clone. These defaults are applied when [Synthesize Speech](/api-v2/post/tts) is called without per-request overrides.

Equivalent to [Update Voice Settings](/api-v1/post/voices-id-settings) (`POST /v1/voices/{id}/settings`). Both share the same write path; `POST /settings` is the canonical form. This `PATCH /config` route is kept for backwards compatibility.

The accepted parameters depend on the voice's engine:

- **BTTS V1** voices accept `consistency` (0 to 1) and `expressiveness` (0 to 1).
- **BTTS V2** voices accept `consistency` (0 to 64, stored as `per_decode`) and `expressiveness` (0 to 1, stored as `boost`).
- **BTTS V3** voices accept only `boost_language_consistency`. Sending `consistency` or `expressiveness` to a V3 voice returns `400 VOICE_CONFIG_UPDATE_ERROR`.

Only cloned voices owned by your org can be configured.

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication. The key's user must be an owner or admin of the org.
</ParamField>

---

## Path Parameters

<ParamField path="id" type="string" required>
  UUID of the voice to configure.
</ParamField>

---

## Body Parameters

At least one field is required.

<ParamField body="consistency" type="number">
  Default consistency. 0 to 1 for V1 voices; 0 to 64 for V2 voices (lower is more consistent).
</ParamField>

<ParamField body="expressiveness" type="number">
  Default expressiveness, 0 to 1. V1 and V2 voices.
</ParamField>

<ParamField body="boost_language_consistency" type="boolean">
  V3 voices only. `true` (the default for new clones) keeps the clone on continuation cloning, which follows the reference transcript closely. `false` switches it to reference cloning, which generalizes better across languages with slightly looser voice mimicry.
</ParamField>

---

## Response

<ResponseField name="status" type="string">
  `success` on success.
</ResponseField>

<ResponseField name="message" type="string">
  `"Voice configuration updated successfully"`.
</ResponseField>

<ResponseField name="voice" type="object">
  The updated voice. See [Get Voice](/api-v1/get/voices-id#response) for the full field list.
</ResponseField>

### Errors

| Code | HTTP | Meaning |
|---|---|---|
| `INVALID_REQUEST` | 400 | No field was provided. |
| `INVALID_CONSISTENCY` | 400 | `consistency` is not a number in range for the engine. |
| `INVALID_EXPRESSIVENESS` | 400 | `expressiveness` is not a number between 0 and 1. |
| `INVALID_BOOST_LANGUAGE_CONSISTENCY` | 400 | `boost_language_consistency` is not a boolean. |
| `VOICE_CONFIG_UPDATE_ERROR` | 400 | The voice was not found, is not a cloned voice you own, or the fields do not apply to its engine. |
| `UNEXPECTED_ERROR` | 500 | The update failed. |
