---
title: "Rename Voice"
api: "PATCH https://api.bland.ai/v1/voices/{id}/rename"
description: "Update the display name and optional description of a cloned voice you own."
---

## Overview

Updates a voice clone in your library. You can change the display name and, optionally, the description in the same request. Only voices owned by your org can be updated; default and shared-library voices return `403`.

---

## Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

---

## Path Parameters

<ParamField path="id" type="string" required>
  UUID of the voice to update.
</ParamField>

---

## Body Parameters

<ParamField body="name" type="string" required>
  New display name. 1-30 characters. Must be unique within your library.
</ParamField>

<ParamField body="description" type="string">
  Optional new description for the voice. Leading and trailing whitespace is trimmed. Omit the field to leave the existing description unchanged.
</ParamField>

---

## Response

<ResponseField name="data.name" type="string">
  The updated display name.
</ResponseField>

<ResponseField name="data.voice_id" type="string">
  UUID of the updated voice.
</ResponseField>

<ResponseField name="data.description" type="string | null">
  The current description on the voice after the update.
</ResponseField>

<ResponseField name="errors" type="null | array">
  `null` on success.
</ResponseField>

<RequestExample>
```json Name only
{
  "name": "DocTestRename"
}
```

```json Name and description
{
  "name": "DocTestRename",
  "description": "Warm, mid-pitch narrator voice for onboarding calls."
}
```
</RequestExample>

<ResponseExample>
```json Response
{
  "data": {
    "name": "DocTestRename",
    "voice_id": "73d4c04b-1e15-4272-9c7f-8d2955914ba9",
    "description": "Warm, mid-pitch narrator voice for onboarding calls."
  },
  "errors": null
}
```

```json Name Taken
{
  "data": null,
  "errors": [
    { "error": "Validation Error", "message": "Voice name is already taken" }
  ]
}
```
</ResponseExample>
