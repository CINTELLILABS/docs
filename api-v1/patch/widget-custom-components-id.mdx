---
title: "Update Custom Component"
api: "PATCH https://api.bland.ai/v1/widget/custom_components/{id}"
description: "Updates a specific custom component by ID. All body fields are optional, but the body cannot be empty."
---

### Headers

<ParamField header="authorization" type="string" required>
  Your API key for authentication.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  UUID of the custom component to update.
</ParamField>

### Body

<ParamField body="widget_id" type="string">
  UUID of the widget to attach the component to. Must belong to your organization.
</ParamField>

<ParamField body="pathway_id" type="string">
  UUID of the pathway the component belongs to. Must belong to your organization.
</ParamField>

<ParamField body="pathway_node" type="string">
  Pathway node ID to display the custom component on.
</ParamField>

<ParamField body="width" type="string">
  Component width as a CSS value (e.g. `"100%"`, `"500px"`) or `"auto"`.
</ParamField>

<ParamField body="height" type="string">
  Component height as a CSS value (e.g. `"300px"`, `"100%"`) or `"auto"`.
</ParamField>

<ParamField body="variables" type="string[]">
  Agent variable names to pass into the iframe URL as query params.
</ParamField>

<ParamField body="iframe_url" type="string">
  URL for the iframe source.
</ParamField>

<ParamField body="component_type" type="string">
  Component type label.
</ParamField>

<ParamField body="component_config" type="object">
  Free-form configuration object stored with the component.
</ParamField>

### Response

<ResponseField name="data" type="object">
  The updated custom component:

  - `id` (string): Custom component UUID
  - `org_id` (string): Organization UUID
  - `widget_id` (string): Widget UUID
  - `pathway_id` (string): Associated pathway UUID
  - `pathway_node` (string): Pathway node ID to display the custom component on
  - `width` (string): Component width (CSS value or `"auto"`)
  - `height` (string): Component height (CSS value or `"auto"`)
  - `variables` (string[]): Variable names passed into the iframe URL as query params
  - `iframe_url` (string): URL for the iframe source
  - `component_type` (string | null): Component type label
  - `component_config` (object | null): Free-form component configuration
  - `created_at` (string): ISO timestamp
  - `updated_at` (string): ISO timestamp
</ResponseField>

<ResponseField name="errors" type="array | null">
  `null` on success, or a list of `{error, message}` objects.
</ResponseField>

### Error Codes

| Status | Error | Description |
|--------|-------|-------------|
| 400 | `INVALID_PARAMETER` | Body is empty, or failed schema validation (unknown keys are rejected). |
| 403 | `FORBIDDEN` | `pathway_id` or `widget_id` does not belong to your organization. |
| 500 | `SERVER_ERROR` | Unexpected failure. An unknown component ID currently returns this status rather than 404. |
