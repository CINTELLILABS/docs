---
title: "Update Organization Members"  
api: "PATCH https://api.bland.ai/v1/orgs/{org_id}/members"  
description: "Add or remove members from an organization."  
---

### Headers

<ParamField header="authorization" type="string" required>  
  Your API key for authentication.  
</ParamField>  

### Path Parameters

<ParamField path="org_id" type="string" required>  
  The unique identifier of the organization.  
</ParamField>  

### Body

<ParamField body="action" type="string" required>  
  The action to perform.  
  <br/>Valid values: `"add"`, `"remove"`  
</ParamField>  

<ParamField body="target" type="string" required>  
  Who to add or remove. Accepts an existing user ID, a phone number (E.164 format, e.g. `+14155550123`), or an email address.  
  <br/>When you pass a phone number or email that doesn't match an existing user, an invitation is created. Phone number invitees receive an SMS, and email invitees receive a sign-up link. Invitees are automatically added to the organization when they sign up with the same phone number or email.  
</ParamField>  

<ParamField body="permissions" type="string[]">  
  A list of permissions to assign when adding a member.  
  <br/>Optional. If you leave it out, the member gets the organization's default member role.  
  <br/>Valid values: `"admin"`, `"operator"`, `"prompter"`, `"viewer"`. See [Roles and permissions](/platform/roles-and-permissions) for what each role can do.  
</ParamField>  

<ParamField body="is_invite" type="boolean">  
  Whether the removal applies to an invite instead of a full member.  
  <br/>Required only when `action` is `"remove"`.  
</ParamField>  

### Response

<ResponseField name="data" type="object">  
  The result of the update.  

  <Expandable title="data object">
    <ResponseField name="isInvite" type="boolean">
      Whether the call created or removed an invitation instead of a full member.
    </ResponseField>
    <ResponseField name="removed" type="boolean">
      Returned when `action` is `"remove"`. Always `true`: the member is no longer in the organization.
    </ResponseField>
    <ResponseField name="alreadyRemoved" type="boolean">
      Returned when `action` is `"remove"`. `true` when the user was removed earlier and this call only retried the access cleanup steps.
    </ResponseField>
    <ResponseField name="cleanupFailures" type="string[]">
      Returned when `action` is `"remove"`. The steps that failed while revoking the removed member's access. Empty when every step succeeded.
      <br/>Possible values: `"sso_account_links"` (their SSO account links), `"org_api_keys"` (their full-access API keys for the organization), `"session_active_org"` (the organization selected in their signed-in sessions).
      <br/>Call the endpoint again with the same `target` to retry the failed steps.
    </ResponseField>
  </Expandable>
</ResponseField>  

<ResponseField name="errors" type="array">  
  `null` on success. On failure, an error with code `ORG_MEMBER_UPDATE_FAILURE`. Returns `403` when the caller isn't an owner or admin (members can still remove themselves), and `404` when the target isn't a member of the organization. If the membership itself can't be deleted, the removal fails and the member stays in the organization.  
</ResponseField>  

<ResponseExample>  

```json Response  
{
  "data": {
    "isInvite": false,
    "removed": true,
    "alreadyRemoved": false,
    "cleanupFailures": []
  },
  "errors": null
}
```
</ResponseExample>
