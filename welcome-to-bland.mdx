{/*
  The docs front door. A full-width splash rather than an article: hero, six
  routes into the documentation, two CTAs.

  THE COPY IS MEG'S AND IS FINAL. Eyebrow, headline, subhead, both CTA labels
  and all six card titles and bodies are hers, delivered verbatim. Do not
  reword any of it.

  Everything visual is in style.css at the repo root, which Mintlify inlines
  into every page. A <style> block inside an .mdx is stripped without warning,
  which is why none of this is local to the file.

  WHY THIS FILE IS STATIC

  The field below was generated, not typed. It used to be generated AT RENDER,
  from about twenty `export const` declarations that held the palette, a seeded
  random generator, the placement rules and the components. `mint dev` and
  `mint validate` both accept that. Mintlify's PRODUCTION build does not: it
  served this page as "A parsing error occured" while every other page in the
  repo built, and no other .mdx in this repo uses `export const` at all.

  So the generator now runs at AUTHORING time and its output is pasted in. The
  script is kept at _working/v2-tutorials/splash-generator/, and the rules it
  encodes are unchanged:

  1. WEIGHTED, not uniform. Orange and Yellow are 45% of the field between them
     and the four darks together are 13%, which is the hand-built mix, counted.
     Uniform picking across twelve colours pushed the darks to 33% and the page
     read heavy and muddled.

  2. NO TOUCHING TWINS. A colour is rejected if the cell to its left or above
     already holds it. Uniform picking averages 7 to 14 adjacent pairs in 88
     cells, and each one welds two modules into a single double-width block,
     which is the one thing that destroys the deck grid.

  3. Positions are designed and fixed: the L, the band across the top, and the
     way the field thins as it travels. Only colour was ever generated.

  The trade is that the field no longer changes per load. It is one good field
  instead of a new one each time, which is also what makes a screenshot of this
  page reproducible.

  To reroll it: run the script with a different SEED and paste the output back
  over the cells below. Nothing else needs to change.

  SETTLE SWEEP

  Each cell's animationDelay is its own diagonal (col + row) scaled so the last
  diagonal in the field lands at 720ms, so the field assembles outward from the
  anchor corner in one continuous pass and takes the same time to do it
  whatever the field's width. The values are baked into the markup below.
*/}
