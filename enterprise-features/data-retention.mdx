## Introduction

Data retention controls how long Bland keeps call recordings and transcripts for your organization. Once a day, Bland deletes anything older than the period you set. Deleted data can't be recovered.

Use data retention when your compliance or privacy policies require you to limit how long call audio and conversation text are stored.

<Note>
  Data retention is available to enterprise organizations. Organization owners and admins can change it.
</Note>

## What data retention covers

You set a separate period for each type of data:

| Setting         | What it deletes                                                    |
| --------------- | ------------------------------------------------------------------ |
| **Recordings**  | Call audio.                                                        |
| **Transcripts** | Conversation text, including copies in logs and webhook history.   |

Bland keeps call details, summaries, analysis, and extracted variables. If a recording is stored in your own Twilio account or storage bucket, Bland removes its link but doesn't delete the file.

## Set a retention period

1. In the dashboard, go to **Settings → Organization → Data retention**.
2. Select a period for **Recordings** and for **Transcripts**. Each defaults to **Keep forever**. You can also select 14, 30, 60, 90, or 180 days, 1 year, or 2 years.
3. Select **Save**.
4. Review the confirmation and confirm the change.

## Confirming changes

Every save asks for confirmation. What you see depends on whether the change deletes data.

### Changes that delete data

Adding a limit or shortening one deletes older data. The confirmation shows:

- The old and new period for each type.
- How many calls the change affects. For a new limit, this is the calls made before the cutoff date. For a shorter limit, this is the additional calls made between the old and new cutoff dates.

To continue, type your organization's name and select **Save and delete data**. Within 24 hours, Bland starts deleting the affected data. You can't undo this, even if you change the setting later.

### Other changes

Lengthening a period or switching back to **Keep forever** gets a simple confirmation. Data already deleted under the previous setting can't be restored.

<Tip>
  If another admin changes the settings while you have the confirmation open, Bland asks you to review the current values and try again.
</Tip>

## Recording link expiration

Data retention is separate from **Recording link expiration** in your general recording preferences. Recording link expiration only controls how long shared recording links stay valid. It doesn't delete recordings.
