The mobile dashboard is a read-only version of the Bland dashboard made for phone screens. Use it to check on an agent from your phone: what it is set up to do, how its calls are going, and what it said in each call or text.

It is built for agents you set up by texting Bland, but it works for any agent in your organization.

## Prerequisites

- A Bland account and at least one agent
- A phone browser signed in to the Bland dashboard

## Open the mobile dashboard

Sign in to the dashboard on your phone. Bland opens the mobile dashboard for you.

If you open a dashboard link on a phone, Bland takes you to the matching mobile page. For example, a link to an agent's analytics opens that agent's analytics on the phone. A link to a page with no phone version opens the agent's main page instead.

Settings and Support open in their full desktop layout on a phone.

If your organization has one agent, the mobile dashboard opens that agent. If it has more than one, pick an agent from the list first.

<Note>
A desktop browser is never redirected, even in a narrow window. If you open the mobile dashboard on a desktop, the side menu shows **Open full dashboard** to switch back.
</Note>

## What you can see

Use the tabs under the header to move between **Agent** and **Pathways**. Open the menu at the top left to reach every section and to switch agents.

| Section | What it shows |
|---|---|
| **Agent** | The agent's name, phone numbers and their channels, voice and languages, instructions, and pathways |
| **Pathways** | Each pathway as text: its prompt, when the agent routes to it, and its steps |
| **Analytics** | Call totals with trends, talk time, calls by day, and call outcomes for a time window you pick |
| **Conversations** | Calls and text threads in one list, newest first. Open a call for its recording, transcript, and facts, or open a text thread to read it. |
| **Norm** | Your past chats with Norm. Open one to continue it full screen. |

Analytics counts calls only. Find texts under **Conversations**.

## Ask Norm from any page

A message box for [Norm](/tutorials/norm) sits at the bottom of every agent page. Type a question and send it. Norm reads the page you are on, so you can ask about the agent, a pathway, or a conversation without explaining which one you mean. The chat then opens full screen.

Some Norm actions need a desktop. For example, a voice test from a phone ends with a message to use a desktop.

## Change your agent

The mobile dashboard is read-only. To change your agent, use one of these:

- Text Bland at **+1 (321) 424-0172** and describe the change.
- Sign in to the dashboard on a desktop and edit the agent in the [agent builder](/agents/agent-builder).

The side menu on a phone shows a **Text Bland** button that opens a text to that number.
