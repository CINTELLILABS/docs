## Overview

API keys authenticate every request you send to the Bland API. You manage them in the [dashboard](https://app.bland.ai/dashboard/settings) under **Settings → API keys**.

Each key can have a name. Names help you tell keys apart without comparing key prefixes. A name is a label only. It has no effect on authentication, and renaming a key never interrupts anything using it.

## Create a key

1. Sign in to the [Bland dashboard](https://app.bland.ai).
2. Open **Settings → API keys**.
3. Select the option to create a new key and enter a name that describes where the key is used, for example `Production backend` or `Staging`.

Store the key securely. Use it in the `Authorization` header of your API requests, as shown in the [quickstart](/quickstart).

## Rename a key

1. Open **Settings → API keys**.
2. Open the row menu for the key you want to rename.
3. Select the rename option, enter the new name, and save.

Renaming takes effect immediately and does not change the key itself. Requests that use the key keep working.

Keys created before naming was available show as **Unnamed key** until you give them a name.
