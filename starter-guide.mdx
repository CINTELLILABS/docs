Sign in to the [dashboard](https://app.bland.ai) and open **Send call**. To try an agent you have built, use the **Agent** tab. To start with standalone instructions, use **Prompt**.

## Send your first call

1. In **Destination**, choose the country and enter your own phone number.
2. On **Prompt**, write instructions for the call or choose a Telehealth, Small business, Stadium venues, or Inbound sales starter. On **Agent**, select the agent to call with.
3. Review optional call settings, including **Knowledge & tools** and **Scheduling & webhook**. Under **Tools and knowledge bases**, select resources and describe in the prompt when each tool should be used.
4. Turn on **Show code** to inspect **API request**. Its JSON, JavaScript, Python, and cURL tabs update with the form.
5. Select **Send call** in the footer. A future **Scheduled time** changes the action to **Schedule call**.

Saved prompts and configurations let you reuse settings. Check the current destination and scheduled time before sending another call. Calls are billed according to your [plan](/platform/billing).

Use [Send a call](/api-v1/post/calls) to make the request from your application, then review the result in [Conversations](/agents/conversations).

## Test and improve an agent

Use the builder's [Testing panel](/agents/testbed) to try Call or Chat. Use [Evaluations](/agents/evaluations) for reusable simulated callers and judges that score their conversations. Testing an agent and sending a standalone prompt call are separate workflows.
