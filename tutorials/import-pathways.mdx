## Introduction

Agents in the Bland dashboard represent conversation behavior as scenarios. The **Import pathways** dialog converts an existing [conversational pathway](/tutorials/pathways) into scenarios on the agent you have open, so you can reuse work you already built instead of recreating it.

You can import in two ways:

- **From your pathway library**: select pathways from your organization and import each one as a scenario.
- **From a JSON file**: drop a pathway export file into the dialog and import it directly.

## Open the Import pathways dialog

1. Open your agent in the dashboard and go to its behavior editor.
2. Select the **Import pathways as scenarios** button in the toolbar.

## Import from your pathway library

1. Select one or more pathways from the list. Use the search field to filter.
2. Select **Continue** to review your selection.
3. For each pathway, choose how it converts:
   - Leave **Translate** off for an exact 1:1 copy of the pathway as a scenario.
   - Turn **Translate** on to re-architect the pathway into simplified agent scenarios. Translations run in the background, and you can start several while you keep working.
4. Select **Import**.

1:1 imports add their scenarios to the agent immediately. Finished translations appear as jobs at the top of the dialog. Select **Insert** on a job to add its scenarios to the agent.

## Import from a JSON file

Drop a pathway JSON export onto the drop zone below the pathway list, or select **Browse files** and pick the file. The dialog accepts:

- The file the agent builder's **Export** button produces.
- A pathway JSON download from the legacy dashboard.

The file must be a `.json` file of 5 MB or smaller, and it must contain a non-empty `nodes` array. An `edges` array is optional.

A file always imports as an exact 1:1 copy. Translate is not available for file imports. The scenario is named after the `name` field in the file. If the file has no name, Bland derives one from the file name.

Because the dialog accepts the agent builder's own export files, exports round-trip: you can export an agent's behavior as a pathway file and import that file back into any agent.

## After an import

- Imported scenarios join the agent's unsaved changes. Save the agent to keep them. You can undo an import before saving.
- If parts of a pathway have no scenario equivalent, such as a global prompt or a memory setting, the import completes and reports those items as flagged.
- If a file cannot be imported, the dialog shows a message that names the exact problem, such as invalid JSON or a missing `nodes` array.
