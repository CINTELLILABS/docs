---
title: "Pronunciation"
description: "Fix how your agent says a name or term with a phonetic spelling or ARPABET sound codes."
---

When your agent says a name, place, or product term the wrong way, add a pronunciation rule. A rule pairs a word with how to say it. Each time the agent is about to say that word, Bland swaps in your pronunciation.

You can write the pronunciation two ways:

| Format | What you write | Works with | Example for Medina |
| :---- | :---- | :---- | :---- |
| Phonetic | The word spelled the way it sounds | Every voice | `muh dye nuh` |
| ARPABET | One sound code per sound, with optional stress numbers | Bland TTS v3 voices | `M AH0 D AY1 N AH0` |

A phonetic spelling is still text that the voice has to interpret, so the result can vary from one spelling to the next. ARPABET names each sound directly. If you have tried a few spellings and none is consistent, and your agent uses a Bland TTS v3 voice, switch to ARPABET.

<Note>
ARPABET covers US English sounds and only works with Bland TTS v3 voices. With any other voice, use a phonetic spelling.
</Note>

## Example: Medina

Say your agent pronounces Medina as "meh-DEE-nuh" and your customer says "muh-DYE-nuh".

1. Look the word up in the [CMU Pronouncing Dictionary](http://www.speech.cs.cmu.edu/cgi-bin/cmudict). Check **Show Lexical Stress** so the result includes stress numbers.
2. The dictionary returns `M AH0 D AY1 N AH0`. The stressed vowel is `AY`, the sound in "my", which is the pronunciation you want.
3. Add a rule for `Medina` with that pronunciation, in the dashboard or through the API.

If the dictionary had returned the other pronunciation, you would change one code. "meh-DEE-nuh" is `M AH0 D IY1 N AH0`, where `IY` is the sound in "see". Swapping `IY1` for `AY1` is the whole fix.

## Add a rule in the dashboard

1. Open your agent and go to **Settings**, then **Speech settings**.
2. Make sure the agent uses a Bland TTS v3 voice if you want ARPABET.
3. Under **Pronunciation guide**, click **Add word** and enter the word.
4. Click **Generate pronunciation** (the sparkle button) to look the word up in the dictionary. Click a choice to hear it in your agent's voice, then click **Done** to apply it. Listening alone does not save a choice.
5. To write the sounds yourself, set the format to **ARPABET** and enter the codes without braces. Bland adds the braces for you.

Each rule has two matching options. **Case sensitive** matches only the capitalization you enter, which helps with names like Max. **Whole words only** keeps a rule for Ann from changing Anna.

A phone number's own pronunciation guide replaces the agent's on calls to that number.

## Pass a rule through the API

Use the `pronunciation_guide` parameter on [Send Call](/api-v1/post/calls). Write ARPABET inside braces so Bland TTS v3 reads it as sound codes instead of letters:

```json
{
  "pronunciation_guide": [
    {
      "word": "Medina",
      "pronunciation": "{M AH0 D AY1 N AH0}",
      "case_sensitive": true,
      "spaced": true
    }
  ]
}
```

A phonetic spelling goes in the same field without braces, for example `"pronunciation": "muh dye nuh"`.

## Write ARPABET

- Use uppercase codes separated by spaces, one code per sound.
- A number after a vowel sets its stress: `0` is unstressed, `1` is primary stress, and `2` is secondary stress. Stress numbers are optional.
- Put stress numbers on vowels only, never on consonants.
- In the API, wrap the codes in braces. In the dashboard, leave the braces out.

The dictionary does not contain every name. For a word it does not have, write the sounds yourself. Jake is `JH EY K`. Samsara is `S AE1 M S AA0 R AH0`.

To adjust a pronunciation, change the code for the sound that is wrong, or move the `1` to the syllable that should carry the emphasis.

## If a rule does not take effect

- **The voice is not Bland TTS v3.** Other voices do not read ARPABET. Change the voice or use a phonetic spelling.
- **The word does not match.** A rule matches the word as the agent writes it. Check the spelling, and check whether **Case sensitive** or **Whole words only** is excluding it.
- **The ARPABET is incomplete.** In the dashboard, a rule with a code that is not in the table above is skipped on calls until you fix it.
- **The phone number has its own guide.** It replaces the agent's guide on calls to that number.
