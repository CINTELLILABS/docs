## Overview

Each agent in the Bland dashboard has a **Channels** page for per-channel behavior and a **Configure → Settings** page for core agent settings. This guide covers the Calls channel settings and how to delete an agent.

## Calls channel

Open your agent in the dashboard, then go to **Channels** and select **Calls**. Calls are always on for every agent, so there is no enable toggle for this channel.

The Calls channel controls per-call behavior:

- **Max duration (minutes)**: hard cap on call length.
- **Wait for greeting**: the agent waits for the call recipient to speak first before responding.
- **Noise cancellation**: filters background noise out of the caller's audio stream.
- **Ignore button press**: ignores keypad presses during the call.
- **Record**: records the call. When the call completes, you can access the recording through the `recording_url` field in the call details or your webhook.

These settings apply as defaults for the agent's calls. Parameters you pass directly on [Send Call](/api-v1/post/calls), such as `wait_for_greeting` or `record`, override them for that call.

### Conversation feel

The **Conversation feel** section shapes how natural the call sounds:

- **Interruptibility**: how easily the caller can interrupt the agent while it speaks. Block interruptions ignores them entirely.
- **Agent backchannels**: short listener murmurs ("mm-hm") while the caller is mid-thought. Choose **Off**, **Sparse**, **Normal**, or **Rich**.
- **Background noise**: plays ambient audio during the call so it feels more natural. Choose **Off**, **Office**, **Coffee shop**, or **Restaurant**.

## Preview voices

You can hear a voice before assigning it to your agent. In the agent builder's voice picker:

1. Open the voice picker.
2. Hover over or highlight a voice and select the play control to hear a sample.
3. Select the voice to assign it, or play another voice to compare.

Keyboard users can highlight a voice with the arrow keys and press **Alt+P** to play or stop the preview. Playing a preview doesn't select the voice, so you can listen to several options before choosing.

## Delete an agent

To delete an agent you no longer need:

1. Open the agent in the dashboard.
2. Go to **Configure → Settings**.
3. Scroll to **Delete agent** and select **Delete**.
4. Confirm by selecting **Delete agent** in the dialog.

<Warning>
  Deleting an agent is permanent and can't be undone.
</Warning>

After deletion, Bland returns you to the dashboard and removes the agent from your agent list.
