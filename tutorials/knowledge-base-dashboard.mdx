## Overview

The Knowledge section of the dashboard is where you manage everything your agents retrieve from. It appears in two places:

- **Organization scope**: **Knowledge** in the sidebar shows every source in your organization.
- **Agent scope**: open an agent, then select **Knowledge** to work with the same views scoped to that agent.

Both scopes share the same five tabs: **Sources**, **Questions**, **Query Logs**, **Knowledge Map**, and **Source Testing**. The agent scope filters each tab to the sources attached to that agent, so you can manage an agent's knowledge without leaving its page.

To create and manage knowledge bases programmatically, see the [Knowledge Base API](/api-v1/post/knowledge-learn-text).

---

## Sources

The **Sources** tab lists every knowledge source in your organization. You can:

- Search sources by name, and filter by type and status.
- Sort the list and page through large source sets.
- Create new sources and delete existing ones.
- Select a row to open the source detail view, where you can edit content, review versions, and manage metadata.

Each row shows retrieval health over the last 30 days, including:

- **Indexed sections**: the number of chunks the source was split into for retrieval.
- **Queries**: distinct queries that consulted the source.
- **Share**: the percent of all queries across the org that consulted the source.
- **Hits / Misses**: queries that returned an answer versus queries that didn't.
- **Coverage** and **Resolved coverage**: the share of queries that returned an answer, before and after counting resolved questions.
- **Contexts**: where the source is used, including agents that reference it and pathway nodes that pull it in.

### Attaching sources to an agent

In agent scope, the Sources tab adds an attach checkbox to each row and shows a count of attached sources in the header. Select the checkbox to attach or detach a source, then select **Save** to apply the change to the agent. Selecting the row itself opens the source detail view without changing the attachment.

The list shows every source in your organization in both scopes. Agents don't own sources; attaching a source is what makes it available to that agent on calls.

## Questions

The **Questions** tab collects questions your sources couldn't answer. For each question you can:

- **Answer** it inline. The answer is saved into a source, so every agent using that source picks it up.
- **Dismiss** questions that don't need an answer, and **Reopen** dismissed ones.
- Filter by source and status, sort the list, and export the filtered set to CSV with **Export CSV**.

In agent scope, the tab only shows questions raised against the agent's attached sources, and inline answers can only be saved to attached sources.

---

## Query Logs

The **Query Logs** tab shows the retrieval queries your agents made, with the time, query text, status, source consulted, the context the query ran in, and a link to the call. You can search queries, filter by state and source, and narrow to a date range. The view defaults to the last 7 days.

In agent scope, the log is filtered to queries made by that agent.

---

## Knowledge Map

The **Knowledge Map** tab lays out your sources and questions as a connected graph, color-coded by coverage and by open versus resolved questions. Select a node to see its details and jump to the source.

In agent scope, the map is narrowed to the agent's attached sources and the questions raised against them. Node sizes use the same org-wide query volume in both scopes, so a source's size means the same thing on either page.

---

## Source Testing

The **Source Testing** tab is a chat tester for retrieval. Select one or more sources, ask a question, and see what comes back before callers do. You can rerun a question with **Test again** after editing a source.

In agent scope, the tester is limited to the agent's attached sources and opens with all of them selected, so a question here answers "what would this agent retrieve on a call?"

---

## Agent scope requires attached sources

The agent-scoped Questions, Knowledge Map, and Source Testing tabs need at least one attached source. If the agent has none, each tab prompts you to attach sources on the Sources tab first.
