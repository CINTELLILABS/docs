title: Webhook signing
description: "Create a signing secret and verify signatures on Bland webhooks."

Bland webhooks are signed with a secret key to ensure that they are not tampered with in transit and to confirm that they were sent by Bland.

## Signing Webhooks

When Bland sends a webhook, it calculates a signature using the HMAC algorithm with the SHA-256 hash function. The signature is then included in the `X-Webhook-Signature` header of the request.

To create a webhook signing secret, open [Settings → Organization](https://app.bland.ai/settings/organization), then **Webhook → Signing secret**.

Select **Generate signing secret** to create your first secret, or **Replace signing secret** to replace an existing one. The secret is shown once, so save it securely. Update your webhook verifier when you replace it.

## Verifying Webhooks

To verify a webhook, you need to calculate the HMAC signature of the request body using the secret key and compare it to the signature in the `X-Webhook-Signature` header.

Note that you must first create a webhook signing secret under **Settings → Organization → Webhook → Signing secret**.

Here is an example of how to verify a webhook in Node.js:

Use the raw request body when verifying. Install this route before any JSON body parser so it receives the bytes that Bland signed:

```javascript
const crypto = require("node:crypto");
const express = require("express");
const app = express();

function verifyWebhookSignature(key, body, signature) {
  if (
    !key ||
    typeof signature !== "string" ||
    !/^[a-f0-9]{64}$/i.test(signature)
  ) {
    return false;
  }
  const expected = crypto.createHmac("sha256", key).update(body).digest();
  return crypto.timingSafeEqual(expected, Buffer.from(signature, "hex"));
}

app.post("/webhook", express.raw({ type: "application/json" }), (req, res) => {
  if (
    !verifyWebhookSignature(
      process.env.WEBHOOK_SECRET,
      req.body,
      req.headers["x-webhook-signature"],
    )
  ) {
    return res.sendStatus(401);
  }
  const payload = JSON.parse(req.body.toString("utf8"));
  // Process payload here.
  return res.sendStatus(200);
});
```
