## Introduction

You can bring a legacy conversational pathway into an agent without rebuilding it by hand. Bland offers two ways to import:

- **1:1 import** copies the pathway verbatim into the agent as a scenario.
- **AI translation** rewrites the pathway into agent scenarios that are easier to maintain. Where possible, the pathway is simplified into a single scenario with tools. When step order matters, it becomes a streamlined flow.

Translations are long-running, so they run as background jobs. You can start several at once, keep working, watch progress from the builder, cancel a job, and insert the finished scenarios when you're ready.

## Import into an existing agent

1. Open the agent you want to add scenarios to.
2. In the configure view, open the **Import pathways** modal.
3. Add one or more pathways to the list.
4. For each pathway, leave **Translate** on to run AI translation, or turn it off to do a 1:1 import.
5. Start the import.

Translations run in the background. Each pathway shows its own progress in the modal, and a status chip in the top bar tracks jobs across the dashboard while you work elsewhere.

When a translation finishes:

- Review the resulting scenarios in the modal.
- Insert them into the agent, or cancel the job if you don't want the result.

You can start several translations at the same time. Each one runs independently, so a slow pathway won't block the others.

## Create a new agent from pathways

The new-agent flow supports the same import. Instead of adding scenarios to an existing agent, Bland spins up a whole agent from your translated pathways.

1. In the sidebar, open **New agent**.
2. Choose to build the agent from existing pathways.
3. Add the pathways you want to translate.
4. Start the job.

The translating screen shows progress per pathway and is resumable, so you can close the modal and come back to it. When translation finishes, the new agent is created with the resulting scenarios and opens for you to review.

## Cancelling a translation

You can cancel a translation while it's still running. Once a job reaches the final insertion or agent-creation step it can no longer be cancelled from the UI, and any completed scenarios remain available to insert.
